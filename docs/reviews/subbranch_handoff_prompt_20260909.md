### 1. 커밋 전에 **반드시** — 이건 선택이 아니다

```bash
bash scripts/check_all.sh      # GPU 불요, 수 분
```

`✓ 전부 통과` 가 아니면 **커밋하지 않는다.**  이유가 둘 있다:
- `--selftest` 는 *검사기가 맞나*, 인자 없는 실행은 *리포가 맞나* 를 본다.  **서로를
  대신하지 않는다.**  같은 실수를 두 번 했다 — 둘 다 selftest 는 초록이었고 CI 가 60 초 뒤
  빨간불을 냈다.
- 그중 한 번은 러너의 fail-closed 게이트라 **사용자의 GPU 런을 막았다.**  원장 오타 하나가
  계산을 세운다.

⚠ 파이프로 넘기면 종료코드가 가려진다.  `| tail` 로 보지 말고 **그냥 돌려서 마지막 줄을 볼 것.**

### 2. ★★ 충돌이 실제로 나는 자리 — 이것만 지키면 거의 안 난다

최근 20 커밋에서 가장 자주 바뀐 파일이 **충돌 위험 순위**다:

| 파일 | 왜 위험한가 | 어떻게 피하나 |
|---|---|---|
| `docs/reviews/claims.json` | **끝에 append** 하는 원장.  두 브랜치가 각각 `CL-90` 을 새로 쓰면 같은 자리에서 충돌 | **작업 끝에 한 번만** 등재.  등재 직전 `git fetch` 해서 **최신 id 를 다시 확인**하고 그 다음 번호를 쓴다 |
| `docs/reviews/findings.json` | 같은 이유 (`AUD-08`, `SELF-17` …) | 같음 |
| `docs/reviews/selftest_inventory.tsv` | 새 selftest 를 **끝줄에 추가** | 같음 |
| `scripts/check_all.sh` · `.github/workflows/discipline.yml` | 새 검사 배선을 **같은 블록**에 추가 | 새 검사를 **한 자리에만** 넣고, 넣으면 위 tsv 등재도 같이 (안 하면 게이트가 막는다) |
| `CLAUDE.md` | 여러 절이 동시에 자란다 | 네 트랙의 절만 건드린다.  다른 절은 **읽기만** |

**충돌이 났을 때**: 원장 JSON 은 **양쪽 항목을 다 살린다** (id 만 안 겹치게 다시 매긴다).
절대 한쪽을 통째로 버리지 않는다 — 그 안에 다른 사람의 판정이 들어 있다.

### 3. 이 리포에서 반드시 알아야 할 규율 다섯

1. **코드 쓰기 전 사다리**: 필요한가 → **이 리포에 이미 있나** → stdlib → 기존 의존 → 최소.
   ★ 2번이 급소다.  오늘도 탄소 모델이 **두 벌**인 것이 그래서 발견됐다
   (`grade_engine` 과 `predictor_engine` 이 각자 갖고 있었고 값이 51배 달랐다).
2. **고치기 전에 재현 테스트 먼저.**  결함을 재현하는 selftest 를 **먼저** 넣고 고친다.
   ★ 그리고 **음성 대조**를 돌려라 — 통과만 하는 검사는 없는 것과 같다.
3. **수치를 철회하는 커밋은 같은 커밋에서 원장·파생 문서를 고친다.**  안 그러면 새어나간다
   (반증된 값이 7일 뒤 신규 문서에서 재주장된 실사고가 있다).
4. **"후보를 고르는 코드" 가 곧 사각지대다.**  필터·글롭·손목록으로 훑으면 조용히 초록이
   된다.  실물을 잡아라 (파서를 실행, 키를 전수로, 스냅샷을 고정).
5. **인용 금지값**: `docs/reviews/claims.json` 의 `quotation_ban` 이 정본이고
   `check_review_findings.py --ban-sweep` 이 강제한다.  ⚠ 그 값을 **설명하려고** 적는 것은
   허용이지만 **현행 결론으로** 적으면 안 된다 — 줄 ±2 안에 철회 표지가 있어야 한다.
