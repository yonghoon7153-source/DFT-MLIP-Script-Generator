## Q1 ⚠⚠ 재하율 — 준정적 한계의 **43배**로 순서 캠페인을 돌려도 되나

```
mpm3d_compaction 준정적 한계   V/c_P ≤ 0.01
스모크 실측                    V/c_P = 0.4275   (--allow-fast-platen 로 승인, 결과에 기록됨)
옛 코퍼스 kit_ps_7_3 (~113 µm) V/c_P = 0.105
real_14 (31 µm)                V/c_P = 0.031
```

킷은 `--platen-mach` 를 안 쓰고 **기하 규칙** `vmax = 0.008·(WALL0 − FLOOR)` 를 쓴다.
사전등록 §4 는 primary 를 `--platen-mach 0.03` 으로 적었으므로 **문서와 실물이 어긋난다.**

### 우리가 이미 아는 것

- **리포 실측** (CLAUDE.md §③, 같은 침대·같은 ε): 마하 **0.0306 → 0.01** (3배 감속) 에
  두께 −0.0 % · **σ +4.8 %**.  느릴수록 σ 가 올라간다 = 관성이 응력을 **낮추고** 있었다.
  ⇒ 4.8 % 는 우리 판정 문턱 `δ_num = 0.04 %` 의 **120배**다.
- **조성 교락은 대체로 배제된다** — `c_P = √(λ+2µ)` 는 SE 재료상수(`--e-se 1.53 --nu-se 0.49`)
  에서 나오고 **조성 무관**이다.  기하 규칙은 **초기 높이**에만 비례하는데 네 조성은 같은
  스캐폴드·같은 `n_grid` 라 높이가 같다.  코드 주석도 *"같은 n_grid 안에서는 v 가 불변…
  베드가 같으면 높이도 같다"* 로 이 축을 명시한다.
  ⚠ **초안에서 우리는 반대로 적었다** (*"VGCF 가 c_P 를 바꿔 조성마다 재하율이 다르다"*).
  코드를 읽고 **철회**했다.  ⇒ 남은 것은 **절대 크기**이지 조성 간 차이가 아니다.

### ★ 묻고 싶은 것

**Q1-1** 조성 **순서**만 묻는 캠페인에서, 네 팔이 같은 (준정적이 전혀 아닌) 재하율을 쓰면
그 편향이 공통모드로 상쇄된다고 볼 수 있나?  아니면 재하율이 **조성과 상호작용**할 경로가
남아 있나 — 예컨대 첨가제가 SE 유동 채널을 막는 정도가 조성마다 다르면, **같은 속도라도
"흐를 시간이 부족한 정도"가 조성마다 달라지지 않나**?

**Q1-2** 이 우려를 **런 전에** 가를 측정이 있나?  우리가 계획한 것은 네 조성의 STEP2 를
돌려 `platen_mach_VcP` 네 값을 비교하는 것인데, 위 기전대로면 그 값들은 거의 같게 나올
것이고 **그것이 공통모드의 증거가 되지는 않는다** (같은 속도인 것과 같은 영향인 것은 다르다).
더 판별력 있는 대조는 무엇인가?  후보:
  (a) 한 조성을 `--platen-mach 0.03` 으로 한 번 더 돌려 **같은 조성 안의** 속도 감도를 재기
  (b) 양 끝 조성(1 · 4 wt%)만 두 속도로 돌려 **속도 × 조성 상호작용**을 직접 보기 = 4 런
  (c) 순서 판정을 속도별로 따로 내고 두 판정이 같은지 보기

**Q1-3** 비용이 결정적이다.  `0.4275 → 0.03` 은 판이 **14배** 느려져 STEP2 가 4 런 10~19 h 에서
**140~270 h** 로 간다 (전체 예산 3.4~5.4일 → 10일+).  (b) 는 4 런 추가로 ~20~38 h 다.
**어디까지가 정직에 필요한 최소인가?**

**Q1-4** 사전등록 §4 를 실물(기하 규칙)에 맞춰 고치는 것이 정당한가?  우리 논리는
*"캠페인 결과가 아직 하나도 없으므로 문턱을 옮기는 것이 아니라 설계를 실물에 맞추는 것"* 인데,
이것이 사전등록의 취지를 훼손하나?  ⚠ Secondary(Lee 절대 대조)는 §4 대로 `0.01` 을 유지한다.

## Q2 두 해상도 게이트가 **반대 방향**을 가리킨다

같은 침대·같은 캠페인인데 두 게이트의 답이 다르다.

| 게이트 | 무엇의 해상도 | 결과 |
|---|---|---|
| `d_h/dx ≥ 3.5` | **MPM 의 SE 응력** (STEP2) | ✅ 통과 — `d_h 0.9821 µm`, 최소 통과 `n_grid 179`, 실행 256 → **5.02** |
| SE neck / h | **STEP3 σ 격자** | ⚠ `h=0.20` 에서 neck 의 **85.6 %**, `h=0.25` 에서 **97.4 %** 가 2 셀 미만 |

`neck Ø 중앙값 0.2751 µm` · `h=0.15` 에서 58.2 % 가 2 셀 미만.

**Q2-1** 사전등록은 세 격자(0.15 · 0.20 · 0.25)로 *"순서가 격자에 강건한가"* 를 묻는다.
그런데 거친 두 격자는 **SE 접점 기하가 대부분 지워진 침대**다.  거기서 순서가 유지되는 것은
*"격자에 강건"* 의 증거인가, 아니면 **다른 침대에서의 별개 관측**인가?
우리는 후자로 좁혀 적었다 (*"SE 접점이 지워져도 순서가 남는다"*) — 이 서술이 정확한가?

**Q2-2** 그렇다면 거친 두 격자(64 팔, 예산의 ~35 %)를 **설계에서 빼는 것**이 옳은가?

## Q3 ⚠ 각도 선별을 **무첨가** 스캐폴드에서 쟀다 (우리 쪽 구멍)

CL-73 이 STEP4 rate 비교를 HOLD 했고, 그 해제 근거로 각도 위험 선별을 돌렸다:

```
cov p05 0.3999 · 중앙 0.5770 · zero fraction 0.00 %
K_required = 8   (사전등록 규칙 K · cov_p05 ≥ 3)
z-bin  collector 0.5915 → mid 0.5720 → separator 0.5700   (기울기 없음)
```

⚠ **그런데 이것은 첨가제를 넣기 전 AM/SE 스캐폴드에서 잰 것이다.**  실제 캠페인 침대는
VGCF 26,816 ~ 111,279 개가 SE 를 밀어낸 상태다.  옛 캠페인 실측 coverage 가
**VGCF 1 wt% 60.7 vs 4 wt% 51.7 (비단조)** 였던 것이 바로 그 효과다.

**Q3-1** 이 선별이 조성 팔로 **전이되나**?  아니면 조성마다 다시 재야 하나
(STEP2 산출 침대에서, 각 조성별로)?

**Q3-2** 전이되지 않는다면 `K_required = 8` 이라는 결론이 무너지나?  coverage 가 낮아지는
쪽(4 wt%)에서 `p05` 가 떨어지면 `K = ceil(3/p05)` 가 커진다.  **어느 조성의 K 를 써야 하나** —
최악 조성인가, 조성별로 다른 K 인가?

**Q3-3** 각도 선별이 STEP4 HOLD 해제의 **필요조건**이지 충분조건이 아니라는 것은 등록돼 있다
(최종 게이트 = *"조성 간 `q_frac_at_cutoff` < 1 %p 이고 동일 SOC 전압차 < 5 mV"*).
그렇다면 선별을 조성별로 다시 재는 것이 **의미가 있나**, 아니면 어차피 실제 런이 필요하니
지금 단계에서는 넘어가도 되나?

## Q4 MPM porosity 13.699 % vs DEM 14.321 % — 0.62 %p

MPM 이 DEM 보다 조밀하게 끝났다.  알려진 관례 오프셋(ε_sphere ↔ union, ~1.25 %p)과
소성 유동의 추가 치밀화가 섞인 것으로 읽었는데, **빠른 재하(Q1)가 여기 기여하나?**
리포 실측은 *"느릴수록 σ↑"* 인데 porosity 방향은 별도로 기록된 적이 없다.

⚠ 이 값이 판정에 들어가지는 않는다 (σ_e 순서가 estimand).  다만 **침대가 옛 캠페인과
같은지**를 말할 때 쓰이므로 해석이 필요하다.

## 5. 우리가 이미 정한 것 (재확인만)

- **`--add-rng-per-phase` = ON** — 스모크 매니페스트에 `True` 로 봉인 확인.  없으면 VGCF
  개수가 RNG 스트림을 밀어 PTFE 형상을 바꾼다 (CL-71/77).
- **음성대조 = exact replay** (seed 변경 아님).  replay 재실행 성분은 실측 **0.000 %** (CL-75).
- **판정 = 최악 팔 직접** (`d > δ_num = 0.04 %`), origin 산포 문턱 없음.  판정기
  `phase_a_order_verdict.py` (selftest 12/12) 가 이 규칙을 코드로 박았고 `δ_num` 은 CLI 로
  바꿀 수 없다.
- **격자 순서 0.15 먼저**, 역전 시 즉시 `ORDER-UNRESOLVED` 로 중단.
