## 1. Q1 — 지금 이 사전등록은 커밋 후 실행하면 안 된다

### [P1] 72 팔은 판정 행렬을 관측하지 않는다

요청서는 **4 조성 × 3 격자 전부의 순서**를 판정하는데, 배치는 0.20·0.25 µm 에서
**생산 조성 하나만** 잰다.  ⇒ 그 두 격자에서 나머지 세 조성의 순위는 **정의되지 않는다**.
게다가 생산 조성의 `h=0.15 × 8` 은 두 스윕에 **중복**된다.

```
문서상 실행 수      72
고유 설계점         64      (24 + 32 − 8 + 8 + 8)
원 질문의 primary   96      (4 조성 × 3 격자 × 8 origin)
+ Lee 대조 각 8    112
```

**두 갈래 중 하나를 택해야 한다** — 이건 GPU 예산 결정이라 사용자 몫이다:

- **(A) 원 질문 유지** ⇒ primary **96 팔** (+ Lee 16).
  비용을 줄이려면 격자별 32 팔을 **순차** 실행하고 역전이 나오는 즉시
  `ORDER-UNRESOLVED` 로 중단할 수 있다.  단 `ORDER-ROBUST` 를 얻으려면 결국 96 을 다 돈다.
- **(B) 72 가 절대 상한** ⇒ **판정을 좁힌다**:
  ```
  h = 0.15          4 조성 × 8              = 32
  h = 0.20, 0.25    endpoint(1·4 wt%)만 2×2×8 = 32
  exact replay                                 8
  ```
  결론도 *"0.15 에서 완전 순서, 나머지 두 격자에서 endpoint 부호 유지"* 로 축소한다.

⛔ **어느 쪽이든 "세 격자 전부에서 1 < 2 < 3 < 4" 는 주장할 수 없다.**

### [P1] seed 변경은 음성대조가 아니다

seed 는 섬유 위치·길이·방향·굴곡을 **실제로** 바꾼다.  더 나쁜 것은 **VGCF 와 PTFE 가 같은
RNG 스트림을 순서대로 소비**한다는 점이다 — VGCF 개수가 달라지면 뒤따르는 PTFE 1 wt% 의
형상도 달라진다.  소형 재현에서 VGCF 개수 1→2 만 바꾸자 동일 seed 의 PTFE SHA 가
`c838818136da8291 → e8cdebe8738da083` 로 변했다.

⇒ **조성 비교가 morphology 교란과 교락된다.**  세 가지를 분리해야 한다:

| 역할 | 무엇 |
|---|---|
| **음성대조** | **exact replay** — 동일 materialized STEP2 배열·동일 규약을 **다른 출력 경로**에서 재계산 |
| **morphology replicate** | 다른 seed (= seed sensitivity, 음성대조 아님) |
| **조성 비교** | 상별 **독립 RNG 스트림** + common-random-number 정책을 구현하거나, *"단일 morphology seed 에 조건부"* 로 제한 |

⚠ **8 origins 는 raster phase 를 잴 뿐 morphology seed 산포를 대신하지 않는다.**

### 판정 규칙 교체 — 임의의 "origin 산포 문턱" 을 없앤다

8 origins 는 무작위 표본이 아니라 **완전 nuisance 집합**이다.  그러면 산포를 통계로 다룰
이유가 없고 **최악 팔을 직접 판정**하면 된다.  인접 조성쌍 `k → k+1`, 격자 `h`, origin `o` 에서

```
d(h,o,k) = log σ(w_{k+1}, h, o) − log σ(w_k, h, o)
```

- **ORDER-ROBUST** — 모든 (격자, origin, 인접 조성쌍) 에서 `d > δ_num`
- **ORDER-UNRESOLVED** — 하나라도 `d ≤ δ_num`
- 평균·SD·범위는 **기술 보고 전용** (별도 HOLD 게이트로 쓰지 않는다)

`δ_num = 0.04 %` 는 합성 solver-method 차이 최대 `0.014 %/solve` 의 양 endpoint 최악합을
올림한 **사전값**으로 쓸 수 있다.
⛔ **exact replay 가 0.04 % 를 넘으면 문턱을 사후 확대하지 말고 전체 HOLD** 한다.
(⚠ 위 §0-2 의 0.108 % 는 이 문턱을 이미 넘는다 — 그래서 replay 를 **먼저** 돌려야 한다.)

### 나머지 Q1 답

- **"순서" 와 "Lee 비교" 는 다른 estimand** 다.  한 문서에 둘 수는 있으나
  **Primary order / Secondary Lee / QC** 로 분리하고 Lee 가 `ORDER-*` 판정에 관여하지
  못하게 한다.
- **Lee 의 "같은 조성" 은 현재 실행 경로에서 성립하지 않는다** — `--add-recipe` 는 AM:SE
  입력을 무시하고 **실제 scaffold 비**를 쓴다.
- **"격자와 규약에 강건" 은 과하다** — centerline **한 규약**만 재므로
  *"centerline 규약 하에서 격자·origin 에 강건"* 으로 좁힌다.
- **6 mAh 실제 scaffold 가 아직 저장소에 없다.**  실행 전 DEM dump · AM/SE scaffold ·
  phase/fibre 배열의 **SHA 를 봉인**해야 한다.
- **STEP2 에서 자동 `dilate-z`·`stiff`·`buckle`·`align` 이 VGCF 함량에 따라 함께 바뀐다.**
  이것을 *"생산 파이프라인 total effect"* 로 볼지 *"함량만의 효과"* 로 볼지 **먼저 명시**한다.
- **STEP3 봉인 최소 집합**: `fibre_stamp=segment` · `ptfe_stamp=centerline` · `sigma_ptfe=0` ·
  `bridge=0` · conductivity tables · plate rule · physical area · backend/rtol/maxiter ·
  그리고 **`LEAN=2` 의 전체 확장**.  정본 축은 `scripts/run_contract.py`.
- **`--platen-mach 0.03` 은 `--allow-fast-platen` 없이 중단된다.**  상대순서용 조건부 규약은
  가능하지만 **Lee 절대 대조에는 0.01 경로가 필요**하다.

## 2. Q2 — 하한 주장은 철회한다

세 coarse-side 점에서 단조 증가해도 `h < 0.15` 의 방향은 결정되지 않는다.  반례:

```
R(h) = R∞ + h − 4h²

h = 0.25 → R∞+0.0000
h = 0.20 → R∞+0.0400      ← 정밀화와 함께 증가
h = 0.15 → R∞+0.0600
h = 0.125→ R∞+0.0625      ← 꺾임
h → 0    → R∞             ← 더 낮은 값으로 복귀
```

★ **코드 자신이 이미 같은 결론을 강제하고 있었다** — `step3_sigma.py` 는 계단 저항 증가와
가짜 상호연결이 **반대 방향으로 경쟁**하므로 상·하한을 **둘 다 금지**하고 `bound=None` 을
반환한다.

| 후보 | 판정 |
|---|---|
| (a) 절대값의 **하한** | ⛔ 기각 |
| (b) *"시험한 격자에서 조성 순서가 유지됐다"* | ✅ 가능 (절대값 방향 주장 없음) |
| (c) 절대 σ | ✅ **격자별 병기**가 정답 |

### SE neck — 실제 분석 가치가 있다 (★ 리포에서 독립 재현 + 확장)

Codex 는 해석 킷 중앙 20 µm 의 **9,476 overlap** 에서 neck 지름 중앙값 **0.274 µm**,

(쌍 수 8,926 vs 9,476 차이는 crop 경계 포함 규약 — 중심 기준 vs 교차 기준.  분포는 같다.)

⇒ **`SE 지름/h = 6.7` 은 neck 해상도를 보증하지 않는다** — 확인.

★★ **그리고 확장이 더 나쁘다.**  Phase A 가 coarse 스윕에 쓰려던 바로 그 두 격자에서

## 3. Q3 — 각도분해 결손은 공통모드가 아니다

코드가 각도를 잃는 **정확한 위치**는 "접촉면별 BV 를 빠뜨린 것" 이 **아니다**:

```
step4_dyn.py:1104   AM–이온상 면을 실제로 찾는다        ✓
step4_dyn.py:1193   면별 BV 전류를 실제로 푼다          ✓
step4_dyn.py:1447   면전류를 입자 하나의 총전류로 합친다  ← 여기서 각도가 죽는다
step4_dyn.py:1693   그 총량을 전 구면적 4πR² 에 살포한다
```

⇒ 버려지는 것은 그 뒤 **고체확산의 `l > 0` 각도 모드**다.

### Q3-1 — 상쇄되지 않는다 (CONFIRMED)

조성이 바뀌면 접촉률·패치 방향·입자별 전류/접촉면적·깊이 방향 전류분포가 **함께** 바뀐다.
**공통 `i0` 도 상쇄 보장이 아니다**: 동일 총전류에서 활성면적 0.25 와 1 인 두 구조의 대칭 BV
상대 과전압 차는 `i0` 를 0.2 → 20 으로 바꾸면 **69.4 → 3.85 mV** 로 변한다.

### Q3-2 — 부호는 정할 수 없다 (UNRESOLVED)

**입자 하나**에는 조건부 부호가 있다: 고정 총전류에서 실제 coverage 가 `c` 면 patch flux 는
균일값의 약 `1/c` 이고, 현재 모델은 국소 표면포화를 **늦추는 낙관 편향**이다.

**그러나 조성 차의 부호는 다르다.**  옛 캠페인 CSV 의 실측 coverage (Hertz, P/S):

```
VGCF 0.5 wt%   40.9 / 41.7
VGCF 1   wt%   60.7 / 62.2      ← 최대
VGCF 2   wt%   44.8 / 45.9
VGCF 4   wt%   51.7 / 52.5
```

**1 wt% 가 4 wt% 보다 높고, 계열 자체가 비단조**다.
⇒ *"VGCF 이득 과소평가"* 는 **사전 가설일 수는 있어도 판정이 아니다**.  고-VGCF 가 SE 접촉을
치환하며 좁은 patch 에 더 큰 전류를 실으면 오히려 **과대평가**가 된다.

### Q3-3 — 현재 상태로는 계약조차 미완성

`--ang-sectors` 는 **CLI 에 없고**, STEP4 NPZ 에 **입자 중심이 없다**.

| K | 역할 |
|---|---|
| 6 | 축편향 진단용 |
| 12 (equal-area) | 최소 파일럿 |
| **{1, 12, 48}** | **권장 사다리** (불안정하면 192 추가) |

**최소값 규칙**: `K · coverage_p05 ≥ 3` — p05 가 10 % 면 `K ≥ 30`, 5 % 면 `K ≥ 60`.

비용 (1,498 입자 · Nr=20):

```
방사 상태 수   K=12 ≈ 0.36 M   K=48 ≈ 1.44 M   K=192 ≈ 5.75 M
로컬 방사부    K=1  1.84 ms·step   K=12 24.1   K=48 113.7      (거의 선형)
```

⚠ 전체 Newton/BV 비용은 **별도 파일럿**이 필요하다.
⚠⚠ **섹터별 독립 radial column 만 만들면 접선방향 확산이 0 인 다른 극단 모델**이 된다.
생산형은 **섹터 이웃 간 확산 결합**이나 **구면조화 모드**가 필요하다.

### Q3-4 — 두께 1.56배로 오차 배율을 정할 수 없다

동일 RVE 를 z 로 반복하는 반례에서는 국소 coverage 분포가 **그대로**다.  fixed C-rate 에서
areal current 와 path length 가 함께 늘어 거시 옴 분극이 대략 `L²` 로 커질 수는 있으나,
**그것은 각도오차 자체의 배율이 아니다**.

### ⇒ 런 전 계산할 대리 지표

```
① coverage c_i 의 p05 · 중앙값 · zero fraction
② H_i = |I_i| / (F · 4πR_i² · c_i · √D_i)  의 p95 / p99
③ 전류가중 effective active area
④ angular dipole 및 유효 활성섹터 수
⑤ ①~④ 의 separator / mid / collector z-bin 대조
```

**VGCF1+PTFE1 과 VGCF4+PTFE1 endpoint** 에서 먼저 계산한 뒤 **median-risk · worst-risk** 팔을
`K = 1/12/48` 로 비교한다.

⛔ **조성 간 `q_frac_at_cutoff < 1 %p` 이고 동일 SOC 전압차 < 5 mV 일 때만** 현재 `K=1`
