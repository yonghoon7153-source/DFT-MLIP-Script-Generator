# 1. exact replay — 자가 흔들리지 않는다

## 무엇이 문제였나

요청서가 인용한 `vox 0.20 = 1.73270e-4` 와 커밋된 JSON 의 `1.73458e-4` 가 **0.108 %** 어긋났다.
제안된 수치 문턱 `δ_num = 0.04 %` 의 **2.7배**라 "재려는 신호보다 잡음이 크다" 는 상태였다.
가능한 원인은 셋이었다: ⓐ 내가 옮겨 적으며 틀림 · ⓑ 솔버가 비결정론적 · ⓒ 저장본이 낡음.

## 실행

```bash
# ⓐ 검증 — 요청서와 똑같은 명령을 다시
python3 scripts/step3_transport_resolution.py --kit kit_ps_7_3 --vox 0.25 0.2 0.15
# ⓑ 검증 — 같은 명령을 세 번, 단일 격자로 고립
for i in 1 2 3; do python3 scripts/step3_transport_resolution.py --kit kit_ps_7_3 --vox 0.2 ...; done
```

## 결과 ① — 내 인용은 옳았다 (ⓐ 기각)

```
replay A (--vox 0.25 0.2 0.15)
  0.25   1.72981e-4        ← 저장본과 정확히 같다
  0.20   1.73270e-4        ← 요청서 인용값을 정확히 재현
  0.15   1.67781e-4
```

## 결과 ② — 솔버는 **완전히 결정론적**이다 (ⓑ 기각)

같은 명령 세 번, **평균뿐 아니라 8개 origin 값이 전부 자릿수까지 동일**:

```
solo#1  mean = 0.00017327   origins = [1.72031, 1.71103, 1.74523, 1.71445,
solo#2  mean = 0.00017327                1.72546, 1.73191, 1.77601, 1.73720] e-4
solo#3  mean = 0.00017327   (세 런 전부 같은 배열)
```

⇒ **`δ_num` 의 replay 성분 = 0.000 %**.  Codex 가 제안한 0.04 % 는 **넉넉한 값**이다
(그가 근거로 든 합성 solver-method 차이 0.014 %/solve 는 다른 백엔드 간 비교였고,
같은 백엔드 재실행에는 그조차 없다).
★ 그래서 **"exact replay 가 0.04 % 를 넘으면 전체 HOLD"** 규칙은 지금 통과한다.

⇒ 미해결 항목으로 남긴다: *"08-17 이후 어느 커밋이 vox 0.20 에서만 σ_eff 를 0.108 % 옮겼나."*
(가르는 법 = 옛 커밋의 `step3_sigma.py` 로 vox 0.2 만 재실행.  환경 드리프트(scipy 판 차이)와

# 2. 각도 위험 선별 — `scripts/step4_angular_risk.py`

## 왜 필요했나

`step4_dyn.py` 는 면별 BV 를 **실제로 푼 뒤**(:1104, :1193) 그것을 입자 총전류로 합치고(:1447)
**전 구면적 4πR² 에 살포**한다(:1693).  버려지는 것은 고체확산의 `l > 0` 각도 모드다.
Codex 판정: 이 결손은 **조성 간에 상쇄되지 않지만**(CONFIRMED) **부호는 미결**(UNRESOLVED).

진짜 각도 구현(`K = 12/48`)은 방사 상태 수가 4~16배로 늘어 비싸다.  그래서 먼저
**스캐폴드 CSV 만으로, GPU 없이** "이 침대가 그 문제에 걸리는가" 를 잰다.

## 규약 대조를 먼저 통과시켰다

새 도구의 coverage 가 리포 정본과 **같은 정의**인지부터 확인했다 (다르면 옛 캠페인 수치와
비교 불가):

```
                                     AM_P            AM_S
정본 mpm_webapp_payload
  .geometric_coverage(real14)   45.9 / 70.2     47.3 / 70.8      (hertz / tabor)
신설 step4_angular_risk
  .per_particle_coverage        45.9 / 70.2     47.3 / 70.8      ← 소수 첫째 자리까지 일치
```

★ 정본은 **집계만** 내놓고 입자별 값을 버린다.  신설 도구는 같은 gap 규약으로 **입자별 값을
보존**한다 — 그게 p05·zero fraction·각도 형상을 낼 수 있는 유일한 길이다.

## ★ 세 가지 발견

### ① 최소 파일럿 `K = 12` 면 충분하다 — 48 이 아니다

사전등록 규칙 `K · c_p05 ≥ 3` 에 실측 p05 를 넣으면 **8~12** 가 나온다.
Codex 의 사다리 `K = {1, 12, 48}` 중 **12 = 최소 파일럿**이 정확히 요구치다.
⇒ 48·192 는 이 침대들에는 과잉이다.  **파일럿 비용이 예상보다 훨씬 싸다** (로컬 방사부
24.1 ms·step, K=48 의 113.7 이 아니라).

### ② 미접촉 입자가 **하나도 없다** — 최악 시나리오는 배제됐다

`zero fraction = 0.00 %` · `H 무한 = 0 개`.  "이온상에 전혀 안 닿아 각도 모델 없이는
표현 불가능한 입자" 는 두 침대 어디에도 없다.  ⇒ **가장 나쁜 실패 모드는 실현되지 않는다.**

### ③ ⚠ **두꺼울수록 나쁘다는 내 예상이 반대로 나왔다**

제가 세션 문서에 적었던 *"6mAh 두꺼운 전극에서 더 걸린다"* 는 이미 CL-73 으로 철회했는데,
**실측이 그 철회를 넘어 반대 방향을 가리킨다**: 두꺼운 킷(113 µm)은 z 기울기가 **거의 없고**
(0.592 → 0.571), 얇은 real14(28.8 µm)에만 강하다 (0.576 → 0.336).

**부분적으로는 자유표면 인공물**이다 — z 가 비주기 방향이라 맨 위 입자는 위쪽에 SE 가 없다.
자기 반경+1 µm 안에 자유면이 있는 입자를 빼고 재면:

```
real14   가장자리 입자 154/457 (34 %)   cov 중앙 0.4360   p05 0.2040
         내부       303/457            cov 중앙 0.4930   p05 0.2870
         내부만 K_required = 11   (전체 12)
```

⇒ 표면 효과가 **일부**를 설명한다 (중앙값 0.436 vs 0.493).  ⚠ 그러나 **전부는 아니다** —
가장자리는 위·아래 양쪽인데 z-bin 은 **위쪽만** 나쁘다 (collector 0.576 ≫ separator 0.336).
남은 비대칭의 기전은 **미규명**이다.

★ 얇은 침대일수록 자유면이 차지하는 몫이 크다: AM_P Ø 12 µm 기준 real14 는 두께의 **39 %**,
킷은 **11 %**.  이것이 두 침대의 차이를 상당 부분 설명한다.

⇒ **결론: 두께가 각도 위험을 키운다는 근거는 없다.**  오히려 이 데이터에서는 얇은 쪽이 나쁘다.
⚠ 다만 두 침대는 SE 씨앗 방식이 다르므로(킷 = 씨앗 채움, real14 = 실제 DEM 압밀) **두께만의
효과로 읽지 말 것**.  6 mAh 침대에서 **다시 재야 한다**.

## 이 도구가 하지 않는 것

- ⛔ **STEP4 를 대신하지 않는다.**  최종 허용 게이트는 Codex 가 등록한
  *"조성 간 `q_frac_at_cutoff` < 1 %p **이고** 동일 SOC 전압차 < 5 mV"* 이고 **실제 런이 필요**하다.
- ⛔ **`H` 절대값 인용 금지** — `I_i ∝ V_i` (균일 활용) 는 §F1 가정이다.  `H ∝ R_i/c_i` 이므로
  **순위와 분포 모양만** 강건하다.
- ⛔ **6 mAh 조성 대조는 아직 못 했다** — VGCF1+PTFE1 / VGCF4+PTFE1 endpoint 를 재려면
  그 침대의 스캐폴드가 필요한데 **리포에 없다** (`8-5` 의 미충족 입력 그대로).

⚠ **주의 하나** — 위 두 팔의 `se_scaffold.csv` 는 **서로 달라야 한다**.  VGCF 를 4 wt% 넣으면

**첨가제가 STEP2 에서 안 걸린 것**이므로 측정이 무의미하다 — 먼저 SHA 를 비교할 것.

⚠ **또 하나** — CL-71 의 RNG 공유 때문에 두 팔의 PTFE 형상도 함께 달라진다.  이 선별에서는
그것이 교락이 아니라 **생산 파이프라인의 실제 상태**이지만, 조성 효과로 해석하려면
CL-71 의 음성대조 재정의(exact replay)를 함께 걸어야 한다.

그 결과가 `K_required` 와 z 기울기를 주고, **그때 비로소 STEP4 파일럿 설계를 확정할 수 있다.**
