> 이 위키는 repo root `wiki/` 하위다 (킷 원본과 배치가 다름 — `wiki/README.md` 참조). 아래 절차의 모든 경로는 repo root 기준이다. 절대 규칙(루트 `CLAUDE.md` 맨 아래)을 지킨다.

`wiki/inbox/` 폴더의 대기 자료를 처리한다.

절차:

1. **스캔**: `wiki/inbox/` 의 파일 목록을 본다 (`README.md` 제외). 비어 있으면 "inbox 비어 있음"을 보고하고 끝낸다.
2. **미리보기**: 각 파일에 대해 제목/DOI(PDF 면)/한 줄 요약/제안 분류(논문 → `/paper`, 글·전사·저장소 → `/wiki-ingest`)를 표로 보여준다.
   PDF 는 DOI 로 `wiki/papers/` 와 대조해 **이미 있는 논문인지** 표에 적는다. SI 로 보이는 파일은 어느 본문에 붙는지 짝을 제안한다.
3. **확인**: 어떤 항목을 처리할지, 수집 목적이 무엇인지 사용자에게 **한 번에** 묻는다.
4. **처리**: 승인된 항목에 대해 `/paper` 또는 `/wiki-ingest` 절차를 그대로 수행한다.
5. **정리**: lint 까지 통과한 항목만 inbox 원본을 삭제한다 (PDF 원본은 저장소에 남기지 않는다 — digest·노트·그림만 커밋).
6. **보고**: 처리 N건 / 보류 M건 / 생성·갱신된 페이지 목록.
