# 이름과 실체가 갈린다 — 하루에 여섯 번

> 2026-09-09 하루에 **서로 독립인 여섯 자리**에서 같은 모양의 결함이 나왔다.
> 각각은 다른 사람이 다른 날 만든 다른 서브시스템인데, **실패 모양이 하나**다.
> 그래서 개별 버그로 적지 않고 **부류**로 적는다.

## 한 줄

> **이름·라벨·폴더명이 실체와 갈렸고, 갈렸다는 사실을 아무도 못 봤다.**
> 여섯 건 중 **다섯 건이 "검사가 초록인데 틀린" 상태**였다.

## 왜 하나의 부류인가

세 가지가 공통이다.

**① 실패가 조용하다.** 여섯 건 중 **다섯 건이 exit 0** 이거나 검사가 초록이었다.
1·2·6 은 아예 아무 신호도 없었고, 3 은 `usage` 세 줄만 로그에 남았다.

**② 검사기가 있는데 못 봤다 — 그리고 그 이유가 매번 다르다.**

| | 있던 검사 | 왜 못 봤나 |
|---|---|---|
| 1 | 없음 | 라벨과 실측을 대조하는 개념 자체가 없었다 |
| 2 | 수렴·ΔV·outlier 3중 게이트 | **전부 통과한다.** 무도핑 원본은 잘 수렴하고 부피도 안 변한다 |
| 3 | `convention_check.check_shell_calls()` (오늘 신설, **0 위반**) | 정규식이 경로 리터럴을 요구하는데 호출이 `python3 "$SCRIPT"` 였다 |
| 4 | selftest (음성 경로 3개 포함) | **자기 출력을 조사 문서로 세는 경로**를 시험하지 않았다 |
| 5 | lint 자신 | 정규식에 끝 경계가 없었다 |
| 6 | 러너의 "설정 균일성" 검사 | **설정**만 본다. 기하·셀은 안 본다 |

**③ 이름이 그럴듯할수록 오래 산다.** `_x010` 은 10 % 처럼 보이고, `FINAL_for_paper` 는
최종처럼 보이고, `b2o3_s2_t10ps` 는 b2o3 시드2 10 ps 처럼 보인다. **셋 다 아니었다.**

## 그래서 무엇을 바꾸나

### 채택 (오늘 코드에 들어감)

1. **계측기는 자기 출력을 먹지 않는다** — `survey_coverage.py` 가 `--json` 대상이 조사 폴더
   안이면 **거부**하고, 스캔 중 자기 출력 모양의 JSON 을 건너뛰며 **경고를 남긴다**
   (조용히 건너뛰면 4번의 재발이다). selftest 에 음성 경로 2개.
2. **확장자 대안은 긴 것부터 + 끝 경계** — `kb_wiki.PATH_RE`. `.jsonl`·`.mdx`·`.inp` 가 같이 닫힌다.
3. **`survey_coverage.py` 도크에 "이 수는 상한이다" 를 실측으로 못박음** — 2026-09-09 사고
   파일 3개 중 2개가 이미 "본" 쪽(34.3 %)에 있었다. 파일명만 스쳐도 인용으로 세기 때문이다.

### 제안 (아직 안 함 — 결정 필요)

4. **`convention_check` 에 축 하나 추가**: 지금 보는 축은 *"필수 인자가 넘어갔나"* 뿐이고,
   실제 사고의 축인 *"기본값·이름·의미가 양쪽에서 같은가"* 는 아무도 안 본다.
   구체적으로 ⓐ 변수 경유 호출(`python3 "$VAR"`)을 **미해결로 보고**(침묵 금지)
   ⓑ `choices=[…]` 를 뽑아 셸이 넘기는 리터럴과 대조 ⓒ 셸에 `set -o pipefail` 강제.
   → Codex BJ 프롬프트 Q7 로 물었다.
5. **치환 결과가 입력과 같으면 거부한다** — `substitute_compound.py` 에서 구조 해시가
   base 와 같으면 `ValueError`. 지금은 조용히 winner 가 된다.
6. **라벨이 아니라 실측값을 하류로 넘긴다** — `concentration_pct` 를 디렉터리 이름에서
   지어내지 말고 `actual_x` 를 쓴다.
7. **계산 산출물에 provenance 를 강제한다** — `fc_gapchk` 에는 아무 기록이 없었다.
   `generate_dft_inputs.py --from_traj` 는 `SNAPSHOTS_*.json` 을 쓴다(그래서 회수됐다).
   **생성기를 우회해 만든 입력은 계보가 없다.**

## 6번의 후일담 — 계보를 절반 회수했다

`fc_gapchk` 는 provenance 가 없어서 *"어느 궤적의 몇 ps 인지 모른다"* 였는데,
`CELL_PARAMETERS` 가 `db/structures/b2o3_relaxV0.xyz` 의 `Lattice=` 와 **소수 6자리까지 같아서**
**셀 정체는 확정됐다** — 마감 카드가 말한 "128원자" 챔피언 벌크 셀.
남은 미지는 **어느 궤적·몇 ps** 하나다.

⇒ **부분 회수도 회수다.** Task #29(σ 비 실행 셀 계보)에서 정한 *"실패 시 영구 unknown 고정"* 은
**전부 아니면 전무가 아니다** — 확정된 축과 미지인 축을 갈라 적는다.

## 반론 (지우지 않는다)

- **"여섯 건이 정말 한 부류인가."** 4·5 는 도구 버그고 1·2·3 은 과학 파이프라인 결함이며
  6 은 운영 실수다. 층위가 다르다는 반론이 가능하다.
  → 그래도 묶는 이유: **셋 다 "검사가 초록인데 틀렸다" 이고, 셋 다 이름을 믿어서 그랬다.**
  그리고 하루에 여섯 번 나온 것 자체가 층위보다 빈도가 문제라는 신호다.
- **"오늘 유난히 많이 본 것뿐 아닐 수 없나."** 그럴 수 있다. 오늘은 조사 4건이 동시에 돌았다.
  ⇒ 이 카드는 **"빈도가 늘었다" 를 주장하지 않는다.** *"찾으면 나온다"* 만 주장한다.
- **"제안 4가 오탐을 만들 것이다."** 만들 것이다. 실제로 오늘 역방향 스캔에서
  `--selftest` 4건이 전부 오탐이었고(세 도구가 argparse 앞에서 가로챈다), 죽은 인자 후보
  106~136건도 대부분 오탐이었다. **수를 발견으로 올리지 않는 규율**이 같이 가야 한다.
