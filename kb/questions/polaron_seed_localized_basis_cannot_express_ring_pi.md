# 국재 기저가 우리가 seed 하려는 상태를 표현하지 못한다

## 무엇을 봤나 (실측 · 2026-09-06)

probe 15잡 전부 정상종료했는데 **판정은 13/13 실패**다. 중단 규칙이 발동했다
(회신 Y Q2). phase S 는 안 열렸다.

```
S0P/eps1/Dradical/B_ring0   FAILED(회전 후 0.028 ≤ 무회전 0.000 + 0.05)
S0P/eps1/Dradical/B_ring5   FAILED(회전 후 0.395 ≤ 무회전 0.994 + 0.05)
S0P/eps1/Pcation/B_ring5    FAILED(회전 후 0.418 ≤ 무회전 0.995 + 0.05)
...
```

⚠ probe 는 `NoIter` 다. **SCF 가 없다** — 회전 직후 초기밀도만 본다.
그래서 이 실패는 "SCF 가 개입을 씻어냈다" 가 아니다. **회전 자체가 목표를 못 놓았다.**

## 왜 중요한가

이 pilot 의 질문은 *"산화된 SDCP 에서 전하가 백본 어디에 앉는가"* 이고, 방법은
**고리마다 하나씩 seed 를 넣어 그 자리에 구멍을 만들어 본 뒤 어느 것이 안정한가**
를 보는 것이다. seed 를 못 넣으면 질문의 절반(비교할 상태들)이 없어진다.

그리고 이건 문턱·인덱스처럼 고쳐서 넘어가는 종류가 아니다. **후보 집합에 그 궤도가
없다**는 것이라, 방법을 바꾸거나 질문을 바꿔야 한다. 그래서 `kb/results` 가 아니라
`kb/questions` 다.

⚠ 원고와의 관계: 이 pilot 은 원고 v6 의 **자가도핑 서술과 별개**다. 자가도핑은
Figure 2d FT-IR(실험)로 말하고 있고, DFT 로 그걸 뒷받침하려는 시도는 사전등록
금지어에 걸린다(`kb/papers/figure2e_dropin_v7_2026_09_05.md` §5-1). 이 pilot 이
막혔다고 원고가 막히지 않는다.

## 원인 — 후보 집합에 그 궤도가 없다

phase L 출력(`L_dminus.out`, 국재화 블록):

```
FOUND  -  49 strongly local MO`s
       - 270 two center bond MO`s
       -   0 significantly delocalized MO`s
```

**delocalized 가 0개다.** Pipek-Mezey 가 점유 원자가 궤도 319개를 전부
1중심 아니면 2중심으로 만들었다. 고리 전체에 퍼진 π 는 국재화 과정에서
개별 C=C π 결합으로 쪼개진다 — **국재 집합 안에 "고리 π" 라는 궤도가 없다.**

궤도 에너지가 확증한다 (같은 파일의 ORBITAL ENERGIES):

| MO | 점유 | ε (eV) | |
|---|---|---:|---|
| 394 | 2.0 | **−7.75** | 선택기가 `B_ring5` seed 로 고른 것 |
| 480 | 2.0 | **−1.03** | HOMO |
| 481 | 0.0 | −0.91 | LUMO |

**선택기가 HOMO 보다 6.7 eV 깊은 궤도를 골랐다.** 폴라론 구멍이 있을 자리가 아니다.

⇒ 무엇을 고르든 구멍이 **결합 하나**에 생긴다. 판정기는 그것을 정확히 재서
그룹 스핀 몫 0.03 을 냈다. 반대로 무회전 기준선은 **정준 HOMO**(고리 π 그대로)를
쓰므로 ring5 에 0.994 가 나온다.

**게이트가 제 일을 했다.** 정상종료 15/15 로 phase S 를 열었으면 결합 궤도에 구멍을
놓은 결과를 "폴라론 국재화" 라고 불렀을 것이다.

## 철회 — 이 진단에 이르기 전 두 번 틀렸다

- ⛔ **"알파↔베타 인덱스 불일치"** — 철회. `%loc` 이 `Operator 0` 인 것은 맞지만
  phase L 출처(`L_neutral`·`L_dminus`)가 **닫힌 껍질**이라 궤도 집합이 하나뿐이고,
  MORead 로 이중항에 넣으면 알파·베타가 같은 공간궤도에서 출발한다. 그 축은 문제가 아니다.
- ⛔ **`pil_parse_lmo_comp` docstring 의 "≤2원자라 판정이 보수적이 된다"** — 방향이 틀렸다.
  보수적인 게 아니다. 후보가 **전부** 1·2중심이라 그 지표는 2중심 결합을 **선호**한다.
  (100% 넘는 가중치 102·112·122% 가 그 신호였다 — 2중심 Mulliken 과잉계수.)

## Evidence For — 후보 집합의 문제다

- 국재화 블록이 `0 significantly delocalized` 를 **명시**한다. 추론이 아니다.
- 고른 MO 의 ε 가 HOMO 대비 −6.7 eV.
- 무회전(정준 HOMO) 은 같은 판정기로 0.994 를 받는다 — **판정기는 멀쩡하다.**
- 실패가 13/13 이다. 하나만 틀렸으면 인덱스·문턱을 의심하지만, 전건이면 설계다.

## Evidence Against — 아직 단정 못 하는 것

- ring5 가 0.994 → 0.395 로 **떨어진** 것은 "결합에 구멍이 생겼다" 만으로는 다 설명이 안 된다.
  회전이 자연 국재화를 헝클어뜨렸다는 뜻인데, 그 정도(−0.6)가 왜 그만큼인지는 안 봤다.
- 국재 MO 인덱스가 **전역 인덱스인지** 국재 창 안의 번호인지 직접 확인하지 않았다
  (319개인데 394 를 골랐으니 전역으로 **보이지만** 확인은 아니다).
- `T_CORE` 가 실제로 몇 개를 잘랐는지 안 셌다 (481 − 319 = 162 로 **추정**).

## 선택지 (하나도 아직 안 골랐다)

| | 무엇 | 대가 |
|---|---|---|
| ⓐ | **정준 frontier 궤도**를 seed 로 쓴다 | 정준은 고리 전체에 퍼져 있어 ring0 vs ring5 를 **구분해 seed 할 수 없다** — 사전등록의 질문이 성립 안 함 |
| ⓑ | 다른 국재화(Boys·IBO 등) | 어떤 국재화든 국재화다. 고리 π 를 통째로 남길 보장 없음 |
| ⓒ | 개입 방식을 바꾼다 — **constrained DFT** 나 국소 전위로 편향 | 사전등록 개정 · 새 검증 필요. 제일 무겁다 |
| ⓓ | **개입을 포기하고 무편향 결과를 보고한다** — "계가 스스로 고르는 자리" | 질문이 *"어디에 앉는가"* 로 바뀐다. 무회전이 이미 ring5 0.994 를 준다 |

⚠ ⓓ 는 싸고 정직하지만 **무회전은 `NoIter` 라 SCF 수렴 결과가 아니다.**
"초기 추측이 ring5 에 구멍을 놓는다" 이지 "수렴한 폴라론이 ring5 에 있다" 가 아니다.
ⓓ 로 가려면 그 상태를 **실제로 수렴**시켜야 한다.

## 아직 말하면 안 되는 것

- ⛔ "SDCP 폴라론이 ring5 에 국재한다" — 무회전은 초기밀도다. 수렴 결과가 아니다.
- ⛔ "방법이 backbone 상태를 못 찾는다" — 찾은 적이 없다. **찾으려고 한 적이 없다**가 맞다.
- ⛔ probe 의 0.03/0.395 를 물리량으로 인용. 그건 잘못 놓인 구멍의 몫이다.

## 결정 실험

**무회전 상태를 실제로 수렴시킨다 (probe 아님, `NoIter` 끄고 SCF).**

지금 있는 0.994 는 초기 추측이다. 그것을 수렴시키면 두 가지 중 하나가 나온다:

- **수렴 후에도 ring5 에 몰려 있다** → 계가 스스로 고르는 자리가 있다. 그러면
  선택지 ⓓ 가 성립하고, 질문을 *"어디에 앉는가"* 로 바꿔 답할 수 있다.
  이때 seed 개입은 *"다른 자리도 가능한가"* 라는 **별도 질문**으로 분리된다.
- **퍼지거나 다른 데로 간다** → ring5 0.994 는 추측의 인공물이었다는 뜻이고,
  무편향 결과조차 못 쓴다. 그러면 ⓒ(constrained DFT) 말고는 길이 없다.

비용: 잡 2개(D• · P⁺) × 환경 1. probe 와 같은 규모다.
⚠ 이 실험은 **선택지를 고르기 위한 것**이지 보고량을 내려는 것이 아니다 —
카드(아래)가 먼저 채워져야 값이 의미를 갖는다.
