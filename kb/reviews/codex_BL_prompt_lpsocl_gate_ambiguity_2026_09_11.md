# 회신 BL 요청 — LPSOCl 3×3×1 닫힘 게이트: **카드가 답을 안 준 세 갈래**

## 0. 이 프롬프트가 묻는 것

LPSOCl 3×3×1 400 ps 9런이 완주했고(2026-09-11), 마감 계약
`db/properties/lpsocl_box331_closure_conditions_2026_09_07.json`(active, 1저자 비준)의
C1–C6 게이트를 돌렸다. **아직 Ea 를 계산하지 않았다** — 그래서 지금 규칙을 정하면
봉인이 유지된다. C3 도구(`tools/ionic/arrhenius_compat.py`)를 돌리는 순간 창이 닫힌다.

⛔ **묻는 것은 "어느 답이 맞나" 가 아니라 "어떤 규칙이 정당한가" 다.**
우리는 결과가 어느 쪽으로 갈지 모르는 상태에서 규칙을 정하려 한다.

## 1. 실측 — C2 (D_inc plateau, MTO, 4창 산포 ≤ 10 %)

| 시드 | 600 K | 800 K | 1000 K |
|---|---|---|---|
| s2 | 6 % ✓ | 2 % ✓ | 2 % ✓ |
| s3 | **9 %** ✓ | 6 % ✓ | 2 % ✓ |
| s4 | **11 % ⛔** | 4 % ✓ | 3 % ✓ |

홉/이온: 600 K 15.5–15.6 · 800 K 36.6–37.6 · 1000 K 66.1–68.0 (C2b 문턱 3.0 을 크게 넘음 → C2b 통과)

`s4/T600` 의 `--scan` (MTO):

```
창:      2-50   10-50  25-100  50-150  50-200~ 100-200~
β:       0.80   0.82   0.86    0.92    0.95    0.99
c [Å²]:  3.01   3.81   5.08    4.53    3.15    0.61
m:      0.687  0.664  0.630   0.637   0.652   0.667
D_inc:  0.116  0.111  0.105   0.106   0.109   0.111
```

도구 자체 판정: `판별 불가`, |Δβ|max = 0.054 (케이지 기준 0.05 를 근소하게 초과).
11 % 는 거의 전부 첫 창(2-50, 0.116) 대 25-100(0.105)에서 나오고, 늦은 창은 0.111 로 **회복**한다.
c 는 올라갔다 **내려온다**. 도구가 적은 '진짜 sub-diffusion' 서명(c 증가 + m 감소 + β 불변)은
**셋 다 해당 없다**.

## 2. 실측 — C6 (골격 rigid), 원소별

β (ratio = 골격 MSD / Li MSD):

| cell | Cl(72) | **O(9)** | P(45) | **S(189)** | 판정 |
|---|---|---|---|---|---|
| s2/600 | 0.02 | 0.12 | 0.05 | 0.02 | rigid |
| s2/800 | 0.00 | **0.40** | 0.00 | **0.23** | **mobile** |
| s2/1000 | 0.00 | 0.03 | 0.00 | 0.02 | rigid |
| s3/600 | 0.01 | 0.01 | −0.01 | 0.00 | rigid |
| s3/800 | 0.03 | 0.21 | 0.03 | 0.06 | rigid |
| s3/1000 | 0.02 | 0.24 | 0.03 | 0.06 | rigid |
| s4/600 | −0.01 | −0.03 | 0.00 | −0.00 | rigid |
| s4/800 | 0.02 | **0.53** | 0.04 | **0.24** | **mobile** |
| s4/1000 | 0.00 | **0.40** | 0.02 | **0.20** | **mobile** |

ratio 는 전 칸 0.002–0.031 (골격이 Li 의 3 % 미만으로 움직인다).

관측 셋:
- **Cl·P 는 9/9 완전 rigid** (β ≤ 0.05).
- **O 의 온도 의존이 비단조다**: 600 K 평균 0.03 / **800 K 0.38** / 1000 K 0.22.
  800 이 1000 보다 높다 — 활성화 과정이면 있을 수 없다. 같은 온도의 시드 산포(800 K 0.21–0.53)가
  온도 전체 범위만큼 크다.
- **그런데 S(189)가 O 와 같이 움직인다** — mobile 셋에서 0.20–0.24, rigid 칸에서 ≤ 0.06.
  n=189 는 통계가 단단하다. 9개짜리 잡음이라면 S 가 따라 오를 이유가 없다.

게이트 규약: 판정 원소는 **n ≥ 8** (2–3개짜리 평균은 한 원자의 단일 사건이 β 를 지배해서).
O 는 **9개** — 문턱을 하나 넘는다. 같은 게이트가 b2o3 128→512원자에서 B(2→8)·O(3→12)가
문턱을 넘나들며 **판정 원소 집합이 바뀐** 전례가 있다(`b2o3_cell_expansion_result_2026_09_10.json`).

⏳ `--framework_com`(전역 흐름 vs 자리 재배열)은 이 프롬프트 작성 시점에 실행 중이다.

## 3. 카드가 답을 안 주는 것 — 갈래 셋

### Q1. C2·C6 은 **시드 단위**인가 **온도 단위**인가

카드 C2: *"`DINC_WINDOWS` 4창 전부에서 D_inc 상대산포 ≤ 10 %"* — 주어가 없다.
카드 C6: *"각 온도에서 비-Li 골격이 rigid"* — "각 온도" 라고 쓰여 있으나 시드가 3개인데
그중 일부만 mobile 일 때를 말하지 않는다.

**두 게이트에 독립적으로 같은 빈칸이 나타났다.** 읽기에 따라:
- 시드 단위: C2 에서 s4/600 탈락, C6 에서 800 K·1000 K 탈락 → 3점이 1점 → **전체 no_value**
- 온도 단위(시드평균): 평균이 잡음을 줄여 **더 쉽게 통과한다** ⇒ 더 관대한 읽기

⚠ 우리는 온도 단위 읽기가 **통과에 유리하다는 것을 알고 있다.** 그 상태에서 그것을 고르는 것이
정당한가? 정당하다면 무엇이 그것을 정당화하는가(예: "보고량이 시드평균 D 로 정의되므로
게이트도 같은 양에 걸어야 한다")? 아니라면 대안은?

### Q2. `s4/T600` 11 % — 무엇이 정당한 처방인가

도구는 "느린 전이면 처방은 점 제거가 아니라 **창 이동/연장**" 이라고 적는다. 그러나
창 2–50 ps 는 CLAUDE.md **전역 규약**이라 이 계에서만 바꾸면 계간 비교가 깨진다
(⚠ 다만 이 카드는 계간 Ea 비교를 `citable:no` 로 이미 제외했다).

우리가 검토한 안:
- **A** s4/T600 만 800 ps 재실행 → ⛔ optional stopping 으로 판단해 기각
- **B** 600 K 세 시드 전부 800 ps (~108 h) → 대칭이나 온도별 길이가 달라진다
- **C** 시드 s5 를 세 온도 전부 400 ps (~54 h) → 대칭 · C3 의 n=3 bootstrap 꼬리(회신 BG 지적)도
  같이 개선(정확 재표본 27 → 256). 단 "s5 추가 후 한 번만 판정" 을 못박아야 optional stopping 이 아님
- **D** Q1 을 온도 단위로 읽어 해소 (0 h)
- **E** 600 K 포기 → 2점 → C3 불성립 → **전체 no_value**

**질문**: C 가 정말 optional stopping 을 피하는가? "표본을 늘린 뒤 한 번만 판정" 이라는 선언이
편향을 실제로 제거하는가, 아니면 형식만 갖춘 것인가? 그리고 C 를 하더라도 s5 가 또 실패하면
그때는 무엇이 정당한가 — 그것도 **지금** 정해야 하는가?

### Q3. C6 의 `β_framework` 가 O(n=9)에서 **잘 정의되는가**

두 해석이 대립한다.

**해석 α (잡음)**: 비단조 온도 의존(800 > 1000), 동일 온도 시드 산포가 온도 범위만큼 큼,
ratio 3 % 미만 — β(O, n=9)는 표본 잡음이 지배하며 게이트가 의도한 양을 재지 못한다.

**해석 β (실물)**: S(n=189)가 같이 오른다. 통계가 단단한 원소가 상관되어 움직이므로
그 세 칸에는 실제 골격 이완이 있다. O 는 PS₃O 의 일부이며(2026-09-10 ICOHP 로 확인),
O 이동은 골격 무결성에 직접 관련된다.

**질문**: 이 둘을 가르는 **결정적 관측**은 무엇인가? `--framework_com`(전역 흐름 vs 자리 재배열)
외에 무엇을 봐야 하는가? 그리고 만약 α 가 맞다면, "β 가 이 원소에서 정의되지 않는다" 를
게이트 문턱 완화와 **구분해서** 기록하는 올바른 형식은?

## 4. 우리가 지키려는 것

- 결과(Ea)를 보기 **전에** 규칙을 정한다
- 문턱(δEa 0.050 eV · plateau 10 % · rigid 0.30)을 사후에 움직이지 않는다
- `HOLD`(정밀도 부족)와 `no_value`(정의 안 됨)를 **합치지 않는다** (estimand 카드 명시)
- 우리가 어느 답을 원하는지 알고 있다는 사실 자체를 방어 대상으로 삼는다
