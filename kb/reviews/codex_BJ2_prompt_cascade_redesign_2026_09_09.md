# 제1부 — **설계를 먼저 선언합니다** (그리고 지금은 못 합니다)

## 1-1. 최소 단위는 "화합물 91종" 이 아니라 **설계**입니다

카드 §1-b 다섯 칸이 채워진 것 하나가 **설계 하나**입니다.

| 칸 | 무엇 | 안 적으면 나는 사고 (전부 저희 실물) |
|---|---|---|
| `substitution_mode` | `lattice` / `separate_phase` / `additive` | **BJ NO-GO** — 별도 상 데이터로 도핑체 순위를 매길 뻔했습니다 |
| `host` | 어느 조성·구조가 모체인가 (파일 경로까지) | comp1 결과와 modelc 결과가 한 표에 섞입니다 |
| `실제_조성_농도` | 셀에 **실제로 들어간** 화학식과 도펀트 분율 | *"같은 계의 크기 차이"* 로 읽었는데 조성이 달랐습니다 (BK 1-2) |
| `보상_방식` | 전하중성을 **무엇으로** 맞추나 | *"중성 치환"* 은 셀 총전하 0 만으로 정해지지 않습니다 |
| `부모_치환_자리` | 시작 Wyckoff 자리 | **관측된 배위**를 **자리 판정**으로 착각했습니다 (BK 1-4) |

⚠ `보상_방식` 은 **"확인했다" 가 아니라 "모델 조건으로 선언했다"** 로 씁니다.
합성 평형에서 그 보상이 실제로 일어나는지는 **다른 질문**입니다.

⇒ **`cation_site` 열의 Li 라벨은 설계 축이 아니라 이름뿐입니다.**

⚠ 그리고 **237 vs 229 문제가 그대로 남아 있습니다** — 이름 기반(가짜 x 라벨 제거)은 229,

조성 기반을 쓰는 이유는 이름을 안 믿기 때문이지 더 정확하다고 확인해서가 아닙니다
(`kb/methodology/cascade_design_contract_2026_08_28.md` §1 원문).

### (b) `보상_방식` — **계약이 안 닫혀 있습니다**

`tools/doping/substitute_compound.py:365-380`:

```python
host_q = HOST_SITES[cation_site]['charge']
surplus = sum((db[c]['charge'] - host_q) * compute_substitution_count(n_units, m)
              for c, m in cations.items())        # ← 양이온만 합산
...
except RuntimeError as e:
    placement_log['li_interstitials'] = {'n': n_int, 'error': str(e)}
    # leave cell charge-imbalanced; UMA will rank it low   ← 실패해도 계속 간다
```

두 가지입니다.
- **음이온 치환이 보상식에 안 들어갑니다.** 그런데 이 배치는 `anion_site` 를
  세 갈래(`S_4a` 98 · `S_16e` 74 · `Cl_4d` 60 — 237 설계 기준)로 돌립니다.
- **삽입 실패해도 불균형 셀을 남기고 진행합니다.** *"UMA 가 알아서 낮게 준다"* 는
  주석이 붙어 있는데, 그건 계약이 아니라 기대입니다.

대조 — Nd 생성기(`tools/doping/b2o3_enumerate.py:176`)는 **계약이 닫혀 있습니다**:

```python
nLi = 2*nS + nCl + 2*nO - 5*nP - 3*nNd
if nLi < 0 or nLi > len(idx["li"]):
    raise SystemExit("⛔ 전하중성이 요구하는 Li ...")     # ← 못 맞추면 멈춘다
```

이 식으로 P→Nd 는 **Nd 당 Li +2**(−5nP 가 +5, −3nNd 가 −3)이고
O²⁻↔S²⁻ 는 **상쇄**(등가 치환)입니다. ⇒ **이 Nd 모델은 Li 공공을 만드는 도핑이 아니라
Li 를 추가하는 보상 모델입니다.** BK 에서 저희가 *"이가원자가 치환은 Li 빈자리를 바꾼다"* 를
이 계에 대고 말한 것은 방향이 반대였고, 철회했습니다.

### (c) `실제_조성_농도` — 라벨과 실측이 다릅니다

`n_units = max(1, int(round(n_fu_actual * x)))`, `n_fu_actual = 4` 이므로
x = 0.02/0.05/0.10 이 전부 1 unit 입니다. 정본 CSV **3,615행 전부 `concentration = 0.25`**
(재현: 아래 §부록). 파일명은 `int(x*1000)` 즉 **요청값**이라 `x020/x050/x100` 으로 다르게 보입니다.
2 unit 경계는 **x ≥ 0.375** 이고, 지금 식은 **x = 0 도 1 unit** 을 만듭니다.
