## F1. ⛔ 배치의 "3 농도" 축이 **존재하지 않습니다**

`_x002` · `_x005` · `_x010` 세 라벨이 **전부 실측 x = 0.25** 입니다.

```python
# tools/doping/substitute_compound.py:678
n_units = max(1, int(round(n_fu_actual * x_compound)))   # n_fu_actual = 4 (1×1×1, 4 f.u.)
# round(4×0.02)=0 · round(4×0.05)=0 · round(4×0.10)=0  → 셋 다 max(1,0) = 1
```

x ≥ 0.125 여야 2가 됩니다. 세 농도 모두 그 아래입니다. **즉사하지 않고 조용히 같은 구조를
세 번 만듭니다.** 그리고 파일명은 `int(x_compound*1000)` 즉 **요청값**으로 붙어서
`x020` / `x050` / `x100` 로 **다르게** 보입니다.

**두 경로로 독립 확인했습니다:**
- ① 세 농도로 실제 구동 후 md5 대조 → **20/20 파일이 바이트 동일**

`concentration_pct = 2.0/5.0/10.0` 을 **지어내서** unified CSV 에 넣고,

1. **§3 의 각 행에 대해 동의/부동의** — 특히 🔴 표시한 넷
2. **A/B/C 중 하나, 또는 "셋 다 아니다"** — 후자면 무엇이 빠졌는지
3. **착수 조건**: GO 라면 *"이것들이 충족되면 던져도 된다"* 를 **목록으로**.
   저희는 결과를 보기 전에 그것을 등록하겠습니다(`db/governance/decisions.json`).
4. **NO-GO 라면 무엇이 바뀌어야 다시 여쭐 수 있는지** — 저희 마감 규율상
   *"재개 조건 밖의 이유로 다시 열지 않는다"* 이므로, 조건이 목록이어야 합니다.

⛔ **다시 말씀드립니다 — 이 요청의 대상 계산은 아직 하나도 안 돌렸습니다.
GO 가 나오기 전에는 안 돌립니다.**
