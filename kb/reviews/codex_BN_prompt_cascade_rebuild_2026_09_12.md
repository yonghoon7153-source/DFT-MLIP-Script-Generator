## 1. 보고량 (estimand card §1)

> **LPSCl 아지로다이트에서 음이온 화학과 치환 자리가 Li 수송 활성화에너지(Ea)와
> 격자 강성을 어떻게 맞바꾸는가.** 순위가 아니라 **요인의 주효과**를 묻는다.

**왜 이 질문인가**: v23 의 **유일한 비오염 축**(`tier2_dopant_blocking_fraction`,
3,615/3,615 채움, 어닐 **전** 기하라 시드 문제를 안 탄다)이 화학족 간 큰 차이를 보인다 —
염화물 0.000 · 브롬화물 0.083 · 황화물 0.280 · 질화물 0.452 · **산화물 0.545** · 불화물 0.714.
그런데 우리 원고 챔피언 **b2o3 는 산화물**이고 DFT 로 B₀ 21.7 → 24.48 GPa (+12.8 %) 가
확인됐다. ⇒ **수송 프록시와 역학 이득이 상충할 가능성**이 있는데 v23 은 σ 를 한 번도
재지 않아 그것을 볼 수단이 없었다.

## 2. 재는 양 (§2)

```
D(T) = MSD(t) / 6t          자유절편 적합, 창 2–50 ps 고정
Ea   = −k · d(ln D)/d(1/T)  600 / 800 / 1000 K 3점
집계 : 600 K 는 시드 3개 → 중앙 D 로 적합, 오차막대는 3시드 산포를 Ea 로 전파
강성 : C_ij(clamped-ion 0 K) → VRH
참조 : host(무도핑)를 **동일 셀·동일 프로토콜·동일 시드 집합**으로
```

## 3. 설계 선언 (§1-b)

| 칸 | 값 |
|---|---|
| `substitution_mode` | `lattice` |
| `host` | `lpscl_F43m_24G_canonical.cif` (md5 `57e24e164d1b…`), **2×2×1 = 16 f.u.** |
| `실제_조성_농도` | **x = 0.0625 단일 고정** (도펀트 1 식단위/셀). 16 f.u. 에서 정수로 떨어지는 값. `max(1, round())` 없음 — 정수 아니면 **거부** |
| `보상_방식` | `compound_set` **고정** (화학식 단위 통째 치환, 전체 수지 보상). ⚠ 모델 조건의 **선언**이지 합성 평형 확인이 아니다 |
| `부모_치환_자리` | 요인 B(양이온) Li_48h / P_4b · 요인 C(음이온) Cl_4d / S_16e. 시작 Wyckoff 동결·승계 |

## 4. 요인설계

```
A 음이온 화학   브롬화물 / 황화물 / 산화물     3수준   ← v23 blocking 0.083 / 0.280 / 0.545 를 가로지름
B 양이온 자리   Li_48h / P_4b                  2수준   ← 0.250 / 0.500 (양 끝)
C 음이온 자리   Cl_4d / S_16e                  2수준   ← 0.300 / 0.545 (양 끝)
                                  3 × 2 × 2 = 12 조합
대조   host(무도핑) · b2o3(산화물 기지점 — DFT 로 물리를 아는 유일한 점)
반복   600 K 시드 3 + 800 K 1 + 1000 K 1 = 설계당 5 런
응답   Ea (수송) · 탄성 (강성)  — 상충을 보는 것이 목적이므로 둘 다
견적   설계당 40 GPU-h × 14 = 560 GPU-h ≈ 2 GPU 12일
```

⚠ **요인 수준을 v23 의 비검증 지표에서 뽑았다.** 방어: **순위 상위가 아니라 스펙트럼
양끝**을 뽑았고, v23 이 **가장 나쁘게 준 족(산화물)을 일부러 포함**했다. 응답변수(Ea·탄성)는
v23 과 독립이다. **이것이 충분한 방어인지가 Q3 이다.**

## 5. 게이트 — 결과 보기 전에 정한다

- **구조**: PS₄ 배위 = 4 (어닐 후·MD 후) · |P| < 0.5 GPa (전압력, `include_ideal_gas=True`) ·
  V/atom 이 host UMA 평형 대비 |dv| < 0.15
- **수송**: MSD log-log 기울기 0.9~1.1 · 아레니우스 3점 R² ≥ 0.95 ·
  600 K 3시드 D 의 RSD 를 **판정바닥**으로 보고
- **탄성**: B>0 · G>0 · 0<ν<0.5 · 0.2<G/B<1.0 ·
  **정본 일치 게이트** `|B_VRH/B₀ − 1| > 0.20` 이면 그 설계는 **탄성 미판정**
  (v23 에서 52 % 가 30 % 넘게 어긋났다)
- **대칭**: host 와 도핑계가 같은 셀·프로토콜·시드 집합인지 코드가 검사하고 **아니면 시작하지 않는다**
- 🔴 **음성 fixture 필수**: 각 게이트에 틀린 입력을 넣어 **실제로 울리는 것**을 selftest 로 증명.
  v23 은 `eos_fit_quality_ok` 가 622/622 통과했다 — **안 우는 게이트는 게이트가 아니다.**
- **깔때기 없음**: 12 조합 전수. 게이트 탈락은 선별이 아니라 **무효 판정**('나쁨'이 아니라 '미판정')

## 6. 닫힘 조건 — 데이터 보기 전에 박는다

1. 12 조합 + 대조 2 에 Ea·탄성이 게이트를 통과한 채로 채워질 것
2. 요인 A 의 주효과가 판정바닥 **위인지 아래인지** 확정될 것 — 어느 쪽이든 닫는다(**'효과 없음'도 결과**)
3. 수송–강성 상충 가설이 지지되거나 반증될 것

재개 조건은 셋뿐: 셀 크기 수렴 확인 · host 조성 변경 · 계면으로 확장.

## 7. 🔴 우리가 스스로 못 푼 문제 — 여기가 가장 중요하다

**host 의 UMA 평형이 DFT 와 34 % 다르다.**

```
lpscl_F43m_24G_canonical.cif    DFT V/atom = 20.71
같은 파일을 UMA 로 완화          V/atom = 27.70   (+33.8 %, P = +0.004 GPa, 수렴)
```
(2026-09-12 실측. `eos_V0_per_atom` CSV 중앙 20.23 과도 어긋난다.
preflight 은 이를 *"Wang 2025 sulfide PES softening, 25–35 %, known UMA bias, NOT a
structure defect"* 로 보고 허용범위를 5 % → 35 % 로 넓혔다 — 실측 33.8 % 가 그 천장 아래 3 % 여유로 통과.)

**왜 치명적일 수 있나**: 아지로다이트 Li 확산은 **자유부피에 강하게 의존**한다.
셀이 34 % 크면 Ea 가 계통적으로 낮게 나올 수 있다. 비(ratio)에서 공통편향이 상쇄된다는
주장은 **가정이지 검증이 아니다** (T13 이 "편향은 계마다 다르다"를 실측했다).

**선택지 셋 — 어느 것이 맞는지 우리는 모른다:**

| | 무엇 | 대가 |
|---|---|---|
| ① | **UMA 평형 셀**에서 NPT/NVT — MLIP 자기일관 | Ea 절대값이 자유부피 과잉으로 왜곡. 비만 말할 수 있음 |
| ② | **DFT 부피 고정** NVT (20.71 Å³/atom) — 실험/DFT 밀도 | UMA 가 그 부피에서 큰 양압을 볼 것이고, 힘이 평형에서 멀어짐 |
| ③ | 둘 다 돌려 **민감도**를 보고한다 | 비용 2배 (560 → 1,120 GPU-h) |
