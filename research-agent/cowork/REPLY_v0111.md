## 1. ⓑ `kind: transient` — 전달 전용

| kind | 뜻 | repo 검증 | `--from` 검증 |
|---|---|---|---|
| `code` | repo 에 그대로 들어간다 | 존재+해시 | 존재+해시 |
| `doc` | repo 에 들어가는 문서 (`cowork/REPLY_*.md`) | 존재+해시 | 존재+해시 |
| **`transient`** | **전달 전용** — `CHANGELOG_<ver>.md` 조각 · `MANIFEST_<ver>.md` | **`skip`** | 존재+해시 |

`--transient` 로 지정하고 매니페스트 자신은 자동 분류됩니다.
repo 에서 돌리면 이렇게 나옵니다:

```
skip      [transient] CHANGELOG_0.1.11.md  (전달 전용 — repo 에는 없는 것이 정상)
...
7/8 일치 (repo) · transient 1건 건너뜀 — `--from <묶음>` 으로 돌리면 이것도 검사한다
```

건너뛴 것을 **숨기지 않고 세어서 보여주고**, 어떻게 하면 검사되는지도 같이 적었습니다.
조용히 빼면 "왜 8개인데 7개만 봤지" 가 남습니다.

## 2. ⓐ `--from <묶음>` — 복사 **전에** 확인

```bash
python scripts/make_manifest.py --verify MANIFEST_0.1.11.md --from .   # 묶음에서
python scripts/make_manifest.py --verify MANIFEST_0.1.11.md            # 병합 후 repo 에서
```

묶음은 평면이라 **basename 으로** 대조합니다. 지적하신 대로 v0.1.10 은 `ROOT` 를
스크립트 위치에서 유도해 **이미 복사한 뒤에만** 작동했습니다 — 정작 쓰고 싶은 자리에서
못 쓰는 도구였고, 그게 §2 후반부 지적의 핵심이라고 봅니다.

`tests/test_manifest.py` 신규 9건. 그중 제일 중요한 것:

```python

    """★ v0.1.10 회귀 — 멀쩡한 전달에서 ⛔ 가 뜨면 안 된다."""
```

**뮤테이션 확인**: `elif kind == "transient":` 를 `elif False:` 로 되돌리면
그 시험이 실패합니다. v0.1.10 상태를 정확히 재현합니다.

## 5. n-시리즈 — 도핑 농도 지적, 프로필에 넣을까요

> *"이 올리고머는 사슬당 구멍 하나라 도핑 농도가 `1/n`. n=3 은 33 %(목표 25–35 % 안),
>  n=6 은 17 %(구간 아래). 공액 길이로는 실물에 가까워지는데 도핑 농도로는 멀어진다.
>  '고정된 구멍 수에서의 사슬길이 의존성' 으로 한정할 생각"*

이건 제가 판단할 자리가 아니지만, **한정 문구를 미리 정해 둔 것**이 축 B 의 다른 규율
(보고량을 계산 전에 정의한다)과 같은 형태로 보입니다.

두 가지만 알려 주시면 프로필에 반영하겠습니다:
1. **n-시리즈를 선점 경보 대상에 올릴까요?** 올린다면 어떤 주제어로
   (예: "전도성 고분자 올리고머 사슬길이–π 국재", "도핑 농도 고정 하 공액 길이 의존성").
2. **`1/n` 한정 조건**을 프로필의 "인용 금지 규약" 옆에 적어 둘까요?
   그러면 앞으로 클라우드가 그 주제 논문을 분석할 때 *"이 논문은 도핑 농도를 고정했는가,
   사슬길이와 섞이지 않았는가"* 를 비판 포인트로 자동으로 봅니다.

폴라론 하향은 이미 반영돼 있고(v0.1.10), *"긴급도는 항상 로컬이 정한다"* 도
주제별 예외가 아니라 **기본 규칙**으로 올려 뒀습니다.
