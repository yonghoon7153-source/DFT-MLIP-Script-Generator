## 0. 이 digest 를 읽는 법

이 논문이 던지는 질문은 딱 하나다 — **"신경망 힘장(NNFF)의 불확실도를, committee(초기값만 다른 모델 여러 개) 말고 더 좋은 방법으로 잴 수 있나?"**

문헌에서 NNFF 불확실도는 거의 항상 committee 다. 이유는 성능이 좋아서가 아니라 **구현이 제일 쉬워서**다(저자들이 초록에서 그렇게 쓴다). 그래서 이 논문은 더 원리적인 후보인 **deep ensemble**(모델이 스스로 분산을 출력하는 다중 헤드 + heteroscedastic loss)을 NNFF 에 맞게 일반화해서 구현하고, 셋(committee / bootstrap-aggregation / deep ensemble)을 같은 코드·같은 데이터로 맞붙인다.

**답은 저자들 자신에게 불리하다.** 새로 만든 deep ensemble 은 "같은 양(에너지 또는 힘)을 잴 때는" committee 대비 **체계적 이점이 없다**. deep ensemble 이 이기는 경우는 **학습 데이터의 품질이 불균질할 때 하나뿐**이다. 이 정직한 음성 결과가 이 논문의 실제 가치이고, 우리에게도 그게 소득이다.

> ⚠ **용어 주의 — 이 논문의 "aleatoric" 은 진짜 aleatoric 이 아니다.** 저자들이 §II D 에서 직접 못 박는다: DFT 학습 데이터에는 원래 잡음이 없으므로 *"엄밀히 말해 모든 기여는 epistemic 이다"*. 일부러 품질을 섞은 실험(§5.5)만 예외다. 그러니 이 논문을 근거로 *"deep ensemble 이 aleatoric 을 분리해 준다"* 고 쓰면 **원문보다 세게 말하는 것**이다.

> ⚠ **두 계는 역할이 다르다.** EAN(이온성 액체) = *MD 가 망가지는 것을 잡아내는가* 시험. SrTiO₃ = *새 상(표면 재구성)으로 모델을 능동학습으로 넓힐 수 있는가* 시험. 숫자를 한 표에 섞지 않는다.

## 1. 한 줄 요약

NNFF 에 **다중 헤드 + heteroscedastic loss** 로 deep ensemble 을 일반화해 에너지·**힘 각각의** 불확실도를 내게 만들었지만, **같은 양을 잴 때 단순 committee 를 체계적으로 이기지 못했다**; deep ensemble 의 유일한 승리는 **학습셋 품질이 섞였을 때 그것을 골라내는 능력**이고, 실용적 진짜 소득은 **ResNet 코어 + 학습된 최적화기 VeLO 로 학습을 10–20× 가속**해 능동학습 고리를 현실화한 것이다.

## 5. 결과 — 섹션별 상세

### 5.1 아키텍처: NeuralIL → ResNet 코어 (`Fig. 1`, `Fig. 2`)

- 입력: **2세대 spherical Bessel 서술자**(원자중심, 회전·병진 불변). 자유 파라미터는 컷오프 반경과 **최대 반경차수 n_max** 둘뿐.
  서술자 개수 `n_p = (n_max+1)(n_max+2) × n_el(n_el+1)/4` → **EAN(n_el=4, n_max=4) = 150**, **STO(n_el=3) = 90** (digest 계산).
- 원소 정체성은 서술자에 안 들어가므로 **n_emb 임베딩 계수**를 덧붙인다 (배포 코드: `EMBED_D = 2`).
- 코어 NN → 원자당 스칼라 **proto-energy** → 공통 학습가능 스케일·오프셋 → **원자합** = 총 퍼텐셜 에너지. 이 합이 순열 불변을 만든다(deep set / set pooling).
  ⚠ 저자 경고: **proto-energy 를 물리적 원자에너지로 읽으면 안 된다** — 같은 데이터로 두 번 학습하면 총에너지는 거의 같은데 원자별 에너지는 약한 상관만 보인다.
- **MLP → ResNet 교체 이유**(§II A): 개선된 MLP 조차 *"5–10개 앙상블에서 평균 1개꼴로 비정상적으로 큰 오차를 내는 outlier 가 나온다"*. 즉 **ResNet 도입의 1차 동기는 정확도가 아니라 앙상블 학습의 안정성**이다. BatchNorm 대신 **LayerNorm**(도함수 계산 방해 회피).
- **Morse 쌍퍼텐셜 옵션**: 원소별 A·B·D 를 SoftPlus 로 양수 구속 + **Kong 혼합규칙**, bump 함수 기반 완전 매끄러운 컷오프, switching 반경도 학습가능(0.5 r_cut ~ r_cut). **SrTiO₃ 에만 사용**. 목적은 학습셋에 없는 **아주 짧은 원자간 거리**에서 MD 가 폭주하는 것을 막는 것.
- **구현**: JAX(JIT + 자동미분) + FLAX. **힘 전체를 에너지의 VJP 한 번으로** 얻는다. MD 는 **JAX-MD**.

> 📌 배포 코드에서 읽은 실제 초매개변수 (**논문 본문에 없다**): `R_CUT = 3.5 Å`, `N_MAX = 4`, `EMBED_D = 2`, feature-extractor ResNet 폭 `[64, 32, 16]`, head 폭 `[16]`, `N_ENSEMBLE = 10`, `N_EPOCHS = 51`, `N_BATCH = 8`, `TRAINING_FRACTION = 0.9`, `run_seed = 31337`.

### 5.2 Heteroscedastic 확장 — 헤드가 셋인 이유 (`Fig. 2`)

코어를 **feature extractor + 헤드**로 쪼개고 헤드를 3개 단다 (각각 `ResNetIdentity(16)`):

1. **에너지 헤드** → proto-energy → 원자합 → E_pot
2. **σ²_E 헤드** → 스케일·오프셋 → **SoftPlus**(비음수 보장) → **원자합** → 총에너지 분산
3. **σ²_f 헤드** → 스케일·오프셋 → SoftPlus → **원자합 안 함** → 원자별 **등방** 힘 분산

- σ²_E 를 원자합으로 만드는 것은 **순열 불변을 얻기 위한 장치**이지, 원자별 에너지분산으로 읽으라는 뜻이 아니다 (저자가 명시).
- σ²_f 가 **자기 원자 서술자만의 함수**라서 생기는 제약: **단거리**다. 등방 가정도 함께 들어간다. 저자들은 "그래도 점가중치를 뽑기엔 충분히 유연하다"고 방어한다.
- 왜 σ_f 를 σ_E 에서 미분해 얻지 않나 → **Appendix (§8)**. 이게 이 논문의 이론적 핵심이다.

### 5.3 손실함수 (Eq. 2, Eq. 3)

- **Homoscedastic (Eq. 2)**: 힘·에너지 각각 **log-cosh**. 척도는 힘 0.2 eV Å⁻¹, 에너지 0.02 eV atom⁻¹. log-cosh 는 2차↔1차를 매끄럽게 잇기 때문에 **outlier 가중치를 줄이고 gradient clipping 역할**을 한다.
  ★ 저자 주장: **에너지/힘 상대가중치를 넓은 범위에서 바꿔도 결과가 거의 안 변한다 → 튜닝 불필요**. 힘만으로도 학습이 되고(선행연구), 에너지항의 역할은 주로 **에너지 원점을 맞춰 주는 것**.
- **Heteroscedastic (Eq. 3, 하이브리드)**:
  - 에너지항 = **Gaussian 음의 로그가능도** `½(ΔE)²/σ²_E + log σ²_E`
  - 힘항 = **hyperbolic secant 분포**의 음의 로그가능도 (초과첨도 2 인 super-Gaussian) = gradient-clipped 판
  - 왜 다르게? 원자에너지가 leptokurtic 이어도 **총에너지는 중심극한정리로 Gaussian 에 가깝기** 때문.
  - `log σ²` 항이 있어서 "전부 불확실하다"로 도망갈 수 없다 — **정확도와 불확실도가 균형을 잡아야 손실이 최소**가 된다.
- **최적화기 VeLO**: SGD 계열이 아니라 **학습된(learned) 비선형 최적화기**. 진화 알고리즘으로 MLP/ResNet/CNN/transformer/autoencoder 에 걸쳐 메타학습된 ML 모델 자체다. **학습률 선택이 필요 없고, 유일한 파라미터가 총 epoch 수**다. OPTAX 로 통합.

### 5.4 세 추정기의 수식 (Eq. 4–6)

| 추정기 | 평균 | 분산 |
|---|---|---|
| **HOS** (committee·bootstrap) | 단순평균 (4a) | `σ²_E,HOS = Σ(E_i−⟨E⟩)²/[N(N−1)]` (4b) — **표본평균의 분산** |
| **HES** (deep ensemble, 분산헤드 결합) | **역분산 가중평균** (5a) | `σ²_E,HES = (Σ 1/σ²_E,i)⁻¹` (5b) — 역시 평균의 분산 |
| **DE** (원조 deep-ensemble 처방, Eq. 6) | 일관성 위해 (4a) 사용 | `σ²_E,DE = N·σ²_E,HOS`(epistemic) `+ N⁻¹Σσ²_E,i`(aleatoric) — **모집단 분산** |

- ⚠ **σ_DE 는 다른 둘보다 약 √N 배 크다.** 정의가 다르기 때문(모집단 분산 vs 표본평균의 분산)이고, 직접 비교할 때는 **σ_DE/√N_ensemble** 로 스케일한다.
- **bootstrap 구성**: 10회 반복 — 전체의 **75 % 를 복원추출**로 뽑고, 그 풀의 **50 % 학습 / 50 % 검증**. 사실상 **10번 따로 학습**하는 비용.
- **committee 구성**: 전원 같은 데이터, **초기값만 다름**. FLAX 모델 하나에 **앙상블 차원 하나를 더한 텐서**로 구현 → **단일 실행으로 10개를 학습**. 추론 오버헤드는 거의 0 (제일 비싼 서술자·VJP 계산이 1회뿐).
  ⚠ 저자 자백: 그 최적화 때문에 **미니배치 분할까지 전 멤버가 동일** → **다양성이 미묘하게 줄어든다**.

### 5.5 EAN MD 를 따라간 불확실도 (`Fig. 4`, `Fig. 5`)

- 설정: 단일 NNFF 로 **12개 NVT 궤적**, **T = 298 K**, **80 ps**, **Δt = 1 fs**, **Nosé–Hoover chain 길이 5, 시간상수 100 스텝**. 초기 구조는 전부 동일(학습셋 스냅샷), **속도만 Maxwell–Boltzmann 으로 다르게** 뽑았다 → **순수한 시드 산포 실험**이다.
- 12개 중 성격이 다른 **4개**를 골라 제시.
  - 궤적 1: 양이온 H 배치 이상 → 국소 결합 파괴가 점점 번짐
  - 궤적 2: 양이온 둘이 상호작용 → **C–N 결합의 인위적 해리**가 연쇄적으로 다른 이온까지 붕괴 (`Fig. 5` 스냅샷)
  - 궤적 3, 4: 무난. 양이온→음이온 **H 하나 이동**뿐 — 양성자성 이온성 액체에서 물리적으로 타당하지만 **학습셋에 없는 사건**
- `Fig. 4` 실제 판독 (내가 본 것):
  - 파국 궤적 2 에서 committee σ_E 가 **~25 ps 에 계단**으로 0 → figure-read ≈ 11 eV, σ_f 는 ≈ 0.05 → 0.55 eV Å⁻¹ 로 점프한 뒤 평탄.
  - 무난한 궤적은 단조 증가만 (committee σ_f 끝값 figure-read ≈ 0.1–0.2 eV Å⁻¹).
  - ★ **committee 는 t=0 에서 σ≈0 에서 출발**하는데, **HES/DE 는 0 이 아닌 바닥**에서 출발한다 (DE σ_E figure-read ≈ 2 eV, HES σ_f ≈ 0.22 eV Å⁻¹). ⇒ **committee 의 동적 범위(0→11 eV)가 훨씬 크다** = 정상/파국 대비가 더 선명하다.
- 저자 결론: **모든 지표가 파국을 잡아낸다. deep ensemble 의 명확한 이점은 없다.** 그리고 *"힘이 총에너지보다 정보가 많듯이, **힘의 불확실도가 에너지의 불확실도보다 더 유용하고 더 얌전하다**"*.
- **문헌의 대안 지표 기각**: 프레임 내 **원자별 힘 불확실도의 최댓값**(Ref. 78)은 ① 최댓값이 합·평균보다 훨씬 덜 robust ② 원자 하나의 힘은 MD 결론에 거의 영향이 없다 ③ 힘 하나 틀린다고 시뮬레이션이 망가진다는 보장이 없다. **softmax·90 백분위수 변형도 시험했으나 전역 지표를 이긴 사례가 없었다.**

### 5.6 재학습으로 MD 를 고친다 (`Fig. 6`, `Fig. 7`)

- 4개 궤적의 **고불확실도 구간**을 구획하고 **등간격 125점 × 4 = 500 스냅샷**을 같은 DFT 설정으로 계산해 학습셋에 추가 → 재학습 → **같은 초기조건에서 재실행**.
- `Fig. 6`: 비물리적 사건이 전부 사라지고, **모든 불확실도 지표가 시작값 근처에서 평탄**해진다. (수치는 §3.4 표)
- ★ 내가 `Fig. 6` 에서 본 것 중 논문이 언급 안 한 것: **DE 의 σ_E 는 네 궤적 모두에서 완전한 수평 직선**(figure-read ≈ 1.05 eV)이다. 모델이 좋아지자 epistemic 항이 사라지고 **aleatoric 바닥만 남아 구성 의존성을 잃었다**. 반면 committee σ_E 는 여전히 요동친다. ⇒ **모델이 잘 학습된 영역에서는 DE 의 에너지 불확실도가 정보를 잃는다.**
- `Fig. 7` — **단일 자유도 스캔**(음이온의 N–O 결합 신축). x = d_N–O 1.03–1.70 Å, y = û_N–O·(f_N − f_O), −20 ~ +60 eV Å⁻¹. 아래 서브패널에 **학습셋의 해당 거리 빈도밀도 g_training** 과 최소·최대 점선.
  - **위(원래 데이터)**: 학습 범위 점선 figure-read ≈ **1.20 – 1.41 Å**, 분포 피크 ≈ 1.28 Å. 학습 범위 안에서는 세 모델 모두 DFT 와 겹친다.
    🔴 **범위 밖에서는 전부 크게 빗나간다**: d = 1.03 Å 에서 DFT figure-read ≈ **+56** eV Å⁻¹ 인데 committee ≈ **+28**, HES/DE ≈ **+16**. 그런데 **불확실도 띠 반폭은 figure-read ≈ ±4–6 eV Å⁻¹ 에 불과**해서 **40 eV Å⁻¹ 짜리 오차를 전혀 감싸지 못한다.**
  - **아래(500점 보강 후)**: 학습 범위 점선이 **1.04 – 1.43 Å 로 넓어졌다**. **committee 가 DFT 곡선을 거의 완전히 덮는다**(1.04 Å 에서 ≈ +56 로 일치). HES ≈ +30, DE ≈ +38 로 여전히 낮다.
  - ★ **그런데 여기서 deep ensemble 이 유일하게 이긴다**: 짧은 d 쪽 데이터는 여전히 희소한데(원 데이터는 1.28 Å 중심) **그 희소성을 띠 폭으로 드러내는 것은 deep ensemble 뿐**이고 committee 띠는 거의 사라진다(과신). 논문 문장 *"The increased uncertainty is, however, only reflected in the deep ensembles"* 를 그림이 뒷받침한다.
  - 긴 거리(1.55–1.70 Å)에서는 세 모델 모두 DFT(≈ −6)보다 아래(≈ −12 ~ −17)로 벌어지고 **DE 띠가 제일 넓다**(figure-read ≈ −10 ~ −25).

### 5.7 aleatoric 판별 — deep ensemble 의 유일한 승리 (`Fig. 8`)

- 합성 실험: 741 구조 중 **에너지가 높은 상위 10 %** 의 에너지·힘을 **EAN-FD(저품질)** 값으로 교체. 에너지 원점은 평균을 맞춰 제거. 에너지를 섞기 기준으로 삼은 이유는 *"서술자로 특징지을 수 있게 하려고"* 인 인위적 선택이라고 저자가 밝힌다.
- 저품질 정도: **그 데이터만으로 학습한 FF 의 학습셋 힘 MAE 가 400 eV Å⁻¹** (원문 표기 그대로 — **§10-A 의 단위 오류 의심 대상**).
- `Fig. 8` 실제 판독:
  - **위(σ_E,DE / eV)**: LCAO 상자 ≈ 8.1–8.4(중앙값 ≈ 8.2), FD 상자 ≈ **9.3–12.0**(중앙값 ≈ 9.8), FD 수염이 15.7 까지 + 이상치 16–18.
    🔴 **두 분포가 겹친다** — LCAO 수염 상단 ≈ 8.9–9.0, FD 수염 하단 ≈ 8.7.
  - **아래(√(n⁻¹Σσ²_f,DE) / eV Å⁻¹)**: LCAO 상자 ≈ **0.9–1.1**, FD 상자 ≈ **2.8–4.05**(중앙값 ≈ 3.15). **상자끼리 겹침 없음**.
  - ⇒ **"높은 판별력"은 사실상 힘 채널의 성과다.** 에너지 채널은 중앙값이 8.2 → 9.8 로 ~20 % 이동에 그치고 분포가 겹친다. 논문의 *"dramatically different distributions"* 는 힘에만 해당한다.

### 5.8 SrTiO₃ bulk 퍼텐셜과 불확실도–오차 상관 (`Fig. 9`)

- `Fig. 9` 판독: x = n⁻¹Σσ²_f, y = n⁻¹Σ‖f_DFT−⟨f_NN⟩‖² (둘 다 eV² Å⁻², 로그–로그). 점선 = 각 양의 75·90 백분위수.
  - 두 방법 모두 **단조 상승 추세가 뚜렷**(Spearman 0.90 / 0.91).
  - ★ **bootstrap 구름이 committee 구름보다 x 축에서 통째로 오른쪽으로 밀려 있다** (백분위수 점선: committee figure-read ≈ 1.8·10⁻³ / 3·10⁻³ vs bootstrap ≈ 4.5·10⁻³ / 8·10⁻³ — **약 2.5×**). 같은 오차에 대해 **bootstrap 이 더 큰 불확실도를 보고**한다. 논문은 이걸 *"절댓값이 다르다"* 한 줄로 넘기는데, **절대 보정(calibration)이 방법마다 다르다**는 실무적으로 중요한 사실이다.
  - 고불확실도 쪽(≈1–5 eV² Å⁻²)에 **오차는 중간(0.15–0.6)인데 불확실도만 큰 점 몇 개** = 과경고. 정반대(오차 큰데 불확실도 작음)는 거의 없다 → **보수적으로 틀린다**(안전한 방향).
- 결론: 랜덤성의 원천이 더 적은 committee 가 bootstrap 과 **동률**이므로, **계산비용·확장성 때문에 committee 채택**.

### 5.9 bulk 퍼텐셜을 표면에 던지면 (`Fig. 10`, `Fig. 11`, `Fig. 12`)

- 예상대로 나쁘다. **자유표면 근처 원자에서 오차·불확실도가 자릿수 단위로 커진다**.
- `Fig. 10` 판독 (split violin, x = 10⁻⁸ ~ 10⁶ eV² Å⁻², 위=오차 / 아래=불확실도, 층별 7행, 파랑 bulk / 주황 AL₁ / 보라 AL₂):
  - 최상층: bulk 오차 피크 **figure-read ≈ 10¹**, AL₁ ≈ 10⁻¹, AL₂ ≈ 10⁻² ⇒ **약 3 자릿수 개선**.
  - 중심층으로 갈수록 전부 왼쪽(작은 값)으로 이동, 최하단(중앙) 층은 ≈ 10⁻⁴ 근처의 넓은 단일 분포.
  - **표면–중심 사이에 오차가 대략 6 자릿수 퍼져 있다.**
  - ★ 이런 **공간분해 분석은 힘에 의존하기 때문에 가능하다** — 총에너지 하나로는 못 한다 (저자 강조).
- `Fig. 11` 판독 (c = 0–10 Å 범위의 상부 5개 층, 왼쪽 Error / 오른쪽 Uncertainty, 컬러바 ~0.2–0.8+):
  - 🔴 **밝은(문제) 원자의 위치가 두 패널에서 다르다.** 오차 쪽 최악은 c ≈ 8.3 Å 행의 원자 2개와 c ≈ 6.1 Å 의 1개; 불확실도 쪽 최악은 **최상행 c ≈ 9 Å** 원자들 + c ≈ 6.1 Å 하나. **부분적으로만 겹친다.**
  - 저자 해석 그대로: **불확실도의 오차 예측력은 원자 집합의 크기가 커질수록 좋아진다** — 층 단위에서는 쓸 만하지만 **개별 원자에서는 못 쓴다**. 이유는 구조적이다: 원자 i 의 **에너지 기여는 자기 서술자만의 함수**지만 **힘은 이웃 전체의 서술자에 의존**한다 ⇒ 이웃이 불확실한 원자도 고오차 후보다.
  - ⇒ **"드물게 나오는 국소환경만 찾아 넣으면 된다"는 전략은 새 상(4×1 재구성)에는 불충분하다.**
- `Fig. 12` 판독 (parity, 두 축 모두 E_pot / eV, −7.0 ~ −4.5):
  - **bulk-only(파랑)**: 상관이 나쁘고 **위쪽으로 통째로 치우쳐 있다**(true −6.5 인데 predicted ≈ −5.4). 저자는 이를 *"DFT 와 FF 의 **에너지 원점 불일치**"* 로 해석. (→ 내가 배포 데이터로 이 해석을 **정량적으로 뒷받침**했다, §12-⑦⑧)
  - **AL₁(주황)**: 구름이 훨씬 길쭉해지고 offset 이 거의 사라진다. 다만 **가장 안정한(가장 왼쪽) 구조들이 여전히 제일 나쁘다** — 표면 재구성이 바닥상태를 결정하므로 이건 표면층 탓.
  - **AL₂(보라)**: parity 선에 더 붙는다. 특히 어려운 구조에서 개선.

### 5.10 적대적 능동학습 (adversarial AL)

- **적대적 손실** (Eq. 7): `L_adv = σ²_f · exp(−E_pot / k_B T)`, **T = 500 K**.
  → *"모르면서 물리적으로 그럴듯한"* 영역을 고른다. σ²_f 가 탐색(모르는 곳)을, Boltzmann 인자가 활용(에너지가 낮은 곳)을 담당한다.
- 절차: 정해진 시작 구조 → **각 원자에 σ = 0.1 Å Gaussian 변위** → **log L_adv 를 Powell 켤레방향법으로 수치 최대화** → 100개 생성 → DFT → 재학습(AL₁) → 2회차 100개 (AL₂).
- 🔴 **2회차의 교훈**: **같은 단일 구조에서 다시 출발하면 수확체감**. 대신 **1회차의 100개 중 하나를 무작위로 골라 출발점으로 삼으면** 또 한 번 큰 개선이 나온다 (`Fig. 10` 보라 violin).
  이유: test 데이터가 **CMA-ES 진화탐색**에서 왔고, 그 탐색의 본질은 **하나의 국소최소 주변에 머무르지 않는 것**이다. 반면 적대적 손실 최적화는 **국소적**이다. ⇒ **국소 AL 과 전역 구조탐색의 구조적 불일치.**
- ★ 또 하나: **AL 진행에 따라 committee 불확실도가 실제 오차보다 더 많이 줄어든다.** ⇒ **불확실도는 "같은 퍼텐셜 안에서 점들을 비교"할 때 유효하고, "서로 다른 퍼텐셜을 비교"하는 데는 덜 믿을 만하다.**

## 6. 전체 논증 흐름

1. NNFF 불확실도는 관행적으로 committee 다 — 좋아서가 아니라 쉬워서.
2. 더 원리적인 deep ensemble 을 NNFF 에 이식하려면 **힘의 분산**이 필요한데, 그건 에너지 분산의 미분으로 안 나온다 (**Appendix** 가 증명).
3. 그래서 **σ_f 전용 헤드**를 따로 단다 (등방·단거리 가정을 감수).
4. 앙상블 학습은 outlier 멤버 때문에 불안정하므로 **ResNet 코어**로 안정화하고, **VeLO** 로 10–20× 가속 → 능동학습 고리가 현실화.
5. EAN MD 에서: **모든 지표가 파국을 잡는다. deep ensemble 우위 없음.** 힘 > 에너지.
6. 고불확실도 구간 500점 보강 → **파국 소멸, 지표 평탄화** (고리 1회전 성공).
7. 품질을 섞은 합성 데이터에서만 **deep ensemble 이 판별력을 보인다** (그것도 주로 힘 채널).
8. SrTiO₃ 에서: 불확실도–오차 Spearman 0.90–0.91, **committee ≈ bootstrap** → 싼 committee 채택.
9. bulk→표면 외삽은 실패. **적대적 AL 2회전**으로 크게 개선. 단 **출발점 다양성이 없으면 수확체감**.
10. 결론: **같은 양을 잴 땐 committee 로 충분하다. deep ensemble 은 데이터 품질이 섞였을 때만 값을 한다.**

## 8. Appendix — 왜 σ_f 를 σ_E 에서 못 얻나 (이 논문의 이론적 중심)

`f_i^(α) = −∂E_pot/∂X_i^(α)` 이므로, 힘 성분들의 공분산을 정의대로 극한으로 풀면

```
cov[f_i^(α), f_j^(β)] = ( ∂² ⟨δE_pot(X) · δE_pot(Y)⟩ / ∂X_i^(α) ∂Y_j^(β) ) |_{X=Y}          … (A3)
```

즉 **한 점 X 에서의 에너지 불확실도만으로는 부족하고, 근접한 두 점 사이의 에너지 예측 공분산 ⟨δE(X)δE(Y)⟩ 이 있어야 한다.**

- Behler–Parrinello 류(그리고 일반적인 set-pooling 구조)는 **한 점 X 에 대해서만** 예측을 내도록 설계돼 있어 이 **공간 공분산 헤드를 붙일 수 없다**. 그래서 저자들은 σ_f 를 **별도 헤드로 직접 학습**시키는 우회로를 택했다.
- 저자 제안: **PADRE (pairwise difference regression)** 처럼 **두 구조를 동시에 입력받는** 구조라면 (A3) 을 직접 쓸 수 있을지도 모른다.

> 🔑 **우리에게 주는 함의**: "에너지 불확실도를 미분해서 힘 불확실도를 얻는" 지름길은 **원리적으로 없다**. 힘 불확실도가 필요하면 (ㄱ) 앙상블 멤버들의 힘 분산을 직접 재거나 (ㄴ) 전용 헤드를 학습시켜야 한다. **UMA 처럼 단일 모델을 쓰는 우리 스택에는 (ㄱ) 밖에 없다** — 즉 **멀티시드/멀티모델이 선택이 아니라 유일한 경로**다.

## 10. 비판 — 이 논문의 약한 곳 ★

**A. 단위 오류가 최소 3건 있다 (배포 데이터로 확인)**
- §III E: `RMSE = 33.6 eV atom⁻¹`, `38.18 eV atom⁻¹`. 같은 문장의 MAE 는 2.44 / 2.54 **meV** atom⁻¹ 이고, 배포 데이터의 에너지 전체 폭이 **1.06 eV/atom** 이다(digest 계산) ⇒ **RMSE 가 33.6 eV/atom 일 수 없다. meV 오식이 거의 확실.**
- §III D: EAN-FD 로만 학습한 FF 의 `force MAE = 400 eV Å⁻¹`. 배포 데이터의 **힘 평균 크기가 0.5396 eV Å⁻¹**(digest 계산)이므로, **0 을 예측해도 MAE 0.54** 다. 400 eV Å⁻¹ 는 그보다 **740배** 나쁘다 ⇒ **meV Å⁻¹ 오식 의심.**
- ⇒ **이 세 숫자는 인용하지 않는다.**

**B. 논문 본문과 배포 코드가 어긋난다 — `xtol`**
- 본문: *"...acceptable for convergence to **xtol = 100**"*. (PDF 스팬 확인 결과 위첨자가 아니라 평문 `100`.)
- 배포 코드 `examples/adversarial_powell.py`: `"xtol": **1e-1**`.
- scipy Powell 에서 xtol=100 이면 사실상 즉시 종료된다 ⇒ **실제로 돌아간 값은 0.1**. **적대적 AL 을 재현하려면 코드 쪽을 따라야 한다.**

**C. 배포 데이터의 원자수가 본문과 2배 다르다** — §12-⑥⑦ 참조. 표면 test 좌표·힘 배열은 **272 원자**인데 본문은 **136 원자**라고 쓰고, `Fig. 12` 의 축은 **136 으로 나눈 값**과 정확히 일치한다. 어느 쪽이 참인지 **배포물만으로는 못 정한다.** 재사용 전 반드시 확인해야 한다.

**D. "deep ensemble 이 aleatoric 을 잡는다"는 주장의 범위가 좁다**
- 판별력은 **힘 채널의 성과**다. 에너지 채널은 상자가 겹친다(`Fig. 8`, §5.7).
- 그리고 실험 자체가 **인위적**이다: 저품질 데이터를 **에너지 상위 10 %** 로 골라 넣었으므로 **서술자로 구분 가능하게 설계된** 문제다. 저자도 그 선택을 밝히지만, *"volume/composition 의존 품질차도 같은 우산 아래"* 라는 일반화는 **시험되지 않았다.**

**E. 불확실도 띠를 신뢰구간으로 읽으면 안 된다** — `Fig. 7` 위 패널에서 실제 오차 ≈40 eV Å⁻¹ 를 띠(±4–6)가 전혀 못 감싼다. 논문 본문은 *"a reliable proxy for error that stays at manageable levels"* 라고 쓰는데, **그림은 그보다 훨씬 약한 결론(순위는 맞지만 크기는 틀림)만 지지한다.** 이건 §III F 의 *"서로 다른 퍼텐셜 사이 비교에는 덜 믿을 만하다"* 와 같은 병이다.

**F. committee 의 다양성이 구조적으로 축소돼 있다** — 저자 자신이 밝히듯 **미니배치 분할까지 전 멤버 동일**. 그런데 그 committee 가 bootstrap 과 동률(0.90 vs 0.91)이라는 게 이 논문의 핵심 근거다. **다양성을 정상적으로 준 committee 라면 더 좋았을 수도, 반대로 bootstrap 과 더 벌어졌을 수도 있다** — 미검증.

**G. 통계적 뒷받침이 얇다** — 12개 MD 궤적 중 **4개만** 보여 주고(선택 기준 = "서로 다른 상황의 대표"), 나머지 8개의 분포는 보고되지 않는다. **오차막대·반복실행이 사실상 없다.** Spearman 0.90/0.91 도 신뢰구간이 없다.

**H. VeLO 채택의 재현성 부담** — VeLO 는 특정 `jax==0.3.21`/`jaxlib==0.3.20` 조합과 별도 저장소 설치를 요구한다(README 가 2023-02 기준으로 명시). 학습 가속의 절반이 여기서 오는데, **의존성이 굳은 외부 메타모델**이라 수년 뒤 재현이 어려울 수 있다.

## 15. 기법 용어 미니사전

| 용어 | 뜻 (이 논문 맥락) |
|---|---|
| **epistemic / aleatoric 불확실도** | 전자는 *모델이 데이터를 덜 배워서* 생기는 것(데이터를 더 주면 준다), 후자는 *데이터 자체의 잡음*(더 줘도 안 준다). ⚠ 이 논문에서는 DFT 데이터에 잡음이 없어 **원칙적으로 전부 epistemic** 이고, 일부러 품질을 섞은 실험만 예외 |
| **committee** | 같은 데이터·같은 구조로 **초기 가중치만 다르게** 여러 NN 을 학습. 랜덤성의 원천이 제일 적고, 제일 싸다 |
| **bootstrap aggregation (bagging)** | 데이터를 **복원추출**로 나눠 멤버마다 다른 학습셋을 준다. 다양성은 크지만 사실상 N 번 따로 학습 |
| **deep ensemble** | 각 멤버가 **자기 예측의 분산도 함께 출력**하고(추가 헤드), **heteroscedastic loss** 로 같이 학습. 앙상블 분산(epistemic) + 헤드 평균(aleatoric) 을 더해 총 불확실도 |
| **heteroscedastic loss** | 점마다 가중치가 다른 손실. `Δ²/σ² + log σ²` 꼴 — σ 를 키워 손실을 줄일 수도 있지만 `log σ²` 벌점 때문에 무한정 키울 수 없다 |
| **HOS / HES / DE** | 이 논문의 세 불확실도 라벨. HOS = homoscedastic 손실로 학습한 앙상블의 분산 · HES = heteroscedastic 모델의 분산 헤드들을 결합 · DE = 원조 deep-ensemble 처방(Eq. 6). **DE 는 정의상 다른 둘보다 √N 배 크다** |
| **ResNet (regression)** | 층을 건너뛰는 shortcut 을 둔 구조. 깊어져도 gradient 가 죽지 않는다. 여기서는 **정확도보다 앙상블 멤버의 학습 실패(outlier) 억제**가 도입 이유 |
| **LayerNorm vs BatchNorm** | 정규화 위치가 다름. BatchNorm 은 배치 통계를 쓰므로 **힘(=에너지 도함수) 계산을 복잡하게** 만든다 → LayerNorm 채택 |
| **VeLO** | 학습률이 필요 없는 **학습된(learned) 최적화기**. 진화 알고리즘으로 메타학습된 ML 모델이 파라미터 갱신량을 직접 계산. 유일한 하이퍼파라미터 = 총 epoch 수 |
| **Sobolev training** | 표적의 **도함수까지 손실에 넣는** 학습. NNFF 에서는 힘을 손실에 넣는 것이 이에 해당하고, 총에너지만 쓰는 것보다 정보량이 훨씬 크다 |
| **set pooling / deep set** | 원자별 기여를 **합**해 전체 값을 만드는 구조. 원자 순서(순열)에 무관해진다 |
| **적대적 능동학습 (adversarial AL)** | 모델의 **불확실도를 최대화**하되 **에너지 페널티**로 물리적 타당성을 유지하는 방향으로 구조를 밀어 새 학습점을 만든다. 여기서는 `L_adv = σ²_f·exp(−E/k_BT)` |
| **eggbox 효과** | 실공간 격자 기반 DFT 에서 **원자가 격자점 사이를 지날 때 에너지·힘이 인위적으로 진동**하는 현상. 병진대칭이 깨진다. 격자를 성기게(h=0.25 Å) 잡으면 심해진다 |
| **CMA-ES** | 공분산행렬 적응 진화전략. 전역 구조탐색용 확률적 최적화. **탐색–활용 균형을 위해 한 국소최소에 머무르지 않는 것**이 핵심 — 그래서 국소적인 적대적 AL 과 맞지 않았다 |
| **PADRE (pairwise difference regression)** | **두 구조를 동시에 입력**받는 회귀. 그래서 두 점 사이 공분산을 낼 수 있고, Appendix (A3) 를 직접 쓸 가능성이 있다 |

## 16. ⚠ 이 논문이 못 하는 것 / 내가 확인 못 한 것

**이 논문이 못 하는 것**
1. **불확실도를 보정(calibrate)하지 못한다.** σ 는 **순위**로 쓸 수 있을 뿐 **크기**가 오차를 감싸지 못한다 (`Fig. 7`, §10-E). "몇 σ 안에 참값이 있다" 는 문장을 이 논문으로 지지할 수 없다.
2. **원자 단위 진단을 못 한다** (`Fig. 11`). 층 단위까지가 한계.
3. **서로 다른 퍼텐셜 사이의 비교를 못 한다** — AL 이 돌면 σ 가 오차보다 빨리 준다 (저자 자인).
4. **deep ensemble 의 이점을 일반적으로 입증하지 못했다.** 이점이 나온 곳은 인위적으로 만든 품질혼합 데이터 하나뿐이고, 그 안에서도 **힘 채널**에 국한된다.
5. **전역 탐색을 못 한다.** 적대적 AL 은 국소 최적화라 CMA-ES 같은 전역 탐색이 도달하는 영역을 스스로 못 찾는다 — 출발점을 사람이 다양화해 줘야 했다.
6. **통계적 오차막대가 없다.** 12궤적 중 4개 제시, Spearman 에 신뢰구간 없음, 앙상블 크기(10) 의존성 미검증.
7. **재료 전이 주장이 없다.** EAN·SrTiO₃ 두 계뿐이고, **황화물 고체전해질·Li 이온 전도체에 대한 언급이 전혀 없다.**
