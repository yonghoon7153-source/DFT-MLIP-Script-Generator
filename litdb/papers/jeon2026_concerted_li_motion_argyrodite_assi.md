## 0. 이 digest를 읽는 법 — **Haven 비 묶음의 세 번째이자 유일한 "우리 골격" 계산본**

우리는 σ 를 **Nernst–Einstein, Haven 비 H_R = 1 고정**으로 낸다. 이 규율의 오차를 정량하려고 모은 3편 중 마지막이다.

| 출처 | 계 | 방법 | H_R | NE 는 | 캐리어 수 규약 |
|---|---|---|---|---|---|
| `adeli2019` | Li₆₋ₓPS₅₋ₓCl₁₊ₓ | **실험** PFG-NMR + EIS | **0.23–0.3** | 과소 | ⚠ **c = 4 Li/cell (저자 명시 하한)** |
| `zaby2026` | IL·LiFSI 액체 | 고전 MD (EH·GK) | **1.3–2.1** | 과대 | 전 이온 = 캐리어 (모호성 없음) |
| **이 논문** | **Li₆₊ₓAs₁₋ₓSiₓS₅I** | **AIMD (집단 MSD 직접)** | **1.83 (x=0) / 0.53–0.77 (x=0.25–0.75)** | **조성에 따라 뒤집힘** | **전 Li = 캐리어 (규약 자유)** |

**이 논문이 채우는 빈칸 세 가지:**
1. **argyrodite 골격에서 tracer 와 charge D 를 둘 다 *계산으로* 냈다** — `adeli2019` 는 D_σ 를 거시 σ 에서 역산했고(규약 의존), 이 논문은 **집단 MSD 를 궤적에서 직접** 잰다 → **캐리어 수 규약이 원천적으로 없다** (§4.3). 우리 UMA 궤적에 그대로 이식 가능한 유일한 정의다.
2. **H 의 부호가 조성에 따라 뒤집힌다** — 부도체급 모체(x=0)에서 H=1.83(>1), Si 치환 후(x=0.25–0.75) H=0.53–0.77(<1). *"argyrodite 의 H_R 은 1보다 작다"* 는 단일 명제가 **성립하지 않는다**.
3. **협동 이동(concerted motion)을 관측량으로 내려놓았다** — 케이지 간 점프의 **지속시간(0.03–3.40 ps)** 과 **참여 Li 수(2–6)** 를 궤적에서 직접 센다. NEB 기반 간접 증거(선행연구)를 대체하는 직접 관측이 이 논문의 자기 규정이다.

**⛔ 그러나 결론부터 — 이 논문은 우리 계의 H_R 부호를 확정해 주지 못한다.** 이유는 §10 에 다 적었지만 요약하면:
(a) H 는 **1000 K 한 점**에서만 쟀다 (조성×온도 표가 없다). (b) x=0 의 집단 MSD 는 `Fig. S14` 에서 **눈으로 봐도 포화**한다 — 확산이 아니다. (c) **오차막대가 없다** (Table S10 만 유일하게 오차 없는 표다). (d) **단일 시드·단일 셀(52–55원자)** 이다. (e) 계산한 H 를 **정작 자기 300 K σ 에 반영하지 않았다**.
⇒ 이 논문 뒤에도 우리 판정은 그대로다: **"H_R = 1 은 근사가 아니라 미측정이고, 오차의 부호조차 우리 계에서 확정돼 있지 않다."** 다만 이제 *"어떻게 재는지"* 는 완전히 정해졌다 (§4.3 · §12).

## 1. 한 줄 요약

Li₆AsS₅I 의 As 를 Si 로 치환한 Li₆₊ₓAs₁₋ₓSiₓS₅I (x = 0, 0.25, 0.5, 0.75)를 PBE-DFT + AIMD(500 ps · 700–1000 K)로 훑어, **σ(300 K)가 6.0×10⁻³ → 12.9 mS/cm 로 ~10³배 뛰는 원인이 "케이지 탈출(intercage) 점프 빈도의 ~10⁶배 증가"이고**, 그 점프는 조성과 무관하게 **2–6개 Li 가 0.03–3.40 ps 동안 도미노처럼 협동하는 과정**임을 궤적 수준에서 보였다. Si 가 SiS₄ 의 S₁₆ₑ 를 전자 부화(−0.93 → −1.45 e)시켜 확산 경로 위의 Li 를 정전기적으로 안정화하는 것이 기전. **부수 산물로 tracer/charge D 를 분리해 Haven 비 H = 1.83(x=0) / 0.53–0.77(x=0.25–0.75)를 보고**했다 — 이 논문에서 우리에게 가장 값진 부분이지만 동시에 가장 얇은 부분이다.

## 3. 절별 결과 — 수치 총정리

### 3.1 구조 탐색과 형성에너지 (`Fig. 1`, `Table 2`, `Table S1`, `Fig. S7`, `Fig. S9`)

- **156개 Li 자리**: T1(16e) + T2(48h) + T3(4c) + T4(16e) + T5(48h) + T5a(24g) = 16+48+4+16+48+24 = **156** (digest 계산으로 합 확인 ✓).
- **구조 탐색 규모**: 조성당 24–27 Li 를 156 자리에 배치 → pymatgen 으로 **Ewald 정전에너지만으로 16,000개 무작위 초기구조**를 훑고 **저에너지 1,600개** 선별 → DFT 완전 이완. + 직관 기반 수작업 200개 = **총 1,800 구조** (조성당 450).
- **형성에너지** (`Fig. 1a`, Li₂S·As₂S₃·S·Si·LiI 기준): 최저값 **−13.45 / −55.52 / −97.30 / −135.96 meV/atom** (x = 0/0.25/0.5/0.75). x 가 커질수록 강하게 안정화.
  - **figure-read ≈**: 조성당 450개 구조의 E_f 분포 폭은 **약 40–50 meV/atom**(x=0 은 −13 ~ +38, x=0.75 는 −136 ~ −100). 즉 **Li 배열 하나만 바꿔도 40 meV/atom 이 움직인다** — 우리 modelc 무질서 배열 민감도와 같은 종류의 문제.
- **E_hull** (`Table 2`, Li₆AsS₅I + Li₄SiS₄ + Li₂S + LiI 분해 기준): **0 / 4.42 / 7.42 / 11.91 meV/atom**. 전부 실온 열에너지(~25 meV/atom) 아래 ⇒ x ≤ 0.75 는 상온에서 분해 없이 존재 가능.
- **격자** (`Table S1`): a,b,c ≈ 10.25–10.36 Å, 각도 89.5–90.6°, V = **1094.3 / 1097.3 / 1100.6 / 1103.9 Å³**. **완전 이완(원자·셀 모양·부피)** 한 결과 입방에서 살짝 벗어난다 — 저자는 Li 배열이 대칭을 깬 탓으로 본다.
- **⚠ 음이온 무질서가 *불리*하다** (`Fig. S9`): x=0.75 에서 S/I 자리 교환 구조 100개를 돌렸더니 최저에너지 무질서 구조가 정렬 구조보다 **0.85 eV/unit cell 불안정**. ⇒ **이 계는 anion-ordered 다.**
  🔑 **우리 LPSCl 과 정반대다.** LPSCl 은 S²⁻/Cl⁻ 반경이 비슷해(1.84 vs 1.81 Å) 무질서가 곧 전도의 열쇠지만(`adeli2019`·`deklerk2016`), S²⁻(1.84)/I⁻(2.20)는 차이가 커서 교환이 안 일어난다. **이 논문의 σ 상승 기전에는 음이온 무질서가 아예 없다.**
- **As/Si 배열**: 1×1×1 셀에서는 각 x 마다 비등가 배열이 **단 하나**(균일 분산)뿐. 비균일 배열을 보려고 2×1×1 정방 셀로 100 구조를 돌렸더니 최저값이 **0.04 eV/(1×1×1 셀)** 만 불리 ⇒ 균일 배열이 바닥상태지만 비균일도 국소적으로 준안정.

- **왜 x↑ 에서 T5a·T2 로 번지나**: T5 옆의 S^As₁₆ₑ 가 S^Si₁₆ₑ 로 바뀌면 전자 부화된 S 가 Li 를 끌어당기고, **T5a 가 S^Si₁₆ₑ 에 더 가깝기 때문에** Li 가 T5 → T5a 로 이동. 전하보상으로 새로 들어온 Li 는 T5·T5a 다음으로 안정한 **T2** 를 채운다. → 이 T2 점유가 뒤에서 **T2 → T2 케이지간 점프**를 만든다.

### 3.3 Bader 전하 — 이 논문의 인과 사슬의 뿌리 (`Fig. 2a`, `Table S4`)

`Fig. 2a` 를 실제로 봤다. 왼쪽 패널: Li ≈ **+0.85 e**, As ≈ **+1.10 e**, Si ≈ **+2.42 e**, S₄d ≈ **−1.66 e**, I ≈ **−0.86 e** — **전부 x 에 대해 평평**하다. 움직이는 것은 S₁₆ₑ(빨강) 하나뿐: **−0.92 → −1.34 e** 로 선형 하락.
오른쪽 확대 패널이 핵심이다 — S₁₆ₑ 를 이웃 양이온으로 쪼개면:

| 종 | Q (e) | x 의존 |
|---|---|---|
| S^As₁₆ₑ (As 이웃) | **−0.93** | **평평** |
| S^Si₁₆ₑ (Si 이웃) | **−1.45** | **평평** |
| S₁₆ₑ (전체 평균) | −0.92 → −1.34 | x 에 선형 |

🔑 **읽는 법**: 두 종의 전하는 조성에 무관하게 고정돼 있고, **바뀌는 것은 두 종의 개체 수 비율뿐**이다. Δ = **0.52 e** 가 Si 치환이 국소적으로 켜는 스위치의 크기다.

  - Si–S^Si₁₆ₑ: Q = +2.42 / −1.45, d = 2.14 Å → **ε = 1.00** (정의)
  - *digest 계산*: 1.10×0.93/2.19 = 0.467; 2.42×1.45/2.14 = 1.640; 비 = **0.285** ✓ 논문값 재현.
- ⇒ SiS₄ 사면체가 AsS₄ 보다 훨씬 안정 → `Fig. 1a` 의 형성에너지 하락을 설명.

### 3.4 ELF — Si–S 결합의 공유성 (`Fig. 3`) ⚠ 나는 이 그림을 안 봤다 (본문 텍스트만)

- η ≥ 0.8 국재 영역이 S₁₆ₑ 주변과 As(Si)–S₁₆ₑ **사이**에 나타남 → 전하이동과 정합.

### 3.5 Li 케이지 (`Fig. 2b,c`)

- **케이지 중심은 I 가 아니라 S₄d** 다 — Li–S₄d 거리(2.38 Å) ≪ Li–I(2.99 Å). S₄d 가 I 보다 전자를 많이 갖고 있어 Li 를 세게 끈다.
- 케이지 **안** = T1·T2·T5·T5a, 케이지 **밖** = T3·T4.
- **점프 4종** (`Fig. 2c` 도해):
  - **케이지 내(intracage)**: T5 → T5a → T5, T5 → T2 → T5
  - **케이지 간(intercage)**: **T5 → T4 → T5**, **T2 → T2** ← 장거리 수송을 지배하는 것은 이 둘뿐
- x ↑ 에 따라 `Fig. 2b` RDF 첫 봉우리: **Li–S₄d 2.38 → 2.45 Å (증가)**, **Li–I 2.99 → 2.89 Å (감소)**. figure-read 로도 두 봉우리가 각각 오른쪽/왼쪽으로 살짝 이동하는 것이 보인다(이동폭 0.07–0.10 Å 로 작다). ⇒ Si 치환이 케이지를 약간 흐트러뜨려 **케이지 간 간격을 줄이고** intercage 점프를 돕는다.

`Fig. 4` 를 실제로 봤다 — 텍스트가 안 적은 두 가지가 보인다:
- **(a) S₄d 자리 O 교환은 어느 계에서도 항상 크게 불리하다** (+0.8 ~ +1.4 eV, 파란 준위). 반응하는 것은 **폴리음이온(PS₄/AsS₄/SiS₄)의 S₁₆ₑ 뿐**이다. ⇒ 가수분해는 "자유 S²⁻" 가 아니라 **폴리음이온 사면체를 친다**.
- **(b) 한 조성 안에서도 자리마다 E_f 가 크게 흩어진다** — Li₆PS₅Cl 은 S₁₆ₑ 준위가 **−0.60 ~ −0.22 eV 에 10여 개** 로 퍼져 있다 (figure-read ≈ 0.38 eV 폭). 즉 **"할로겐 종에 따른 차이(0.36 eV)" 와 "같은 결정 안 자리별 차이(0.38 eV)" 가 같은 크기다.** 저자는 항상 **최저값**만 인용한다 — 그 규약을 밝히지 않으면 순위가 흔들릴 수 있다.
- x=0.75 에서 −0.27 eV 를 만드는 것은 **오렌지색 S^Si₁₆ₑ 준위**뿐(+0.05 / 0.00 / −0.16 / **−0.27**)이고, 초록 S^As₁₆ₑ 는 여전히 +0.42~+0.44 로 불리하다. ⇒ **Si–O 결합이 As–O 보다 강한 것이 유일한 원인**이고, 취약점은 SiS₄ 사면체에 국한된다.
- 저자 스스로 단서를 단다: 음의 E_f 가 **자발적 H₂S 발생을 뜻하지 않는다** — 이건 교환 전후 에너지차일 뿐이고 실제로는 표면에서 장벽을 넘어야 한다.

### 3.9 ★★ 협동 이동 — 관측량과 문턱 (`Fig. 7`, `Fig. 8`, `Fig. S13`, `Table S8`, `Table S9`)

#### 3.9a "concerted motion" 이 정확히 무엇인가

이 논문의 정의는 **정량 지표가 아니라 궤적 서술**이다. 케이지간 점프 하나가 일어날 때, 출발점과 도착점 주변의 **다른 Li 들이 같이 움직여서 그 점프를 가능하게 만드는 과정**을 협동 이동이라 부른다. 두 개의 구체적 역할이 명시돼 있다:

1. **뒤채움(back-fill)** — 점프하는 Li 가 비운 자리를 **인접 Li 가 즉시 차지**해서 되돌아오지 못하게 막는다.
2. **자리 비켜주기(way-making)** — 도착 지점의 T5 를 이미 점유한 Li 가 **옆 T5 로 비켜준다**. (T2→T2 는 도착 T2 가 원래 비어 있어 이 단계가 필요 없다 → 그래서 더 쉽다.)

**반례가 있다** (`Fig. S13`, 나는 이 그림을 안 봤다 — 본문 서술만): 두 조건이 안 갖춰지면 케이지를 나간 Li 가 **원위치로 되돌아온다**. 저자는 이 되돌아옴을 "실패한 시도"로 세고 **성공률**을 낸다.

### 3.10 ★★★ Discussion — tracer / charge D 와 Haven 비 (`Fig. S14`, `Table S10`, SI "Tracer and collective diffusion")

#### 3.10a 정의 (SI 원문 그대로)

**단일 time-origin (본문 `Fig. 5`·`Table 3`·`Fig. S3–S5` 전부 이걸 쓴다)**

```
D_tr = MSD(t) / 6t                        MSD(t) = (1/N_Li) Σᵢ |rᵢ(t) − rᵢ(0)|²
σ    = n_Li q² D_tr / (k_B T)             ← Nernst–Einstein, 전 Li 가 캐리어
```

**multi-time-origin (Haven 비 산출에만 쓴다)**

```
MSD_tr(τ) = 1/[N_Li(N_t−n)] · Σⱼ Σᵢ |rᵢ(tⱼ+τ) − rᵢ(tⱼ)|²
MSD_σ(τ)  = 1/[N_Li(N_t−n)] · Σⱼ |Σᵢ (rᵢ(tⱼ+τ) − rᵢ(tⱼ))|²      ← 합을 먼저, 제곱을 나중에
D_tr = MSD_tr(τ)/6τ        D_σ = MSD_σ(τ)/6τ
σ_NE = n_Li q² D_tr/(k_B T)      σ_col = n_Li q² D_σ/(k_B T)
H = D_tr/D_σ = σ_NE/σ_col
```

- **τ_max = 250 ps** (총 500 ps 의 절반) — time-origin 통계를 유지하고 후반부 요동을 줄이려고. 근거 ref 4 = López 2024.
- 도구: **pymatgen + pymatgen-diffusion (pymatgen-analysis-diffusion)** — Deng/Zhu/Chu/Ong, *Chem. Mater.* 2017 (ref 48). multi-time-origin 은 He/Zhu/Epstein/Mo, *npj Comput. Mater.* 2018 (ref 58).
- **집단 항 통계 수렴 확인?** — **하지 않았다.** 오차막대도, 블록 평균도, 독립 궤적 비교도 없다. `Table S10` 은 SI 에서 유일하게 오차 열이 없는 표다.

🔑 **`Table S10` 은 원장 정의상 절대값 인용 금지 대상이 아니라, "규약 자유(convention-free)"라서 오히려 값진 표다.** `adeli2019` 는 D_σ = k_BT·σ/(c q²) 로 거시 σ 에서 **역산**했기 때문에 c(캐리어 수) 선택이 H_R 절대값을 좌우했다. 이 논문은 **집단 MSD 를 궤적에서 직접** 재고, D_tr 도 같은 궤적·같은 정규화로 재므로 **H 안에서 n_Li 가 그냥 약분된다.** 우리가 UMA 궤적에서 낼 값과 **정의가 완전히 일치**한다.

### 4.3 ★ Haven 비 산출 (재현 가능한 부분)

§3.10a 에 식을 그대로 옮겼다. 재현에 필요한 것 전부:
1. **unwrapped 궤적** (PBC 를 푼 연속 좌표) — MSD_σ 는 부호 있는 벡터합이라 wrap 되면 망가진다.
2. **multi-time-origin**: 지연시간 τ 마다 원점 tⱼ 를 1..(N_t − n) 전부 사용.
3. **τ_max = 총시간의 1/2.**
4. **MSD_σ 의 정규화는 1/N_Li** (1/N_Li² 가 아니다 — 이 규약이 갈리면 H 가 N배 틀린다).
5. **D 는 MSD/6τ 의 현.** (우리는 자유절편 기울기를 쓴다 → **§12 에서 반드시 맞춰야 할 지점**.)
6. 도구: `pymatgen-analysis-diffusion`.

**★ 점프 판정 알고리즘 (SI 원문, 우리가 이식할 수 있는 유일한 완전 규격)**
1. 골격 S 분류: 초기 배열에서 각 As/Si 의 **최근접 S 4개 = S₁₆ₑ**, 나머지 = S₄d.
2. 프레임마다 모든 Li 의 국소 환경 판정: Li–S 2.75 Å / Li–I 3.20 Å 컷오프 (RDF 근거) + `Table S6` 위상 기준(다면체 종류·AsS₄/SiS₄ 와의 공유 관계·S₄d/I₄a 꼭짓점 유무).
3. 기준 불만족 배열은 **transient 라벨** — 전이의 중간 구간으로 유지하되 **점유·완료 점프로는 세지 않는다**.
4. PBC 는 최단 주기상(minimum image)으로 처리. **저장 프레임 = 1 fs 전부** 분석.
5. **되돌림(fluctuation) 제거**: **0.1 ps 이내 & 1.0 Å 이내**의 짧은 전이를 후보로 걸러, 연속 후보가 **A→B→A** 를 이룰 때만 가역 요동으로 판정해 **제외**. 나머지는 유지.
6. **T5→T4→T5 는 복합 사건**: 같은 Li 의 연속 T5→T4, T4→T5 를 **하나로 병합**. 시작·끝 T5 가 **다른 S₄d 케이지**면 성공, **같은 케이지**면 **실패 시도**.
7. **T2→T2** 는 5번을 통과하면 전부 완료된 케이지간 점프로 계수. **T2→T2 에는 실패 범주가 없다** (단일 단계라서).

⛔ **없는 것**: NEB, BVSE, DOS/PDOS, COHP/ICOHP, grand-potential ESW, 탄성상수, 포논. 전자구조는 Bader + ELF 두 가지뿐이고 **밴드갭조차 안 나온다.**
⛔ **협동 사건의 그룹화 기준**(몇 개 Li 를 한 사건으로 묶는가)은 위 7단계 어디에도 없다.

## 8. ★★ Haven 묶음 3편 재정렬 — 규약을 맞추면 그림이 바뀐다

### 8.1 문제: 세 논문의 캐리어 수 규약이 다르다

- `adeli2019`: D_σ = k_B T·σ/(**c** q²), **c = 4 Li/cell** (저자 명시 **하한**). Li₅.₅PS₄.₅Cl₁.₅ 의 전 Li = 5.5×4 = **22/cell**.
- `zaby2026`: 액체라 **전 이온이 캐리어** — 모호성 없음.
- **이 논문**: 집단 MSD 직접 → **규약 자체가 없다** (H 에서 n 이 약분). NE 쪽 캐리어는 **전 Li** (§3.10b 검산).

### 8.2 ★ *digest 계산 (원논문 미보고)* — adeli 를 "전 Li" 규약으로 옮기면

H_R = D*·c·q²/(k_B T·σ) ∝ **c**. c: 4 → 22 (또는 x=0 이면 4 → 24) 이므로 **H_R 이 5.5–6배 커진다**.

| 출처 | 원 보고 H_R | 규약 | **전-Li 규약 환산** | NE 는 |
|---|---|---|---|---|
| `adeli2019` x=0 (Li₆PS₅Cl) | ~0.3 | c=4/24 | **≈1.8** | **과대** |
| `adeli2019` x=0.5 (Li₅.₅PS₄.₅Cl₁.₅) | 0.23 | c=4/22 | **≈1.3** | **과대** |
| `zaby2026` (IL·LiFSI) | 1.3–2.1 | 전 이온 | 1.3–2.1 | 과대 |
| **jeon2026 x=0** | **1.83** | 전 Li | **1.83** | **과대** |
| **jeon2026 x=0.25–0.75** | **0.53–0.77** | 전 Li | **0.53–0.77** | **과소** |

🔑 **규약을 맞추면 네 묶음 중 셋이 H_R ≈ 1.3–2.1 (NE 과대) 로 모인다.** 그리고 그 셋 안에는 **argyrodite 실험(adeli)과 argyrodite 계산(jeon x=0)이 둘 다** 들어간다. 유일한 이탈자가 **jeon 의 Si-치환 조성(0.53–0.77)** 이고, 그것이 하필 **집단 MSD 통계가 가장 미심쩍은 값들**이다 (§3.10c).

⚠⚠ **이 환산을 과신하면 안 되는 이유 셋:**
1. **adeli 의 σ 는 cold-press 펠릿 total** 이라 GB 저항이 섞여 있다. GB 가 σ 를 깎으면 D_σ 가 작아지고 **H_R 은 부풀려진다** ⇒ 진짜 bulk 값은 1.3–1.8 보다 **작다**. 얼마나 작은지는 모른다. (다만 Ea(EIS) ≈ Ea(PFG) 이므로 GB 가 **장벽**을 왜곡하진 않는다 — 앞지수만 건드린다.)
2. adeli 의 c=4 는 저자가 *"장거리 수송을 지배하는 것은 케이지간 점프"* 라는 물리적 논거로 고른 값이지 임의값이 아니다. 전-Li 규약이 **더 옳다는 뜻이 아니라, jeon 과 비교하려면 같은 자를 써야 한다**는 뜻이다.
3. jeon 의 H 는 **1000 K**, adeli 는 **270–340 K**. 온도가 3배 넘게 다르다.

⇒ **그래서 결론은 여전히 바뀌지 않는다: "H_R = 1 은 근사가 아니라 미측정이다."** 다만 이제 **부호에 대한 약한 사전(prior)** 이 생겼다: **규약을 맞추면 argyrodite 계에서도 H_R > 1(NE 과대) 쪽 증거가 더 많다.** 이건 인용할 결론이 아니라 **우리가 직접 재야 할 이유**다.

## 9. 적용 인사이트 (우리 연구에 어떻게)

### ① ★★★ 우리 UMA 궤적으로 **후처리만으로** H_R 을 낼 수 있다 — 단, 지금 궤적으로는 부족하다

**가능한 것 (새 MD 불필요) — 확인해 보니 우리 도구가 이미 거의 다 갖춰져 있다**
- MSD_σ(τ) = (1/N_Li)·⟨|Σᵢ Δrᵢ(τ)|²⟩ 는 **tracer MSD 와 완전히 같은 unwrapped 궤적 한 벌**에서 나온다. 비용은 tracer 와 동급(O(N·T)).
- **`tools/ionic/msd_origin.py` 가 이미 프레임간 분수좌표 증분을 최소상(minimum-image)으로 풀어 쓴다** (`df = np.diff(frac); df -= np.round(df)`) — 즉 **집단 변위 Σᵢ Δrᵢ 를 만들 재료가 이미 그 함수 안에 있다.** 제곱 순서만 바꾸면 된다.
  ⇒ **새 파일 금지. `msd_origin.py` 에 `--collective` 플래그**를 다는 것이 맞다 (CLAUDE.md 코드 규율 사다리 ③).
- **궤적이 디스크에 있다** — `msd_origin.py` 가 `T*/traj.xyz` 를 읽는다. 즉 **새 MD 없이 후처리만으로 가능**하다.
  ⚠ 단 `msd_refit_window.py` 가 쓰는 `msd.json` 으로는 **안 된다** — 거기엔 tracer MSD 시계열만 있고 좌표가 없다. **집단 MSD 는 반드시 원 궤적에서** 다시 만들어야 한다.
- **폐기 게이트도 이미 있다**: `tools/ionic/msd_diffusive_check.py` 가 `D_inc(t1,t2)` plateau·창 안정성·독립 hop 수로 판정하고 실패를 **`no-value`(정의 안 됨) / `HOLD`(정밀도 부족)** 두 층으로 나눈다. **`Fig. S14` 의 x=0 곡선은 정확히 그 도구의 `no-value` 사례다** ⇒ 같은 게이트를 MSD_σ 에 그대로 적용한다.
- **점프 통계도 이미 있다**: `tools/ionic/aimd_jump_stats.py` 가 **케이지 중심(자유 음이온) 기준 inter-cage hop 율**과 van Hove Gs(r,Δt)를 낸다. `cage_jump_descriptors.py` 는 intra/inter-cage 48h–48h 거리를. ⇒ **§3.8 의 "총 점프 수 vs 케이지간 점프 수" 분해를 우리 계에서 재현할 수 있다.**
- 캐리어 규약도 이미 맞다 — 우리 σ 는 **NE, 전 Li 캐리어** 이므로 **H = σ_NE/σ_col 이 그대로 성립**한다.

**⛔ 그러나 지금 궤적으로 나오는 H 는 신뢰할 수 없다 — 이유가 이 논문 안에 있다**
- 집단 MSD 의 **유효 표본 수는 N_Li 배가 아니다.** tracer 는 Li 24–27개가 각각 표본이지만, 집단항은 **계 전체가 표본 1개**다. 이 논문이 **500 ps · Li 24–27개** 로도 `Fig. S14` 같은 포화 곡선을 얻은 이유가 그것이다.
- 우리 프로덕션은 **200 ps** → multi-origin τ_max 는 100 ps. 이 논문보다 **더 짧다**.
- 우리 3 시드는 **속도 시드만 다르고 배열은 고정**이라 집단항의 배열 의존성을 못 잡는다.

**⇒ 제안하는 순서 (비용 낮은 것부터)**
1. **파일럿(무료)**: 기존 comp1·modelc 1000 K 궤적으로 MSD_σ(τ) 를 그려 본다. **판정 기준을 먼저 정한다** — *"MSD_σ 가 우리 2–50 ps 창에서 직선인가"*. `Fig. S14` 의 x=0 처럼 꺾이면 **그 값은 쓰지 않는다** (결과를 보고 정하지 않는다 — 계산 규율).
2. **추정자 정합**: 이 논문은 현(MSD/6τ), 우리는 자유절편 기울기다. **두 추정자로 다 내서 차이를 먼저 본다.** 차이가 크면 그 자체가 "이 계에서 D_σ 는 잘 정의되지 않는다"는 신호다 (보고량 카드 §판정 기준과 같은 논리).
3. **본계산(MLIP 의 우위가 나오는 지점)**: H_R 의 병목은 **힘 정확도가 아니라 독립 궤적 수**다. AIMD 로는 조성당 500 ps 가 한계지만 UMA 로는 **8–16 시드 × 500 ps–1 ns** 가 현실적이다. 즉 **이 논문이 못 한 것을 우리가 할 수 있다.** ⚠ 배열 시드도 섞어야 한다(속도 시드만으로는 부족).
4. **보고량 카드를 먼저 채운다** (`kb/templates/estimand_card.md`). H_R 은 "admissible state 가 여럿인데 집계 규칙이 없으면 스칼라가 정의되지 않는다"의 전형이다 — τ 선택·추정자·창·시드 집계를 **결과 보기 전에** 못박아야 한다.

### ② ★★ "협동 이동은 도펀트로 조절 가능한가" — **빈도는 되고, 성질은 안 된다**

이 논문의 답은 명확하다: **참여 Li 수(2–6)와 지속시간(0.03–3.40 ps)은 x 에 무관하고, 사건 *빈도*만 10⁶배 바뀐다.**
⇒ **cascade 축으로 쓸 수 있는 것은 "협동 이동의 빈도"이고, "협동성 자체"는 도펀트로 켜고 끄는 스위치가 아니다.**
우리 도핑 캠페인(Nd/O·B₂O₃ 등)에 옮기면: 도펀트가 노려야 하는 것은 *"협동을 만들어내는 것"* 이 아니라 **"이미 있는 협동 사건의 성공률을 올리는 것"** 이다. 이 논문은 그 성공률을 **10 % → 37–42 %** 로 4배 올렸다 (`Fig. S13` 기반 통계).
🔑 그리고 그 지렛대는 **국소 음이온 전하**다 — Si 가 S₁₆ₑ 를 −0.93 → −1.45 e 로 만들고, 확산 경로 위의 S 가 **0.49–0.62 e 더 전자를 갖게** 되는 것. 우리 Bader/ICOHP 축과 정확히 같은 관측량이다.

### ③ ★ "총 점프 수는 그대로, 분배만 바뀐다" — 우리 BVSE·MD 해석의 경고

`Fig. 6b` 가 보여주는 것: x=0 과 x=0.75 의 **총 점프 수는 60 vs 65** 로 거의 같은데 σ 는 **2000배** 다르다.
⇒ **"Li 가 활발히 움직인다"(MSD·점프 수·확률밀도 부피)를 전도도의 대리지표로 쓰면 안 된다.** 우리 BVSE 채널% 와 MD MSD 모두 같은 함정에 걸릴 수 있다 — **연결성(percolating channel)** 이 실제 지표다. `Fig. 6a` 의 "끊어진 케이지 → 연결된 망" 그림이 그 시각화다.

### ④ 부차 — 수분 축의 참고점 (⚠ 우리 ESW 축과 섞지 말 것)

`Fig. 4b` 의 **Li₆PS₅Cl H₂S 생성 E_f = −0.60 eV** 는 우리 comp1 과 같은 조성이다. 다만 (i) 이건 **전기화학 산화가 아니라 가수분해**고, (ii) 저자가 채택한 것은 **여러 자리 중 최저값**이며 같은 결정 안 산포가 0.38 eV 로 할로겐 종간 차이(0.36 eV)와 같은 크기다. 인용하려면 **"자리 최저값 규약" 을 반드시 같이 적는다.**

## 10. 주의 / 한계 (over-claim 방지) — **비판적으로**

### 10.1 저자가 스스로 적은 한계

이 논문에는 **"Limitations" 절이 없다.** 본문에 흩어진 단서는 세 개뿐이다:
1. H₂S 형성에너지가 음수라고 **자발적 발생을 뜻하지 않는다** — 표면 반응 장벽이 따로 있다 (§3.5 말미).
2. x > 0.8 에서 실험 σ 가 급락하는 것은 구조 붕괴 때문이며 **계산은 그 영역을 안 다뤘다**.
3. H 의 조성 순서가 케이지간 점프 수 순서와 **안 맞는다** — "이동 방향에 따라 기여가 다를 수 있다"로 넘어간다 (§3.10b).
⇒ **AIMD 통계·시드·유한크기·외삽에 대한 자기 한계 서술은 없다.**

### 10.2 내가 보는 한계 (심각도 순)

1. ⛔⛔ **Haven 비의 통계 근거가 없다.**
   - **1000 K 한 점**에서만 쟀다. 조성×온도 표가 없으니 **온도 의존을 모르고**, 300 K 로 옮길 근거도 없다.
   - **오차막대 0.** `Table S10` 은 SI 에서 유일하게 오차가 없는 표다. 집단 MSD 는 self 보다 훨씬 잡음이 크다는 것이 이 분야의 상식인데(`zaby2026` §6.2: ionicity 의 SE 가 σ_NE 의 SE 보다 훨씬 크다, GK 오차막대가 EH 의 3–8배), **그 상식이 이 표에서 전혀 반영되지 않았다.**
   - **`Fig. S14` 를 보면 x=0 의 charge MSD 는 확산이 아니다** (150 ps 이후 포화). H=1.83 은 "τ=250 ps 에서의 현" 이상의 의미가 없다. **그런데 H>1 을 만드는 유일한 점이 바로 그것이다.**
   - **단일 궤적·단일 배열·Li 24–27개.** 집단항은 계 전체가 표본 1개라 유효 표본이 극도로 적다.
   ⇒ **"argyrodite 의 Haven 비는 0.53–0.77 이다" 로 인용 금지.** 인용 가능한 것은 *"같은 골격에서 조성에 따라 H 가 1 위아래로 뒤집힐 수 있음을 계산이 시사"* 까지.
2. ⛔ **계산한 H 를 결론에 반영하지 않았다.** 헤드라인 σ 는 전부 σ_NE 다. 반영하면 x=0.75 가 12.9 → 16.8 mS/cm 로 **실험(8.1–10.4)에서 멀어진다**(§3.10d 의 digest 계산). Discussion 에서 보정을 계산해 놓고 Abstract·Conclusion 은 보정 전 값으로 쓰는 구조다.
3. ⛔ **협동 사건의 그룹화 기준이 없다.** SI 는 자리 판정·점프 계수 규칙을 7단계로 상세히 적었는데(§6), **"몇 개의 Li 를 한 협동 사건으로 묶는가"** 의 시공간 문턱은 어디에도 없다. ⇒ `Table S8`·`S9` 의 **참여 Li 수(2–6)·지속시간(0.03–3.40 ps)은 현재 문헌 상태로는 재현 불가능**하다. 이 두 숫자가 초록에 나가는 헤드라인인데도 그렇다.
4. ⛔ **x=0 의 협동 통계는 사건 2개씩에서 나왔다** (digest 환산, `Table S2` 로 교차확인). `Table S8` x=0 행의 "4 (4.00)" 은 사건 2개, `Table S9` 의 "4–5 (4.50)" 도 사건 2개다. **논문에 적혀 있지 않다.** `Fig. 7` 은 "대표 사건" 이 아니라 "가용 사건의 절반" 이다.
5. ⛔ **저자의 오차범위가 저자의 결론을 지지하지 않는다.** `Table S7` 의 x=0.75 두 구간이 [2.1×10⁻³, 4.2×10⁻³] 에서 겹치므로 **"T2→T2 가 T5→T4→T5 보다 지배적" 은 통계적으로 성립하지 않는다.** x=0 의 T2→T2 는 오차가 **6자릿수**(1.9×10⁻¹² ~ 2.6×10⁻⁶)다. 게다가 `Table S2` 는 **컷오프/k-mesh 만 바꿔도 두 유형의 대소가 뒤집힘**(140:155 → 180:125)을 보여준다.
6. ⚠ **"500 ps 수렴" 주장이 자기 그림과 어긋난다.** `Fig. S5` 에서 **x=0 의 Ea 는 500 ps 까지 계속 상승 중**이고, x=0.25 는 비단조로 크게 흔들리며, x=0.75 의 σ 도 500 ps 에서 상승 중이다. 본문의 *"provide sufficiently converged σ and Ea"* 는 x=0.5 에서만 설득력 있다.
7. ⚠ **300 K 외삽이 과하다.** 700–1000 K 4점(1000/T = 1.00–1.43)에서 300 K(3.33)로 — **외삽 거리가 적합구간 폭의 4.4배**다. 게다가 `Fig. S3` 로 보면 **x=0 의 700·800 K MSD 는 사실상 비확산**이라 4점 중 2점의 D 가 의심스럽다. 그 4점으로 정한 Ea 로 10¹⁰ 배 아래까지 내려간다.
8. ⚠ **"실험과 잘 맞는다" 가 3배 오차막대 안의 이야기다.** `Table S5` 의 x=0.75 σ 구간이 **[7.1, 23.5] mS/cm** (3.3배 폭), x=0.5 는 **[2.8, 23.5]** (8.4배 폭). 이 폭 안에서는 거의 아무 실험값이나 "잘 맞는다".
9. ⚠ **`Fig. 5d` 가 본문 서술과 어긋난다.** 본문 *"conductivity at x=0.25 is somewhat higher than the experimental value at x=0.2"* 인데, figure-read 로는 **0.9 vs ≈0.03 = 약 30배**다. "somewhat" 이 아니다.
10. ⚠ **유한크기 처리가 없다.** 52–55 원자 · 1×1×1 셀. 케이지가 셀당 4개뿐이라 **"케이지간 점프" 가 곧 "셀 절반을 가로지르는 이동"** 이다. 2×1×1 셀은 As/Si 배열 정적 검토에만 썼고 **AIMD 셀 크기 수렴 시험은 없다**. 집단 MSD 는 특히 크기 민감한 양이다.
11. ⚠ **평형화·시드가 안 적혀 있다.** 500 ps 중 몇 ps 를 버렸는지, 승온 절차가 무엇인지, 초기 속도를 어떻게 뽑았는지 전부 없다. **재현 불가.**
12. ⚠ **1000 K = 727 °C 에서 이 상이 유지되는지 확인이 없다.** 열팽창 미고려(0 K 부피 NVT), 용융/분해 점검 없음.
13. ⚠ **기전이 "전자 부화 S 가 확산 장벽을 낮춘다" 로 서술되지만, 장벽을 직접 계산하지 않았다.** 본문 표현이 *"appears to lower"*, *"probably lowering"*, *"is expected to significantly lower"* 로 일관되게 조건부다. NEB 는 이 논문에 없다(자매편 ref 40 에 있다). **"Si 가 확산 장벽을 X eV 낮춘다" 로 인용 금지.**
14. ⚠ **PBE·vdW 없음·+U 없음.** 황화물 argyrodite 에서 관행적이나, Bader 전하 절대값과 ELF 국재 전자 수(1.55 / 1.75 e)는 **functional·분할 방식 의존**이다. 순위와 차이만 인용.

## 11. 인용 가능 문장 (deck / paper 용)

- ✅ "In argyrodite Li₆₊ₓAs₁₋ₓSiₓS₅I, AIMD shows the **total number of Li jumps barely changes with Si content (≈60 → 65 Å⁻³ ns⁻¹ at 700 K), while the σ at 300 K rises by ~10³** — the conductivity gain comes entirely from the rare cage-escaping jumps, not from more Li motion." (`Fig. 6b`, `Table 3`)
- ✅ "Intercage jumps in Li₆₊ₓAs₁₋ₓSiₓS₅I proceed by a **concerted motion involving 2–6 Li ions over 0.03–3.40 ps at 700 K**, and this character is essentially independent of Si content — Si changes the **frequency** (≈10⁶× at 300 K), not the **mechanism**." (`Table S8`, `Table S9`)
- ✅ "The success rate of attempted T5→T4→T5 intercage jumps rises from **10 % (x=0) to 37.4–41.9 % (x=0.25–0.75)** at 700 K." (본문 §3.8)
- ✅ "Si substitution enriches the polyanion sulfur from **Q = −0.93 e (S^As₁₆ₑ) to −1.45 e (S^Si₁₆ₑ)**; the two species' charges are composition-independent — only their population changes." (`Fig. 2a`, `Table S4`)
- ⚠ **조건부**: "A single-temperature (1000 K) AIMD estimate gives Haven ratios **H = 1.83 (x=0) and 0.53–0.77 (x=0.25–0.75)** in Li₆₊ₓAs₁₋ₓSiₓS₅I — i.e. the sign of the Nernst–Einstein error can flip within one structural family." → **반드시 "single temperature, single trajectory, no error bars" 를 같이 적는다.**
- ⛔ **금지**: "argyrodite 의 Haven 비는 ~0.6 이다" / "Si 치환이 확산 장벽을 X eV 낮춘다" / "계산 σ 12.9 mS/cm 가 실험과 정량 일치한다" / 이 논문의 σ·D 절대값을 우리 modelc 값과 나란히 놓기.

## 13. 용어 미니 사전 (이 논문을 읽는 데 필요한 것)

| 용어 | 뜻 · 이 논문에서의 쓰임 |
|---|---|
| **tracer(self) diffusion D_tr** | 개별 이온 변위의 제곱을 **먼저 제곱하고 나중에 평균**. MSD = (1/N)Σᵢ\|Δrᵢ\|². 이온끼리의 상관을 못 본다 |
| **charge(collective) diffusion D_σ** | **먼저 합하고 나중에 제곱**. MSD_σ = (1/N)\|ΣᵢΔrᵢ\|². 순 전하 변위 = 실제 전류에 대응. 이온이 같은 방향으로 몰리면 커지고, 서로 상쇄하면 작아진다 |
| **Haven 비 H_R = D_tr/D_σ = σ_NE/σ_col** | 1 = 무상관. **>1 이면 집단 운동이 순 전하 변위를 깎아 NE 가 과대**, **<1 이면 집단 운동이 순 전하 변위를 키워 NE 가 과소**. ⚠ **엄밀히는 상관인자(correlation factor) f 와 다르다** — f 는 tracer 쪽 상관만, H_R 은 교차상관까지 포함. 이 논문은 둘을 구분하지 않는다 |
| **multi-time-origin MSD** | 지연시간 τ 에 대해 원점 tⱼ 를 궤적 전체에서 미끄러뜨려 평균. 표본 수를 (N_t − n)배로 늘린다. 대신 원점끼리 독립이 아니라 **오차막대를 이걸로 대체할 수 없다** — 이 논문이 정확히 그 함정에 빠졌다 |
| **intracage / intercage jump** | Li 는 S₄d 중심 케이지를 이루고, 케이지 **안**에서 도는 점프(T5↔T5a, T5↔T2)는 장거리 수송에 기여하지 않는다. 케이지를 **넘는** 점프(T5→T4→T5, T2→T2)만이 σ 를 만든다 |
| **T5 / T5a / T2 / T4** | argyrodite Li 자리. T5(48h)·T5a(24g)·T2(48h)는 케이지 **안**, T4(16e)·T3(4c)는 **밖**. T5–T5 면공유 쌍이 셀당 24개 |
| **concerted motion** | 여러 Li 가 순차적이지만 거의 동시에(도미노) 움직여 하나의 케이지간 점프를 성사시키는 것. 역할 2종: **뒤채움**(빈 자리를 즉시 메워 되돌아옴 방지) + **비켜주기**(도착지 Li 가 옆으로 이동) |
| **S₄d vs S₁₆ₑ** | S₄d = 폴리음이온에 안 속한 "자유" S²⁻ (Wyckoff 4d), 케이지 중심. S₁₆ₑ = AsS₄/SiS₄ 사면체를 이루는 S (16e). 이 논문에서 도펀트 효과가 걸리는 것은 **S₁₆ₑ 뿐** |
| **E_hull** | convex hull 위 에너지 = 분해 구동력. 실온 열에너지 ~25 meV/atom 이 관행적 기준선 |
| **ε 서술자** | Q_A·Q_B/d_A–B 를 Si–S 로 규격화한 단순 정전 세기 지표. 이 논문 자체 정의 (`Table S4`) |
| **CRITIC2** | 전하밀도 위상 분석 도구. 여기서는 ELF 국재 영역의 전자 수 적분에 사용 |
| **R.I.N.G.S.** | Rigorous Investigation of Networks Generated using Simulations — RDF·배위수·고리 분석 코드 (ref 47) |

## 14. 이 논문이 못 하는 것 / 내가 확인 못 한 것

**이 논문이 못 하는 것**
- **우리 계(LPSCl)에 값을 옮길 수 없다** — 양이온(As/Si vs P)·음이온(I vs Cl)·무질서 상태(정렬 vs 무질서)가 전부 다르다.
- **H_R 의 온도 의존을 모른다** (1000 K 1점). ⇒ 실온 σ 보정에 못 쓴다.
- **H_R 의 불확실도를 모른다** (오차막대 없음, 시드 1개).
- **확산 장벽을 직접 안 잰다** (NEB 없음). "장벽이 낮아진다"는 전부 정전 논증 + 조건부 서술.
- **협동 사건의 정의를 재현 가능하게 안 적었다** (그룹화 문턱 부재).
- **밴드갭·ESW·탄성·포논이 없다** — 우리 4축 중 ①②③④ 어디에도 값을 못 준다. 유일하게 걸리는 것은 **가수분해(수분 축)** 이고 그건 우리 ESW 축이 아니다.
- **실험이 하나도 없다** (`Fig. 5d` 초록 원은 전부 ref 25 재인용).

**내가 확인 못 한 것**
- **그림 12장을 안 봤다**: `Fig. 3`(ELF), `S1`, `S2`, `S4`, `S6`, `S7`, `S8`, `S9`, `S10`, `S11`, `S12`, `S13`. 이 중 `S13`(실패한 점프)과 `S10`/`S11`(경로 주변 전하)은 본문 주장의 근거 그림이라, 본문 서술을 그대로 옮긴 부분(성공률 10 %/37.4–41.9 %, 0.62 e/0.49 e)은 **캡션·본문 대조만 했고 눈으로 검증하지 않았다.**
- **SI 의 POSCAR(S33–S43, 4 조성)를 구조로 검증하지 않았다** — 격자상수가 `Table S1` 과 일치하는지만 x=0 에서 눈으로 확인했다(10.335/10.327/10.253 vs 표 10.34/10.33/10.25 ✓).
- **원논문 재현 계산 없음.** §3.8·§3.10·§8 의 *digest 계산* 은 전부 **논문 안 숫자끼리의 산술**이다 (사건 수 환산은 `Table S2` 로 교차확인 ✓, σ_NE 재현은 캐리어 규약 확인 ✓, adeli 규약 환산은 D_σ ∝ 1/c 관계에 기반 — **실험 원자료 재해석이 아니다**).
- **자매편 ref 40 (Li₆₊ₓSb₁₋ₓSiₓS₅I, JMCA 2025)을 안 읽었다.** 단일이온 vs 협동 확산 장벽 비교가 거기 있다고 본문이 말한다 — 우리 NEB 축과 직접 연결될 수 있는 편이므로 **후속 인입 후보**.
- **ref 53 (López/Rurali/Cazorla, JACS 2024, "상관 이온 10±5")** 도 안 읽었다. 협동 이동의 정량 기준이 거기 있을 가능성이 높다 — **§10.2-3 의 정의 공백을 메울 후보 원전**.
- **VASP 버전·POTCAR 버전 미기재**라 확인 불가.
