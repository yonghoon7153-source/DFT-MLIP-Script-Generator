## 1. 한 줄 요약

**"시뮬레이션이 충분히 길다(ergodic)"는 가정을 검증 없이 쓰면, 가장 단순한 LJ 유체에서도 초기 속도만 바꾼 두 궤적이
95 % 신뢰구간이 겹치지 않는 MSD 를 낸다.** 게다가 MSD 를 직선 적합해 D 를 얻는 "표준" 절차는 최소제곱회귀의
**정규성·등분산성 가정을 둘 다 위반**하므로 **그 회귀가 뱉는 D 의 오차는 아예 쓰면 안 된다.**
해법은 하나 — **여러 개의 독립 시뮬레이션(MIS)을 돌려 D 를 표본으로 모으고, 그 표본에서 Student-t CI 를 낸다.**

## 4. ★★ 논증의 뼈대 — 이 논문의 전부

### 4-1. ★★ 무엇이 문제인가 — 순진한 "N개 독립 궤적의 표준오차"의 편향

여기서 **두 개의 서로 다른 문제**를 구분해야 한다. 논문은 둘 다 다루는데 자주 뒤섞여 인용된다.

#### 문제 A — **단일 궤적의 D 는 편향돼 있다** (방향: 초기 조건 쪽으로)

- ergodic 가정은 *"충분히 길면 시간평균 = 앙상블평균"* 인데, **얼마나 길어야 충분한지는 사전에 알 수 없고,
  돌린 뒤에 "충분했다"를 증명하기도 어렵다** (본문 반복 강조).
- 실측: 125 LJ 입자, **표준 교과서보다 훨씬 긴** 생산 런(1 M 스텝)에서, **초기 속도만 다른 두 궤적**이
  **95 % CI 가 겹치지 않는 MSD(τ)** 를 냈다 (**Fig. 4**). 저자 표현: *"This was surprising"*, *"To our surprise"*.
- ⇒ **단일 궤적의 D 는 초기 상태의 기억을 지우지 못한 값**이고, 그 편향의 **방향은 계마다 무작위**다
  (위로든 아래로든 그 궤적이 어디에 갇혔느냐에 달렸다).

**편향의 크기 (수치)**
- **Fig. 4 (figure-read ≈)**: τ = 4 에서 Run 1 ≈ **6.045**, Run 2 ≈ **6.11** → **약 1 %** 차이. 각 점의 95 % CI 반폭은 ≈ **0.02–0.025**
  (MSD 값의 **0.4 %**) 라서 **겹치지 않는다.** 본문 그림 전체(τ 0–20)에서는 두 곡선이 육안으로 구별 안 되고,
  **inset 으로 확대해야만** 보인다 — 이게 무서운 점이다.
- **100 시드의 D 산포 (SI §2, 논문 소환값)**:
  - L = 11.26 (N = 1000): μ = **0.2822721**, σ = **0.0003096** → **CV 0.110 %**
  - L = 5.63 (N = 125): μ = **0.2579971**, σ = **0.0005075** → **CV 0.197 %**
  - MSD(τ = 10) 자체의 산포: μ = **15.512558**, σ = **0.0605846** → **CV 0.39 %**
    (→ **적합이 잡음을 반으로 줄인다**: MSD 한 점의 0.39 % → 회귀로 얻은 D 의 0.197 %)
- **프랙탈 응집체 (Table 3 에서 역산, digest 계산)**: 10 MIS · t₉ = 2.262 로 σ 를 되돌리면
  **CV 2.7 – 4.1 %** — LJ 유체의 **약 20배**.
  ⇒ **입자 하나(거대분자)의 D 는 여러 입자가 각자 표본을 내주는 유체보다 시드 노이즈가 압도적으로 크다.**

#### 문제 B — **회귀가 뱉는 D 의 오차는 애초에 무효다** (편향이 아니라 *무자격*)

MSD 를 τ 에 직선 적합해 `D = β̂₁/6` 을 얻는 표준 절차는, 최소제곱회귀의 네 가정 중 **둘을 위반한다**:

| 가정 | 성립? | 근거 |
|---|---|---|
| SD(τ) 가 유한 평균·분산을 갖는 분포로 존재 | ✅ | **Fig. 3** — SD 가 유한 범위 안에 있다 |
| MSD ∝ τ 선형 | ✅ | Einstein 관계의 물리적 근거 |
| SD 표본의 **독립성** | ✅ *단, δ ≥ τ 로 뽑았을 때만* | **Fig. 2** 로 δ 를 결정 (§4-3) |
| **정규성** | ❌ **위반** | **SI §1**: SD(τ=1) Shapiro–Wilk **W = 0.874744, p < .0001** · \|변위\| 도 **W = 0.970387, p = 0.0076** |
| **등분산성(homoscedasticity)** | ❌ **위반** | **Fig. 3** — τ 가 커질수록 SD 산포가 계속 커진다 |

> ⇒ 저자 결론: *"This violation **invalidates least-squares regression analysis** in this case."*
> **직선 적합은 점추정 `D = β̂₁/6` 로는 여전히 쓸 수 있다** (Einstein 관계에 물리적 근거가 있으므로).
> 하지만 **그 회귀가 함께 뱉는 D 의 표준오차/CI 는 쓰면 안 된다.** 저자 원문:
> *"the straight line fit … would result in a point estimate of D = β̂₁/6 **even though uncertainty in D cannot be determined**."*

⚠ **여기가 오해하기 쉬운 지점이다.** 사용자 질문의 표현 *"독립 궤적을 여러 개 돌려도 오차 추정이 자동으로 옳아지지 않는다"* 는
**절반만 맞다.** 이 논문의 실제 주장은 반대에 가깝다 — **MIS 가 바로 그 해법이다.** 정확히는:

> **"독립 궤적을 여러 개 돌리는 것"이 필요조건이지만, *어디서* 표준오차를 뽑느냐가 결정적이다.**
> ⛔ **한 궤적 안의 MSD-vs-τ 회귀**에서 뽑으면 → **무효**(정규성·등분산 위반).
> ⛔ **한 궤적 안의 겹친 시간원점 개수**로 √N 나누면 → **과소평가**(SD 표본이 독립이 아님, §4-3).
> ✅ **여러 독립 궤적의 D 표본**에서 뽑으면 → **유효**(D 는 정규분포임이 SI §2 에서 검증됨).
>
> 초록의 *"statistically distinguishable MSD … by simply varying the initial velocities"* 는
> "MIS 가 소용없다"가 아니라 **"단일 궤적이 얼마나 위험한지"의 증거**다.

#### ★ 그리고 편향의 **방향**을 정하는 진짜 위험 — 선택 편향

논문이 명시적으로 쓰진 않았지만 §4-1 문제 A 의 논리적 따름정리이고, **우리가 실제로 밟은 지뢰**다:
시드마다 D 가 ±20 % 흔들리는데 **"확산영역 통과한 시드만" 채택**하면, MSD 가 우연히 큰 시드만 살아남아
**D 가 위로 편향**된다. → `kb/methodology/beta_gate_seed_policy.md` §"⛔ 금지" 와 동일한 판정.

### 4-2. ★★ 저자가 제안하는 올바른 추정 절차 (식·단계·가정)

> **표기**: τ = 변위를 재는 시간 간격(lag) · δ = 이웃한 두 **시간원점** 사이 거리 · N_τ = 그 τ 폭의 구간 개수 ·
> N_P = 입자 수 · M = 독립 시뮬레이션 개수

**Step 0. MSD 의 정의를 δ 를 노출한 형태로 쓴다** (본문 Fig. 1 이 이 그림이다)

```
MSD(τ, δ) = (1/N_τ) Σ_{j=1..N_τ}  [ (1/N_P) Σ_{i=1..N_P} | r_i(jt_i + τ) − r_i(jt_i) |² ]
             단,  j+1 t_i − j t_i = δ
```
즉 MSD 는 **τ 만의 함수가 아니라 (τ, δ) 의 함수**다. 대부분의 논문이 δ 를 안 밝힌다는 게 이 논문의 출발점.

**Step 1. δ 를 데이터로 정한다 — 사전에 알 수 없으므로 반드시 재야 한다**

SD 의 정규화 자기상관함수를 정의하고,
```
R_SD(τ, δ) = ⟨ SD(τ,0) · SD(τ,δ) ⟩ / ⟨ SD(τ,0) · SD(τ,0) ⟩
```
δ 를 키우며 R_SD 가 **평평해지는 지점**을 δ_min 으로 잡는다 (**Fig. 2**).
- **이 계의 답: δ ≥ τ** — 즉 **겹치지 않는 구간**으로만 SD 를 뽑아야 독립이다.
- ⚠ **R_SD 는 0 으로 안 떨어진다.** ⟨SD(τ, δ→∞)⟩ > 0 이므로 **일정한 상수**로 수렴한다
  (**figure-read ≈ 0.60**). **"0 이 될 때까지"를 기준으로 삼으면 δ 를 영원히 못 정한다** — 기준은 **평탄화**다.
- 저자 강조: **δ 는 계마다 다르고 사전에 알 수 없다.** 문제마다 다시 재라.

**Step 2. 그 δ 로 MSD(τ) 와 그 CI 를 낸다**

- 표본 수 N_SD = N_τ × N_P 가 **충분히 크면**(통계학 경험칙 **~40**, 이 논문은 τ 당 **> 30,000**)
  **중심극한정리**로 MSD 의 표본평균은 정규분포를 따른다 — **SD 자체가 정규가 아니어도 된다.**
- ✅ 검증됨: **SI §2 / Fig. S3** — MSD(τ=10) 이 실제로 정규 (**W = 0.993936, p = 0.9376**).
- (digest 계산으로 확인) 생산 5,000 시간단위, τ = 20, δ = 20 → N_τ = 250, × N_P = 125 = **31,250** > 30,000. ✔ 본문 서술과 일치.

**Step 3. 각 궤적에서 D 는 점추정만 취한다**

```
MSD(τ) = β̂₀ + β̂₁ τ        →      D = β̂₁ / 6      (3차원)
```
**β̂₁ 의 표준오차는 버린다** (§4-1 문제 B). 절편 β̂₀ 는 자유(free intercept)로 둔다.

**Step 4. M 개의 독립 시뮬레이션에서 D 표본을 모은다 (MIS)**

- 독립화 방법: **초기 속도를 Maxwell–Boltzmann 에서 다시 뽑는다** (나머지는 전부 동일).
- 저자 경고: *"the generation of independent initial states is **nontrivial for complex systems**"* —
  복잡계에서는 속도 재추출만으로 부족할 수 있고, NEB 로 최소에너지 상태를 만드는 등의 기법이 문헌에 있다.

**Step 5. D 표본에서 t-분포 CI 를 낸다 — 단, 정규성을 먼저 검사한다**

```
D̄ = (1/M) Σ D_k
S² = (1/(M−1)) Σ (D_k − D̄)²
100(1−α) % CI :  D̄  ±  t_{M−1, 1−α/2} · S / √M
```
- ✅ **가정 검사가 절차의 일부다**: D 가 정규인지 **Shapiro–Wilk** 로 확인 (SI §2: L=11.26 **p = 0.1887**, L=5.63 **p = 0.3286** → 기각 안 됨).
- ⛔ **`D̄ ± S` 는 오차가 아니다** — 그건 산포(spread)일 뿐. ⛔ **`D̄ ± S/√M` 도 아니다** — 그건 **68.2 %** 구간.
  **표준 관행은 95 % CI (α = 0.05)** 다. (본문이 이 흔한 오용을 두 문단에 걸쳐 명시적으로 지적한다.)

**Step 6. (선택) 유한크기 보정 — 여기서도 MIS 가 필요하다**

```
D = D_o + ξ k_B T / (6 π η L)      ξ = 2.837297
```
(Dünweg & Kremer 1993; Dünweg 1993; Yeh & Hummer 2004)
→ **D vs 1/L 의 절편이 D_o**. 이 회귀에도 같은 가정 검사를 다시 돌린다:
- 존재 ✅ (Fig. 5) · 선형 ✅ (위 식) · 독립 ✅ (MIS) · **D 정규성** ✅ (SI §2)
- **등분산성 ❌ 위반** (**Fig. 5 / Fig. S4** — 상자가 작을수록 D 산포가 커진다)
  → **가중최소제곱(WLS, weights = 1/variance)** 으로 교정 (SI §3).

**절차가 필요로 하는 가정 (요약)**

### 4-3. ★ 다중 시간원점(multiple time origins) — 다룬다, 그리고 이게 §1 의 절반이다

**다룬다.** 본문 "Sampling Squared Displacements" 절 + **Fig. 1**(모식도) + **Fig. 2**(R_SD) 가 통째로 이 주제다.

- **핵심 결과: δ ≥ τ.** 겹치는 시간원점으로 뽑은 SD 는 **서로 상관돼 있다.**
- **독립성에 미치는 영향 (Fig. 2, figure-read)**: τ = 5 곡선은 δ ≈ 5 에서 평탄화, τ = 10 은 δ ≈ 11–12,
  τ = 15 는 δ ≈ 15–16, τ = 20 은 δ ≈ 18–20. **네 곡선 모두 δ ≈ τ 에서 평탄값(≈0.60)에 닿는다.**
  δ = τ/4 쯤에서는 **R_SD 가 아직 0.85 근처**다 — "약하게 상관" 이 아니라 **강하게 상관**이다.
- **저자의 실용적 딜레마 서술**: *"The distance between two consecutive time origins (δ) is usually kept to a
  **minimum to maximize the number of samples** … However, for a small δ and large τ, the consecutive values of
  squared displacements are likely to be correlated, thus resulting in a **biased estimate of MSD(τ)**."*
  → 계산비 절약(작은 δ)과 독립성(큰 δ)이 정면충돌하고, **어느 쪽을 택하든 δ 를 밝혀야 한다.**
- **어디에 영향이 있고 어디에 없나** (이 구분이 실무의 전부다):
  - **MSD(τ) 의 점추정**: 겹쳐 뽑아도 **평균은 여전히 불편(unbiased)** 하다 — 표본을 더 넣는 것이 평균을 망치지 않는다.
    (다만 본문은 "biased estimate of MSD" 라는 표현을 쓴다 — 겹친 표본이 특정 시간대에 과대표집되면
    유한 궤적에서 **실효적 편향**이 생긴다는 뜻으로 읽는다. §13 에 불확실로 표시.)
  - **오차 추정**: 여기가 **치명적**이다. n = "겹친 원점 개수" 로 `S/√n` 을 하면
    **실제 독립 표본은 τ/δ 배 적으므로 정밀도를 √(τ/δ) 배 과대평가**한다.
- 저자는 δ 를 정하는 다른 접근도 인용: Calderon et al. 의 **최대우도** 기반 확률모형 적합.

## 7. Post-processing ★

- **무엇**:
  ① **SD 자기상관함수** R_SD(τ,δ) → δ 결정
  ② **MSD(τ)** 다중 시간원점 평균 + **Student-t 95 % CI**
  ③ **선형회귀** MSD~τ → D = β̂₁/6 (점추정만)
  ④ **정규성 검정** — **Shapiro–Wilk W** (SD, |변위|, D, MSD, 잔차 전부)
  ⑤ **ANOVA + Lack-of-Fit 검정** (pure error 분해)
  ⑥ **가중최소제곱(WLS)**, weights = 1/variance, **Pearson 잔차**로 진단
  ⑦ **유한크기 외삽** D vs 1/L → 절편 D_o
  ⑧ **CoM 표류 대조**
- **도구**: MD 는 **LAMMPS**; 통계는 전부 **JMP 12.0.0** (www.jmp.com). pymatgen·VESTA·LOBSTER 류는 등장하지 않음.
- **수치화·기록 방식**: JMP 출력(Parameter Estimates / Goodness-of-Fit / ANOVA / Lack Of Fit 표)을 **SI 에 그대로 붙였다.**
  본문에는 D̄ + LCL/UCL 만 표로 옮겼다. **오차는 항상 "95 % CI 의 하한·상한 두 수"로 적었지 `±` 하나로 뭉개지 않았다** —
  우리가 배워야 할 표기 관례다.

### 9-3. 🔴 우리 MTO 가 δ ≥ τ 를 어긴다 — 구체적으로

| τ | 우리가 세는 원점 수 (`nt−L`) | **Pranami 기준 독립 원점 수** (⌊200/τ⌋) | 과대계수 배율 | √배율 = 정밀도 과대평가 |

| 2 ps | 1,980 | **100** | 19.8× | 4.4× |
| 10 ps | 1,900 | **20** | 95× | 9.7× |

그리고 그 파일의 docstring 은 이렇게 적혀 있다:
> *"Averaging over every time origin multiplies the sample count by the number of **(weakly correlated) origins** at no extra MD cost."*

   **우연히 피해 있다** — 그러나 이건 설계가 아니라 결과다.

**⛔ 그래서 절대 하면 안 되는 것**: `n_origins` 로 `S/√n` 을 만들어 MSD 나 D 에 오차막대를 붙이는 것.
그러면 정밀도를 **최대 19배 과대평가**한다. 지금 코드에 그런 경로가 없다는 것을 확인해 뒀다 —
**앞으로도 넣지 않는 것을 규약으로 못박는 게 낫다.**

### 9-4. ⚠ 이 논문이 우리에게 **주지 못하는 것** — quenched disorder

**결정적 차이다.** Pranami 의 "독립 시뮬레이션" 은 **초기 속도만** 다르다. LJ 유체는 균질해서 그게 곧 전부다.

**우리는 아니다.** argyrodite 는 S/Cl 자리 무질서가 있고, **한 셀은 하나의 무질서 배열을 얼려서 갖고 있다.**
`tools/modelc_v3/aimd_mlip.py` 의 `--seed` 는 **초기 속도 + Langevin 잡음**만 시드한다
(`disorder_ensemble_diffusion.py` 만 `--seed` 가 무질서 배열까지 건드린다 — 두 경로를 구분해야 한다).

⇒ **속도만 재추출하는 시드를 100개 돌려도, 그것은 "이 배열에서의 D" 의 CI 일 뿐 "이 조성의 D" 의 CI 가 아니다.**
저자도 이 위험을 알고 있었고 그래서 이렇게 썼다:
> *"the generation of independent initial states is **nontrivial for complex systems**"*

**우리 언어로 번역하면**: 우리에게는 분산 성분이 **두 개**다 — ① 열/운동학(시드), ② **배열(configuration)**.
지금 우리 오차막대는 ①만 담고 ②는 **0으로 취급**한다. 이 논문은 ②를 다루지 않으므로,
②에 대한 처방은 우리가 따로 만들어야 한다 (배열 앙상블 → `disorder_ensemble_diffusion.py` 가 이미 그 방향의 도구다).

### 9-5. ★★ **우리 시드 3개는 충분한가** — 이 논문의 절차로 계산한 답

> **전부 digest 계산이다.** 이 논문에는 "목표 정밀도별 필요 시드 수" 표가 **없다**(§11-4).
> 아래는 이 논문의 **Step 5 식** `h = t_{M−1,0.975} · S/√M` 에 **우리 실측 CV 22.1 %** 를 넣은 것이다.

**(a) 단일 D 를 목표 정밀도로 재려면**

| 목표 95 % CI 반폭 | 필요 시드 M (CV = 22.1 %) | (CV = 25 % 일 때) |
|---|---|---|
| ± 50 % | **4** | 4 |
| ± 30 % | **5** | 6 |
| ± 20 % | **8** | 9 |
| ± 10 % | **22** | 27 |
| ± 5 % | **77** | — |

**현재 3시드 → 반폭 ±63 %** (LPSCl1.6 600 K 실측). **"D 를 자릿수로만 말한다" 면 3개로 되고,
"몇 % 다르다" 를 말하려면 어림도 없다.**

**(b) 비(ratio) 를 재려면** — ⚠ **이 논문에 없는 부분, 우리가 붙였다**

로그공간 전파 (두 계 각각 M 시드, 독립, 합동자유도 2M−2):
```
SE(ln R) = CV · √(2/M)          R 의 95 % CI = R · exp( ± t_{2M−2,0.975} · SE )
```

| M (계당 시드) | R 의 95 % CI 배율 | **폭(fold-span)** |
|---|---|---|
| **3 (현재)** | **× [0.61, 1.65]** | **2.72** |
| 4 | × [0.68, 1.47] | 2.15 |
| 6 | × [0.75, 1.33] | 1.77 |
| 10 | × [0.81, 1.23] | 1.51 |
| 20 | × [0.87, 1.15] | 1.33 |
| 50 | × [0.92, 1.09] | 1.19 |

**(c) 어떤 크기의 차이를 "있다" 고 말하려면 몇 개가 필요한가**

| 주장하려는 비 R | 필요 M (계당) |
|---|---|
| R = 1.08 | **64** |
| **R = 1.33** *(철회된 그 값)* | **6** (CV 25.3 % 로 하면 **8**) |
| R = 1.5 | 4 |
| R = 2.0 | 3 |
| R = 2.6 *(comp1 → modelc D 비)* | **2** |

**(d) 🔴 우리 1.33× 철회를 사후가 아니라 사전으로 재현하기**

**단일시드 vs 단일시드** 비교에서 시드 노이즈만으로 생기는 로그 표준편차:
```
SE(ln R)|_{M=1} = CV·√2 = 0.221 × 1.414 = 0.3125
```
- 측정된 **1.33×** → `ln 1.33 / 0.3125 = ` **0.91 σ**  ⇒ **1σ 도 안 된다. 완전히 잡음.**
- 참고로 우리 baseline 의 **2.56×** (comp1 → modelc D(600 K)) → `ln 2.56 / 0.3125 =` **3.01 σ** ⇒ 잡음으로는 설명 안 된다.

⇒ **판정: 이 논문 기준으로 시드 3개는 —**
> - **"자릿수 / 2배 이상의 차이"** 를 말하기에는 **충분**하다 (R ≥ 2 는 M = 3 으로 판별 가능).
> - **"1.3× 수준의 차이"** 를 말하기에는 **부족**하다 → **계당 6–8 시드**.
> - **"통계적으로 동등하다"(1.0 근처)** 를 **적극적으로 주장**하기에는 **크게 부족**하다 → **수십 개**.
>   ⚠ 그래서 2026-07-09 의 올바른 서술은 *"동등하다"* 가 아니라 **"구별되지 않는다(not distinguished)"** 다.
>   실제로 CSV 주석이 `# NOT DISTINGUISHED` 로 적혀 있다 — **그 표현이 맞다.** 지켜야 한다.
> - **Ea 오차막대(600 K 3-시드)** 는 위 (a) 표 기준 **±50 % 급 정밀도**의 도구다. Ea 자체는 로그기울기라
>   D 보다 산포가 작지만, **3점으로는 정규성 검정도 lack-of-fit 검정도 불가능**하다.

**비용 감각** *(digest 계산)*: 3 → 6 시드는 MD 시간 2배로 비의 CI 폭을 **2.72 → 1.77** 로 줄인다.
6 → 20 은 다시 3.3배 비용으로 1.77 → 1.33. **√M 이라 수확체감이 가파르다** — 그래서 "시드를 늘린다" 보다
**"CV 자체를 줄인다"**(셀 확대 → Li 수 증가, 생산 시간 증가) 가 더 나은 투자일 수 있다.
Pranami 의 LJ 유체가 CV 0.1 % 인 이유가 정확히 **입자 수** 였다는 점을 기억할 것.

### 9-6. 유한크기 — 우리는 이 보정을 아예 안 한다

Pranami: **가장 큰 상자(용매 78,233개)에서도 D_o 대비 −22 %** *(digest 계산)*.
우리: **셀 크기 하나**(62원자, Li 27개) → D vs 1/L 을 그릴 점이 없다 ⇒ **보정 불가능**.

⚠ **단, 그대로 옮기면 안 된다.** 그 보정식 `D = D_o + ξk_BT/(6πηL)` 은 **유체동역학(hydrodynamic) 상호작용**에서
나온다 — 주기 이미지끼리 흐름장으로 상호작용하는 것. **고체 전해질 안의 Li 홉핑에는 그 물리가 없다.**
우리 계의 유한크기 효과는 다른 기원이다 (홉 통계, 상관홉/Haven, 격자 변형, 무질서 배열의 유한성).
⇒ **인용할 수 있는 것은 "유한크기가 D 를 수십 % 바꿀 수 있고 한 크기로는 못 잰다" 는 사실**이지,
**보정식 자체가 아니다.** (우리 baseline 의 `Haven = 1` 가정도 같은 종류의 미검증 가정이다.)

### 9-7. 우리 MSD 창 2–50 ps 는 이 논문 기준으로 어떤가

⚠ **이 논문은 적합 구간의 수치 권고를 주지 않는다** (§11-3). 하지만 두 가지 간접 결과가 우리 창을 평가한다:
1. **창의 위쪽 끝이 독립 표본 수를 정한다** — τ=50 ps 는 200 ps 궤적에서 **독립 원점 4개**뿐.
   창을 2–25 ps 로 줄이면 8개, 2–10 ps 면 20개. **긴 τ 를 넣을수록 그 점의 신뢰도가 급락한다.**
2. **창 안에서 등분산이 깨진다** — Fig. 3 이 보여주듯 SD 산포는 τ 와 함께 커지고,
   여기에 더해 **우리 창의 양 끝은 독립 표본 수가 25배 차이**난다 (100 vs 4).
   ⇒ **등가중 OLS 는 τ=50 ps 근처의 잡음 큰 점에 τ=2 ps 점과 같은 무게를 준다.**
   Pranami 의 처방을 그대로 적용하면 **WLS (weights = 1/variance)** 가 맞다.
   그의 LJ 사례에서 OLS→WLS 는 절편을 **0.28 %**, 기울기를 **2.9 %** 움직였다 (§5-2) — 작아 보이지만
   **그 계의 CV 가 0.1 % 였다.** CV 22 % 인 우리 계에서는 훨씬 크게 움직일 수 있다.
   *(⚠ 실제로 얼마나 움직이는지는 안 해봤다 — §13)*
3. ✅ 우리 규약 **"창을 옮겨 구제하지 않는다"**(`beta_gate_seed_policy.md` 규칙 4)는 이 논문과 정합적이다.
   Pranami 도 τ 범위를 결과 보고 고르지 않았다.

## 10. 적용 인사이트 — 우리 연구에 어떻게

- ① **"시드 3개" 를 목적별로 나눈다.** *자릿수·2배 이상* 주장 → 3개로 충분. *1.3× 급* 주장 → **6–8개**.
  *동등 주장* → 실질적으로 불가하므로 **"구별되지 않는다"로 표현**한다. 이걸 규약 문장으로 못박으면
  "시드를 몇 개 돌려요?" 라는 질문이 매번 다시 안 나온다.
- ② **던지기 전에 M 을 계산한다.** 보고량 카드(`kb/templates/estimand_card.md`)에 **"주장하려는 최소 효과 크기 R"**
  칸을 만들고, `M = f(CV, R)` 을 §9-5 (c) 표로 채운다. **정지 규칙을 결과 전에 선언한다**는 기존 규율과 정확히 맞물린다.
- ③ **R_SD(τ,δ) 를 한 번은 우리 궤적으로 그린다.** 그림 하나(Fig. 2 재현)면 우리 MTO 의 실효 표본 수가 확정된다.
  이건 새 MD 없이 **이미 저장된 궤적으로 가능**하다. 그리고 그 그림은 SI 감에 바로 쓸 수 있다.
- ④ **`n_origins` 로 오차막대를 만들지 않는다** 를 코드 주석·규약에 명시. 지금은 안 하고 있지만 명시돼 있지 않다.
- ⑤ **MSD 창에 WLS 를 시험해 본다.** 등가중 OLS 대비 D 가 얼마나 움직이는지 **한 번 재보고**,
  차이가 시드 산포 안이면 "OLS 로 충분" 을 근거와 함께 적어둘 수 있다 (지금은 근거 없이 OLS 다).
- ⑥ **배열(quenched disorder) 분산은 이 논문 밖이다** — 별도 축으로 세운다. 속도 시드만 늘리는 것으로는
  "조성의 D" 에 대한 CI 가 안 나온다.
- ⑦ **오차 표기 관례를 바꾼다**: `D̄ ± S` (산포) 와 `D̄ ± S/√M` (68 %) 와 **95 % CI** 를 구분해 적는다.
  우리 CSV 주석은 이미 *"±0.047 is the SD of the seed-combination distribution — NOT a confidence interval,
  NOT a standard error"* 로 정확히 이 구분을 하고 있다 — **그 관례를 원고·화면까지 확장**한다.

## 11. 사용자 질문 7개 — 정면 답변 (짧게)

**1. 무엇이 문제인가 / 편향의 방향·크기** → §4-1.
편향은 **두 층**이다. (A) 단일 궤적의 D 가 **초기조건 쪽으로** 치우친다 — 방향은 계마다 무작위, 크기는
LJ 유체에서 CV 0.11–0.20 %, 단일 거대분자에서 **2.7–4.1 %**, 우리 계에서 **≈22 %**.
(B) MSD 회귀가 뱉는 오차는 **애초에 무자격**(정규성 W=0.8747 p<.0001, 등분산 위반) — 방향이 아니라 **무효**.
그리고 세 번째로 (C) **겹친 시간원점으로 √n 을 하면 정밀도를 최대 √(τ/δ) 배 과대평가**한다.

**2. 올바른 절차** → §4-2 Step 0–6. 요약: **δ 를 R_SD 로 재고(δ≥τ) → MSD·CI 는 CLT 로 → D 는 회귀 점추정만 →
M 개 독립 시뮬레이션의 D 표본 → 정규성 검정 후 t-CI → (유한크기면) WLS 로 1/L 외삽.**

**3. MSD 적합 구간과 오차의 관계** → **명시적 권고 기준 없음 (n/a).** 저자는 창을 수치로 지정하지 않는다.
간접 결과 둘: (i) 창의 최대 τ 가 독립 표본 수를 ⌊T/τ⌋ 로 정한다, (ii) SD 산포가 τ 와 함께 커져 등분산이 깨진다(Fig. 3)
→ 등가중 OLS 부적절. 우리 창 2–50 ps 에 대한 해석은 §9-7.

**4. 필요한 궤적 수 / 길이** → **목표 정밀도별 수치 권고 없음 (n/a).** 논문이 실제로 쓴 것:
LJ 유체 **100 MIS** × (평형 100k + 생산 1M 스텝), 응집체 **10 MIS** × (평형 500k + 생산 **10M** 스텝).
CLT 경험칙 **~40 표본**, 실제로는 τ 당 **>30,000 SD 표본**. 우리 수치로 환산한 필요 M 은 **§9-5 (digest 계산)**.

**5. 다중 시간원점** → **다룬다. 핵심 결과가 이것이다: δ ≥ τ** → §4-3. 겹치면 SD 가 상관되고(δ=τ/4 에서 R_SD≈0.85),
"원점이 많다"는 것이 "표본이 많다"를 뜻하지 않는다.

**6. 저자가 적은 한계** → §12-1.

**7. SI 의 표·유도** → §5-2, §5-3, §7 에 전부 옮겼다. **SI 의 진짜 실무 소득은 두 개**:
① **lack-of-fit 검정** — MIS 가 있어야만 pure error 를 분리할 수 있고, 그래야 "모형에 항이 빠졌다"를 객관적으로 안다.

## 12. ★ 주의 / 한계 / 비판 (over-claim 방지)

### 12-1. 저자가 스스로 적은 한계

1. *"The findings from this work should be applied **after careful consideration of the system** being studied and time and length scales involved."*
2. **느리게 변하는 형태 자유도**를 가진 계에서는 이 문제가 훨씬 어렵다 (Calderon 등 인용).
3. **단일 D 로 동역학을 대표하는 것 자체가 부적절할 수 있다** — Thompson et al. 의 효모 mRNA 는
   D 가 정규분포가 **아니었고**, 그 원인은 세 가지 확산 모드(random / confined / directed)였다.
4. **복잡계에서 독립 초기 상태를 만드는 것은 nontrivial** — 속도 재추출은 관행일 뿐 보장이 아니다.
5. **D vs 1/L 모형에 항이 빠져 있다** (lack of fit p<.0001). 1/L², 1/L³ 을 넣을 **물리적 근거가 없어** 안 넣었고,
   더 정확한 D(L) 유도는 **범위 밖**이라고 명시.
6. **앙상블(NVT vs NVE)이 D 를 유의하게 바꾼다** (N=125, 95 % 수준).
7. 아주 긴 런은 **유한 수치정밀도로 인한 drift** 로 동역학이 변한다 → 그래서 "적당한 길이 × 여러 개" 를 권한다.
8. 물리계 종류별 확산 논의는 범위 밖.

### 12-2. 내 비판 — 논문의 약한 곳

- **일반화의 범위가 좁다.** 실증은 **LJ 유체 하나**와 **그 안의 강체 응집체 하나**뿐이다.

  "δ ≥ τ" 도 **이 계에서 측정된 결과**이지 보편 법칙으로 증명된 것이 아니다 — 저자도 *"in the system studied here"*
  라고 한정한다. **우리 계에서 다시 재야 한다.**
- **"몇 개면 되나" 에 답하지 않는다.** 100 과 10 이라는 숫자는 나오지만 **왜 그 숫자인지, 목표 정밀도와 어떻게 연결되는지**

## 13. ⚠ **못 하는 것 / 확인 못 한 것** (필수 절)

**A. 이 digest 가 못 하는 것**
1. **비(ratio) 의 오차에 대한 논문의 권위는 없다.** §9-5 (b)(c)(d) 는 **전부 digest 계산**이다 —
   이 논문이 아니라 **우리가 붙인 로그공간 전파**이고, 정규성·독립성·등분산을 가정한 근사다.
   특히 **비의 자유도 처리**(합동 df = 2M−2)는 단순화다. 엄밀히는 Welch–Satterthwaite 나 부트스트랩이 맞다.
2. **CV ≈ 22 % 는 3개 시드에서 나온 CV 다.** 3표본 CV 자체의 불확실성이 매우 크다 (대략 ±40 % 상대).
   따라서 §9-5 의 필요 M 은 **자릿수 감각**이지 정밀한 처방이 아니다. 6개 세트 평균을 쓴 이유가 그것이다.
3. **그 CV 는 `gen0_pre_gate` 프로토콜(2026-08-19 이전) 산물**이다. 현행 4-창/MTO/궤적보존 규약에서
   시드 산포가 같은지 **확인 안 했다.**
4. **comp1/modelc 자체의 시드 CV 는 모른다** — 그 계는 온도당 단일 궤적이다. §9-5(d) 의 2.56× 계산은
   **modelc/b2o3 재시드의 CV 를 comp1 에도 적용**한 것이다. 검증되지 않은 이식이다.
5. **WLS 가 우리 MSD 창에서 D 를 얼마나 바꾸는지 안 재봤다** (§10 ⑤ 는 제안이지 결과가 아니다).
6. **R_SD(τ,δ) 를 우리 궤적으로 그려보지 않았다.** §9-3 의 "독립 원점 수" 는 **δ ≥ τ 규칙을 우리 계에 가정**하고
   센 것이다. 우리 계의 실제 δ_min 은 τ 보다 작을 수도, 클 수도 있다.

## 14. 인용 가능 문장 (deck / paper 용)

- "Pranami and Lamm showed that, even for a Lennard-Jones fluid, two molecular dynamics trajectories differing only in
  their initial velocities can yield mean squared displacements whose 95 % confidence intervals do not overlap,
  demonstrating that a single trajectory does not guarantee ergodic sampling." *(Fig. 4)*
- "Because squared displacements are neither normally distributed (Shapiro–Wilk W = 0.87, p < 10⁻⁴) nor homoscedastic,
  the uncertainty returned by a least-squares fit of MSD versus time is not a valid estimate of the uncertainty in D;
  the uncertainty must instead be obtained from an ensemble of independent simulations." *(SI §1 + 본문)*
- "Independent sampling of squared displacements requires that successive time origins be separated by at least the lag
  time itself (δ ≥ τ); with overlapping origins the squared-displacement autocorrelation remains high, so the number of
  time origins overstates the number of independent samples." *(Fig. 2)*
- "Finite-size effects remained at the level of ~20 % even for the largest simulation box examined (78,233 solvent
  particles), and could only be quantified because multiple independent simulations were run at each box size." *(Table 3 + digest 계산)*

⛔ **우리 값과 섞어 쓸 수 있는 문장은 없다** — 단위가 무차원이고 계가 다르다.
우리 쪽 서술은 **§9-5 의 digest 계산**으로 하고, 그 출처를 "이 논문의 절차 + 우리 실측 CV" 로 밝힌다.

## 15. 용어 미니 사전 (이 digest 안에서만)

| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|
| **SD** (squared displacement) | 입자 **하나**의, 시간 τ 동안의 변위 제곱 | 이것들의 평균이 MSD. **SD 는 정규분포가 아니다** |
| **MSD** | SD 를 입자·시간원점에 대해 평균한 것 | Einstein 관계로 D = 기울기/6 (3D) |
| **τ (lag)** | 변위를 재는 시간 간격 | 크면 통계가 나빠지고 등분산이 깨진다 |
| **δ (time-origin spacing)** | 이웃한 두 시간원점 사이 거리 | **δ ≥ τ 여야 SD 표본이 독립** |
| **MIS** (multiple independent simulations) | 초기 조건만 바꾼 여러 궤적 | **오차의 유일한 정당한 출처** |
| **MTO** (multiple time origins) | 한 궤적 안에서 여러 원점으로 평균 | 표본을 늘리지만 **독립 표본은 안 늘린다** |
| **homoscedasticity (등분산)** | 잔차 분산이 설명변수에 무관 | 깨지면 OLS 의 오차가 무효 → **WLS** |
| **Shapiro–Wilk W** | 정규성 검정. H₀ = 정규 | **작은 p 면 정규 기각.** W 는 1 에 가까울수록 정규적 |
| **Lack-of-Fit 검정** | 잔차를 "모형 부적합" + "순수 잡음" 으로 분해 | **반복(MIS)이 있어야만 가능.** 모형에 항이 빠졌는지 객관 판정 |
| **Pure error** | 같은 조건 반복 사이의 순수 산포 | lack-of-fit 의 분모 |
| **Pearson 잔차** | 표준잔차 × √(가중치) | WLS 진단용 |
| **CLT (중심극한정리)** | 표본이 크면 **평균**이 정규 | 원자료(SD)가 비정규여도 **MSD 평균**은 정규 |
| **CV** (변동계수) | σ / μ | 시드 노이즈의 무차원 척도. 이 digest 의 공용 화폐 |
| **ξ = 2.837297** | 3D 주기 격자의 Ewald-형 상수 | 유한크기 보정식의 계수 |
