## 0.5 처음 읽는 사람을 위한 배경 (이 논문이 전제하는 것들)

**① HF 가 어디서 오나 — 두 줄짜리 연쇄**
LiPF₆ 전해질은 스스로 깨진다(Eq 1): `LiPF₆ → LiF↓ + PF₅`.
그 PF₅ 가 미량의 물과 만나면(Eq 2): `PF₅ + H₂O → 2HF + POF₃`.
결과가 **둘 다 나쁘다**: ⓐ **LiF 가 전극 표면에 석출**된다 — Li⁺ 투과성도 전자전도도도 낮은
wide-gap 절연체라 계면 임피던스를 올린다. ⓑ **HF 가 생긴다** — 양극에서 **전이금속을 녹여낸다**
(금속 용출 = 용량 퇴화의 주 경로).
PVDF 바인더도 HF 생성에 기여한다고 본문이 덧붙인다.

**② 그래서 코팅을 씌운다 — 그런데 "왜 듣는지"를 몰랐다**
Cho 2000 의 Al₂O₃/LiCoO₂ 이후 산화물·불화물 코팅이 쏟아졌지만, 보호 기전은 미해결이었다.
유력 후보가 **HF-scavenging**(HF 포획): 실험에서 *용출 금속량 ∝ 전해질 HF 량*이고,
산화물 코팅을 넣으면 **둘 다 같이** 줄어든다. Myung 2005 가 직접 확인한 반응이
`Al₂O₃ + 6HF → 2AlF₃ + 3H₂O` (Eq 3).
즉 **코팅이 HF 를 대신 먹고 불화물로 바뀐다**. 그리고 그 불화물 층이 **2차 물리장벽**이 된다.

**③ 이 논문이 하는 일 — "에디슨식 탐색"을 열역학 4속성으로 대체**
① **HF 포획 경향** −ΔH_s-HF (얼마나 세게 먹나)
② **부피당 포획능** Ω_V (mol-HF cm⁻³) — 같은 양을 먹으려면 코팅이 얼마나 두꺼워야 하나 = **Li⁺ 확산 장벽 두께**
③ **무게당 포획능** Ω_G (mol-HF g⁻¹) — 셀 비용량·에너지밀도에 직접
④ **가역 Li 손실 경향** — 코팅(과 그 불화물)이 작동 전압에서 Li 를 먹어버리면 용량이 준다
이 4개를 **한 장의 조합 설계도표(Fig. 5)** 에 올려 81종을 동시에 비교한다.

**④ 왜 실험 열화학표로 안 하고 DFT 로 하나**
불화물의 실험 생성엔탈피가 **표에 아예 없거나**(81 중 40 반응), 있어도 **불확도가 ±0.05–0.4 eV** 다.
FeF₃ 는 문헌 간 격차가 ~0.5 eV. → 열화학표만으로는 순위를 못 매긴다. 그래서 DFT.
단 DFT 가 맞는지를 **표가 믿을 만한 단순 금속 화합물**(알칼리·알칼리토·Al·Zn)에서 먼저 검증한다(Fig. 1).

**⑤ 읽을 때 주의**
자체 실험 0. 모든 검증은 **문헌 실험의 *순위*와 맞는가**로 이뤄진다. 0 K·PV 무시·ICSD 결정상 가정이고,
HF/H₂O 는 **고립 분자**로 다룬다(용매화 없음). 그리고 두 개의 게이트 문턱 중 **상한은 저자가 손으로 고른 값**이다(§10).

## 1. 한 줄 요약

**LiPF₆ 계 액체 LIB 양극 코팅을 "HF 를 얼마나 잘 먹나 + 그 대가로 가역 Li 를 얼마나 잃나"라는 4속성 열역학으로 환원하고, s·p·d-block 이원 산화물/불화물 쌍 81종을 DFT(VASP-PBE·OQMD)로 전수 계산해 한 장의 조합 설계도표(Fig. 5)에 올린 논문.** 게이트(−ΔH_s-HF ≥ 0.30 eV HF⁻¹ = 양극 자신의 HF 공격 발열보다 세게 + 불화물 전환전압 ≤ 3.0 V = 방전 하한 아래)로 **81 → 40 → 27** 을 남기고, 이미 검증된 코팅(Al₂O₃·MgO·TiO₂·ZrO₂)이 상위에 저절로 재현되는 것으로 틀을 검증한 뒤, **미탐색 3가 전이금속 산화물 Sc₂O₃·Ti₂O₃·V₂O₃·Cr₂O₃·Mn₂O₃·Y₂O₃** 를 새 후보로 예측한다. 부가로 **LiF-scavenging**(석출된 LiF 를 삼원 Li–M–F 로 흡수해 치우는) 이라는 **새 보호기전**을 제안하고 29개 반응의 엔탈피를 낸다. 🔑 가장 재사용성 높은 결론은 추천 목록이 아니라 **"HF 포획은 생성물이 상온에서 안정한 고체 불화물일 때만 보호가 된다"** — SiO₂(→SiF₄ 기체)·B₂O₃(→BF₃ 기체)·P₂O₅(→PF₅ 기체, 오히려 HF 재생산) 의 실험적 실패를 이 한 조건이 설명한다.

## 2.5 이 틀이 답하는 질문 4개 (= Fig. 5 의 네 패널)

코팅을 고르는 일은 네 질문이다. 설계도표의 각 패널이 하나씩 맡는다.

1. **HF 를 양극보다 먼저·세게 먹나** → −ΔH_s-HF ≥ 0.30 eV HF⁻¹ *(하한: 양극 자신의 HF 공격 발열 ≈0.3)*
2. **너무 세게 먹지는 않나** → −ΔH_s-HF ≤ −ΔH[CaO] = 1.50 *(상한: "과잉 반응성" — ⚠ 손으로 고른 값)*
3. **얇게 발라도 충분히 먹나** → Ω_V, Ω_G 클수록 좋다 *(문턱 없음, 연속 서열)*
4. **가역 Li 를 안 훔치나** → V_MxF ≤ 3.0 V *(방전 하한. 불화물 전압이 산화물보다 항상 높으니 불화물로 건다)*

> **비용 순서가 곧 단 순서인 [Xiao19] 깔때기와 달리, 여기는 단이 없다.** 네 속성을 **동시에** 한 도표에 올리고
> 사람이 "성질 사각형(property rectangle)"을 그어 우열을 읽는다 — **깔때기 이전 세대의 조합 설계도표**다(§6c).

### 3b. DFT 정확도 — **실험 불확도와 나란히 판정** (Table 1 전량) ★

| 화합물군 | mean-CSU: ΔH_s-HF [eV HF⁻¹] | V(MₓO₁⸝₂) [V] | V(MₓF) [V] ‖ MAE: ΔH_s-HF | V(MₓO₁⸝₂) | V(MₓF) |
|---|---|---|---|---|---|
| **Simple**(알칼리·알칼리토·Al·Zn) | 0.021 | 0.018 | 0.017 ‖ **0.029** | **0.027** | **0.031** |
| **p- and d-block**(Be 포함) | 0.070 | 0.014 | 0.070 ‖ **0.157** | **0.160** | **0.277** |
| **All** | 0.055 | 0.015 | 0.053 ‖ **0.125** | **0.128** | **0.219** |

- **CSU** = combined standard uncertainty, `CSU = (Σᵢ cᵢ²uᵢ²)^½` (cᵢ = 반응식 계수, uᵢ = 열화학표의 ΔH_f 불확도). **35 쌍**만 CSU 계산 가능.
- 읽는 법: **MAE 를 0 과 비교하지 않고 mean-CSU 와 비교한다.** simple 군은 MAE ≈ CSU(둘 다 0.02–0.03) → *실험만큼 정확*.
  p/d 군은 MAE 0.157 vs CSU 0.070 → 차이 0.087 eV — 저자 판정: "상대적으로 작다 → 허용 가능".
  전압은 "MAE−CSU ≈ 0.15–0.20 V" → **DFT 전환전압 정확도를 ±0.20 V** 로 자기선언.
- **DFT+U 는 도움이 안 된다**: Fe·Co·Mn·Cr·Ni·V·Cu 화합물에 Wang 2006 U 를 적용해도 MAE **0.157 → 0.149 eV HF⁻¹**
  (개선폭 0.008 = 실험 CSU 0.070 의 **1/10**). → 본 논문은 **plain GGA 결과를 본문값으로 채택**.
  🔑 이유(명시 안 됨, 물리): Eq 4 는 TM 의 **형식 산화수를 바꾸지 않는다**(O²⁻→F⁻ 로 음이온만 교체) → +U 의 d-전자 자기상호작용 보정이 **양변에서 상쇄**된다.
- **0 K vs 298 K**: 대표 5반응 차이 평균 **≈11 meV**(SI Table S2: Al₂O₃ 0.014 / Li₂O 0.008 / MgO 0.013 / ZrO₂ 0.015 / TiO₂ 0.008) ≪ 평균 실험 불확도 55 meV → **혼용 정당화**.
- **분자 보정 불필요**: Eq 5 에서 `(½E[H₂O] − E[HF])` 는 **모든 반응에 공통**이라 *순위*에서 소거된다. Fig. 1 이 보정 없이도 실험과 일치 → "분자 DFT 오차가 있어도 서로 상쇄된다"고 자인.

## 4. DFT / 계산 방법 ★

- **code**: **VASP** (refs 65–68). 버전 미기재.
- **functional**: **PBE-GGA** (refs 70,71). **vdW 보정 없음**. → 분자(HF·H₂O) 포함 계에 vdW 무보정.
- **pseudo**: **PAW** (Blöchl, ref 69). 어떤 PAW 세트(POTCAR 버전·valence)인지 **미기재**.
- **ecut**: **520 eV** (전 화합물 공통).
- **k-points**: **8,000 k-points per reciprocal atom** 의 명목 밀도 (= OQMD 표준). **분자는 Γ-only**.
- **DFT+U**: Dudarev 회전불변형(ref 72), U 값은 **Wang/Maxisch/Ceder 2006**(ref 73). **Fe·Co·Mn·Cr·Ni·V·Cu 산화물·불화물에만** 시험적으로 적용 → **채택 안 함**(§3b). 🔑 우리 MP GGA/GGA+U hull 과 **같은 U 계보**.
- **구조 / 이완**: **ICSD**(ref 74) 실험 구조에서 출발, **내부·외부 자유도 전부 완전 이완** 후 **final static run** 으로 총에너지.
- **supercell / nat**: **없음** — 전부 이원 화합물 원시포. 결함·표면·계면 슬랩 **0**.
- **무질서 처리**: **없음** (무질서 상 없음. ICSD 정렬 결정상만).
- **온도·압력**: **T = 0 K**, **PV 항 무시** → H ≈ E_DFT. 진동 자유에너지·배위 엔트로피 **없음**.
- **분자**: HF·H₂O 를 **고립분자**(Γ-only)로. **용매화·활동도 없음** — 활동도 1 가정과 동치.
- **프레임워크**: **OQMD** (refs 75,76). Materials Project 가 **아니다** → hull·총에너지 세대가 우리와 다르다(§7).
- **상평형 도구**: **GCLP**(grand canonical linear programming, refs 55·83–85) — Table 2 양극+HF 반응의 **산물 결정에만** 사용. **코팅 반응(Eq 4·7·8·15)의 산물은 가정된 것**이지 hull 최소화 결과가 아니다. ⚠ 이 비대칭이 §6b 대조의 핵심.
- **AIMD / MLIP / NEB / 포논 / COHP / Bader**: **전부 없음**. kinetics 는 명시적으로 향후 과제로 미룸.
- **특이사항**: Eq 4 를 **HF 1몰 기준**으로 정규화해 HF·H₂O 화학량을 전 반응에 고정(1 : ½) → **순위가 분자 에너지에 독립**이 되게 설계. 이 설계 덕에 Fig. 1 에서 **분자 에너지 보정이 불필요**함을 보일 수 있었다.

## 5. 결과 — 섹션별 상세 (그림 실독 포함)

### 5.1 단순 금속 화합물에서 DFT 검증 (`Fig. 1`) ★

**실제로 본 것**: 축 x = −ΔH_s-HF **실험**, y = −ΔH_s-HF **DFT**, 둘 다 **0–3.0 eV HF⁻¹**. 점 **11개**(Zn·Al·Mg·Ca·Sr·Li·Ba·Na·Cs·K·Rb — Be 는 `Fig. 2` 로 감). 점선 대각 = 완전 일치.

- **모든 점이 대각선 위에 거의 정확히 얹혀 있다.** 오차막대(수직·수평 CSU)가 마커보다 작다 → 눈으로 "보정 불필요"가 읽힌다.
- **파선 십자**: 수평 y ≈ 1.70 / 수직 x ≈ 1.72 (figure-read) = **Li₂O 의 −ΔH_s-HF**. Table S1 의 DFT 1.70 과 일치.
  이 선의 의미 = **Eq 14 의 경계**: 이 선보다 **아래**에 있는 산화물은 *그 불화물 전압이 산화물보다 높다*.
  즉 Rb·K·Cs·Na·Ba·Sr **6개만 선 위**에 있고 나머지는 전부 아래 — 그래서 게이트를 불화물로 건다.
- **알칼리토 서열이 눈으로 보인다**: Mg(1.16) < Ca(1.50) < Sr(1.73) < Ba(1.88) — 본문이 "표면 반응성 서열과 동일"(ref 87)이라 부르는 그 추세.
- Zn(0.57) 과 Al(0.76) 이 최하단 — **가장 온건한 포획자들이 실제로 쓰이는 코팅**이다.

### 5.2 p·d-block 에서는 *실험이 못 믿을* 만하다 (`Fig. 2`) ★

**실제로 본 것**: 같은 축, 범위 **x −0.1–1.2 / y 0–1.05+**. 점 ~30개, 라벨은 **산화수 표기**(Fe³⁺ᵃ/Fe³⁺ᵇ 처럼 출처별 중복 포함). 파선 = 완전 일치.

- **수평(실험) 오차막대가 압도적으로 길다.** Mn⁴⁺ᶜ·Hg²⁺·Nb⁵⁺·Sb³⁺·Zr⁴⁺·Fe²⁺ᵇ 등은 막대 길이가 **±0.1–0.3 eV** 로 마커 간 거리보다 크다 → *"실험표로 순위를 못 매긴다"* 는 본문 주장이 그림 하나로 증명된다.
- **산포가 대칭이 아니다** (figure-read, 본문 미언급): **Sn²⁺·Sb³⁺·Bi³⁺·Pb²⁺ 등 p-block 무거운 양이온이 파선 *위*로 0.2–0.35 eV 치우친다**(DFT 가 더 발열). 반대로 **In³⁺·Fe²⁺ᵇ·Cu²⁺ 는 아래**. → MAE 0.157 은 **등방 잡음이 아니라 화학군별 편향**을 품고 있다. §10 비판 항목.
- 같은 원소가 출처(a/b/c)에 따라 **0.1–0.4 eV 떨어진 두 점**으로 찍힌다(Fe³⁺ᵃ vs Fe³⁺ᵇ, Mn²⁺ᵃ vs Mn²⁺ᶜ) — 실험 문헌 간 불일치의 시각적 증거.
- **Y³⁺(≈1.07, 1.05) 과 Pb²⁺(≈0.70, 1.02) 이 최상단**. Y₂O₃ 가 신규 추천에 들어간 근거가 여기 보인다.

### 5.3 전환전압의 DFT 검증 (`Fig. 3`) ★

**실제로 본 것**: 두 패널. 왼쪽 **Oxides**(x,y ≈ −0.25 – 3.0 V), 오른쪽 **Fluorides**(x,y ≈ −0.3 – 4.3 V). 파선 = 완전 일치.

- 두 패널 모두 **점이 파선에 붙어 있다**. 불화물 쪽 오차막대(CuF₂·MnF₄·HgF₂·CrF₄·SbF₃)가 눈에 띄게 길다 → Table 1 의 "불화물 CSU 0.070 V" 가 눈으로 확인된다.
- 🔑 **축 범위 자체가 결론이다**: 산화물은 3 V 안에 다 들어오는데 **불화물은 4.3 V 까지 간다**. "불화물이 Li 를 더 잘 먹는다"가 축 눈금으로 읽힌다.
- 최하단(≈ −0.2, −0.2)의 점 = **CaO**(복원값 −0.23; 라벨이 잘려 보이지 않음, figure-read 추정). **BeO 는 (0.0, 0.02)** 부근 — 복원값 0.00 과 일치.
- 좌하단 밀집군 Al₂O₃·ZrO₂·Ti₂O₃·TiO₂ = **저전압 = Li 를 안 먹는** 좋은 코팅들. 우상단 CoO·NiO·CuO·Ag₂O·HgO = 전형적 **전환 양극** 물질(2–2.6 V).

### 5.4 Li 손실 게이트 (`Fig. 4`) ★★ — 이 논문에서 우리 축과 가장 가까운 그림

**실제로 본 것**: x = **산화물** 전환전압(DFT), y = **불화물** 전환전압(DFT), 둘 다 0–5 V. 점선 = 파리티. **파선 = x=3, y=3 의 "안전 창"**. 범례 s/p/3d/4d/5d.

- **거의 모든 점이 파리티 선 위쪽**: 불화물 전압 > 산화물 전압. 세로 간격은 **≈1.0–1.5 V**(본문) — 본 digest 복원값으로 평균 **1.16 V**, 중앙값 **1.30 V**(§15).
- **파리티 아래로 내려간 것은 빨간 삼각(s-block) 뿐**이다(확대 크롭으로 재확인). 본문이 지목한 **Rb·Cs·K·Sr·Na·Ba 6개**와 개수가 맞는다.
  - ⚠ **다만 본문 목록은 한 종을 빠뜨린 것으로 보인다**: Table S1 + Eq 14 로 계산하면 **Pb₂O(Pb⁺, −ΔH = 2.52 > 1.70)** 도 같은 조건을 만족해 V(oxide) 2.14 > V(PbF) 1.32 다. 그런데 `Fig. 4` 의 (2.14, 1.32) 자리에는 p-block 마커가 **안 보인다**(figure-read). → 플롯 누락이거나 본문 열거가 불완전. **결론에는 영향 없음**(Pb⁺ 는 어차피 후보가 아니다).
- **y > 3 V 구역에 점이 아주 많다** — 복원 결과 **81종 중 31종(38 %)이 Li 손실 게이트에서 탈락**한다. 5d 다이아몬드(Pt·Ir·Au·Re)와 4d 사각(Ag·Pd·Ru·Rh)이 그 상단을 채운다.
- **x > 3 V 는 점이 딱 하나**(오른쪽 끝 초록 다이아몬드, ≈(3.65, 4.65)) = **PtO₃**. 복원값과 정확히 일치 ✓.
- 🔑 이 그림의 설계 메시지: *산화물 전압만 보면 거의 다 안전해 보이지만(모두 x<3), **HF 를 먹은 뒤 생기는 불화물**로 보면 38 %가 탈락한다* → **게이트는 반드시 "진화 후"의 상(phase)에 걸어야 한다.**

### 5.5 조합 설계도표 (`Fig. 5`) ★★★ — 논문의 본체

**실제로 본 것**: 축을 공유하는 **2×2 패널**. 위 두 패널 y = −ΔH_s-HF (0 → 3.0 eV HF⁻¹, 위로 증가), 아래 두 패널 y = **[전환전압 − 3.0] V**(위 2.0 → 아래 −4). 왼쪽 두 패널 x = **Ω_V, 축이 반전**(왼쪽 0.30 → 중앙 0.00), 오른쪽 두 패널 x = **Ω_G**(중앙 0.00 → 오른쪽 0.10). 화합물은 **양이온 이름**으로 라벨. 범례 s/p/3d/4d/5d.

- **축을 거울로 놓은 이유**: 네 패널 모두 **바깥쪽으로 갈수록 좋다**(포획능 大). 좋은 재료는 도표의 **가장자리**에 있고 나쁜 재료는 **중앙**에 몰린다. 한 물질의 네 점을 가로·세로 선으로 이으면 **성질 사각형**이 되고, **그 사각형 *안*에 들어오는 물질은 전부 그보다 열등**하다.
- **그려진 사각형 2개**: 빨강 = **Mg²⁺**, 파랑 = **Al³⁺**. 본문의 *"Al₂O₃ 보다 −ΔH·Ω_V·Ω_G 를 동시에 능가하는 이원 산화물은 없다"* 가 이 사각형으로 시각화된다.
- **군집 구조(figure-read)**:
  - **빨강 삼각(s-block)** = 위쪽 높은 −ΔH(1.5–2.5) + 아래쪽 매우 낮은 전압(−2.4 ~ −3.0) → **Li 는 절대 안 먹는데 너무 반응성이 크고 포획능이 작다**.
  - **초록 다이아(5d)·연두 사각(4d) 상당수** = 아래 패널에서 **0 보다 위**(= 3 V 초과) → 탈락군.
  - **보라 원(3d)** 은 Al₂O₃/MgO 와 중앙 p-block 덩어리 **사이 영역**을 채운다 — 본문이 "가장 주목할 특징"이라 부른 그 위치. Sc³⁺ 가 그중 Al³⁺/Mg²⁺ 에 가장 가깝다.
  - **B³⁺** 가 오른쪽 Ω_G 패널의 **맨 오른쪽 끝**(0.086)에 홀로 있다 — **81종 중 무게당 포획능 1위**인데 −ΔH 0.28 로 게이트 탈락. **Pt⁶⁺**(PtO₃)는 왼쪽 Ω_V 패널의 **맨 왼쪽 끝**(0.259) = 부피당 1위인데 전압 +1.65(=4.65 V)로 탈락. → **양 극단이 둘 다 다른 축에서 죽는다**. 이 도표가 "동시 최적화"임을 가장 잘 보여주는 두 점.
  - 음수 −ΔH 10종(PdO·IrO₂·Pd₂O 등)은 위 패널 y 범위(0 시작) **밖**이라 위 패널에 안 보인다 — 도표를 "전 81종이 다 보인다"고 읽으면 안 된다(figure-read 주의).

### 5.7 스크리닝 결과 (`Fig. 6`) ★

**실제로 본 것**: x = 통과 **27 양이온**(왼→오), y = **정규화 HF 포획능 0–1.0**. 곡선 3개: **파란 원 = 평균 · 빨간 사각 = 무게당 · 검은 삼각 = 부피당**. 정규화 기준 = **BeO**(Ω_G 0.080, Ω_V 0.236 둘 다 최대).

- **x 순서 = 평균(파란 곡선) 내림차순**: Be²⁺ → Al³⁺ → Ti⁴⁺ → Mg²⁺ → Cr³⁺ → Ti³⁺ → Fe³⁺ → V³⁺ → Mn³⁺ → Sc³⁺ → Fe^2.67+ → Zr⁴⁺ → Ga³⁺ → V²⁺ → Fe²⁺ → Hf⁴⁺ → Mn²⁺ → Ca²⁺ → In³⁺ → Y³⁺ → Zn²⁺ → Cd²⁺ → Sn^2.67+ → Sn²⁺ → Pb²⁺ → Bi³⁺ → Tl⁺. **본 digest 의 재현과 완전 일치**(Zr⁴⁺/Ga³⁺ 한 쌍만 뒤바뀌는데 두 평균이 0.583 vs 0.586 으로 사실상 동률 — §15).
- **파란(평균) 곡선만 단조 감소**하고 **검은(부피) 곡선은 톱니**다: Cr³⁺(≈0.86)·Fe³⁺(≈0.84)·Hf⁴⁺(≈0.80) 에서 솟고 Sc³⁺(≈0.69)·Ca²⁺(≈0.50) 에서 꺼진다(figure-read). → **순위가 Ω_V/Ω_G 가중치에 민감**하다. 논문은 "둘이 똑같이 중요하다고 가정"한다고만 적는다 → §10 비판.
- **Hf⁴⁺ 가 가장 극단적**: 부피당 0.805 (상위권) ↔ 무게당 0.237 (27종 중 최하) — 본문의 *"HfO₂ 의 유일한 단점은 작은 Ω_G"* 가 그래프의 깊은 골로 보인다.
- 오른쪽 끝 Tl⁺(0.12)·Bi³⁺(0.20)·Pb²⁺(0.22) = 통과는 했으나 **독성 + 포획능 최하** — 실사용 후보가 아니다.

### 5.8 저자가 스스로 그은 경계 (본문 3.5) ⚠

논문이 자기 한계로 명시한 것 (인용할 때 반드시 같이 가져갈 것):

1. **반응식은 실험 관찰에 맞춰 *가정*된 것**이다. 실제 경로는 옥시불화물·수산화물·금속착물 같은 **중간상**을 거칠 수 있다.
2. **전환은 평균 전압**이라 중간 삼원 Li–M–F 상이나 **Li 삽입(insertion)** 경로를 무시한다.
3. 전해질에는 F⁻ 말고 **(OH)⁻·PF₆⁻·(CO₃)²⁻** 등 다른 음이온이 있다 — 넣으려면 **활동도**를 알아야 하는데 모른다.
4. **Eq 4 가 H₂O 를 만든다** → 그 물이 Eq 2 로 **HF 를 재생산**한다("water regeneration issue"). 코팅 수화가 완화책일 수 있다.
5. 실제 코팅은 **비정질**일 수 있다. 열역학 추세는 안 바뀔 것으로 보지만 **Li⁺/e⁻ 수송은 결정성에 크게 좌우**된다.
6. **kinetics 전면 부재**. 이온·전자 전도도, 접착력, 비용은 틀 **밖**이다.
7. 생성물이 **전해질에 녹으면 안 된다** — LiAsF₆ 가 그 예(전해질 염으로 쓰이는 물질).

### 6c. 무엇이 승계됐나 — 2014 → 2019 의 문법 번역

- **승계**: 열 이름 `G_{s-HF} (eV/HF)` — **2014 의 정규화 단위(eV per HF)가 그대로**다. HF-scavenging 개념·양극 공격 비교·전압 게이트 모두 승계.
  ⚠ **부호 규약이 뒤집혔다**: 2014 는 `−ΔH` 를 **양수**로, 2016 은 `G_s-HF` 를 **음수**로 보고한다 (Al₂O₃ 2014 **+0.76** ↔ 2016 **−0.380**).

  그리고 **HF 와 H₂O 의 기준상태가 바뀐다**: 2014 = **고립 분자 DFT 총에너지** → 2016 = **액체 H₂O + 전해질 내 희박(dilute) HF 의 실험 열화학값**. 용매화 이온은 표준 산화전위로(`ΔfG°(ionⁿ⁺) = −nFε`), 활동도는 `ΔrG = ΔrG° + RT ln Q`(Persson 2012 Pourbaix 형식).

- **추가된 것**: `E_d (V)` / `E_d (products) (V)` / `E_c (V)` 전압 3열 + **`HHI_R`·`HHI_P`**(Herfindahl–Hirschman 원소 **공급위험** 지수) → 경제성·공급망 축 도입. 그리고 **MOOP**(다목적 최적화) — **Pareto front + weighted-sum/rank-aggregation** 으로 순위를 낸다(2014 의 "사람이 사각형을 그린다"에서 기계적 순위로).

- 🔑 **2014 의 신규 예측이 적중한다**: **Sc₂O₃ 가 2016 HF-scavenger 순위 1위**(2위 MgO). 2014 가 *"Al₂O₃·MgO 에 가장 근접한 미탐색 후보"* 로 지목한 그 물질이다.

### 7b. 🔑 1저자 질문에 대한 답 — "우리 grand-potential 방법의 조상인가?"

> **아니다. 같은 *과(科)*, 다른 *속(屬)* 이다.**

- 우리 `oxidation_stability.json` 의 산화 onset(comp1/modelc 공통 **2.256 V**, LiS₄ 제외)은
  `pymatgen PhaseDiagram.get_element_profile(Li, …)` 로 **μ_Li 를 스캔**해 얻는다.
  방법 원전은 **Mo/Ong/Ceder 2012 → [Zhu15]** (`zhu2015_esw_grand_potential_origin.md`)이고, HT 화한 것이 **[Xiao19]** 다.
  **Aykol 2014 는 이 계보에 없다.** μ 를 열지 않고, 반응식을 가정하며, 산물을 hull 로 안 뽑는다.
- 다만 **접점은 두 군데** 있고, 둘 다 의미가 있다:
  1. **전압 = −ΔH/ne 라는 변환**은 공통 조상이다(Aydinol/Ceder 1997, ref 50·51 — Aykol 이 직접 인용). 우리 grand-potential onset 도 결국 같은 변환의 μ-스캔 판이다.
  2. **U 값 계보가 같다**: Aykol 은 **Wang/Maxisch/Ceder 2006**(ref 73)의 U 를 쓴다. 우리 MP GGA/GGA+U hull 도 같은 세트다. → **"같은 U 를 쓰는 두 DB(OQMD vs MP)"** 이지 같은 DB 가 아니다.
- **[Xiao19] 가 두 계보의 합류점**이다: 코팅 *설계 문법*은 Aykol 에서, 산화 *창 계산*은 Zhu/Mo 에서 가져왔다.
  그래서 우리 cascade 의 직계 조상은 **[Xiao19]** 이고, Aykol 2014 는 **조부(祖父)뻘의 방법 前史**다.

| **③ *평형 후* 상이 여전히 기능하나** ⬅ **2014 엔 없고 [Aykol16] 이 추가한 것** | (2014: 없음 — 코팅을 pristine 상태로만 본다) · **[Aykol16] 본문 Eq 5–6**: 코팅을 **양극과 먼저 평형**시킨 뒤 HF 를 때린다 → `LiCoO₂+αAl₂O₃ → (1−4α)LiCoO₂+2αLiAlO₂+αCo₃O₄+αLi₂CoO₃` 이 되고 나면 **HF 공격에서 LiAlO₂ 는 안 줄고 LiCoO₂ 만 소모** = *"완전 반응한 Al₂O₃ 코팅은 더 이상 HF-scavenger 가 아니다"*(저자 표현 **counter-intuitive**) | **없다.** 우리 `interface_reactivity` 는 **SE+양극 1회 반응의 ΔE 와 산물까지**만 내고, **그 산물이 다음 단계에서 무엇을 하는지**는 묻지 않는다 | 우리 축으로 번역하면: comp1/LCO 평형 산물 `Co₉S₈+Li₃PO₄+Li₂S+LiCl+Li₂SO₄` 중 **Li₃PO₄·LiCl 은 절연 보호막 후보**이고 **Co₉S₈ 은 전자전도체**다 — 즉 *"이 CEI 는 스스로 passivate 하나, 아니면 전자경로를 깔아 분해를 이어가나"* 가 **아직 우리 표에 없는 질문**이다. ([Xiao19] SI 재검증에서 나온 *"기존 3원 산화물 코팅의 분해산물이 전자전도성 TM 황화물"* 행과 **같은 질문**) |

## 10. 비판 — 이 논문의 약한 곳 ★

1. **🔴 상한 게이트가 임의값이다.** *"we cannot quantify a precise value of −ΔH that would indicate an 'excess reactivity.' Upon screening, we select −ΔH of CaO as an upper limit."* — 계산도 근거도 없이 **CaO 를 골랐다**. 그런데 이 한 줄이 **s-block 전체(+Pb₂O)를 죽인다**(40→32). 문턱을 BaO(1.88)로 잡았으면 SrO·Li₂O·BaO 가 살아남고, MgO(1.15)로 잡았으면 CaO·SrO·Li₂O·BaO 가 다 죽는다. **컷 민감도 보고가 없다.**
2. **🔴 "평균" 전환전압으로 Li-손실을 판정한다 → 게이트가 관대하다.** 볼록포 구성상 **첫 리튬화 평탄부 ≥ 평균 전압**이다. 따라서 `V(MₓF) ≤ 3.0` 을 통과한 물질 중 일부는 **실제로는 3 V 위에서 이미 Li 를 먹기 시작**한다. 논문도 "중간 삼원상·삽입 경로를 무시했다"고 자인하지만, **그 방향(과소평가)까지는 말하지 않는다.**
3. **🟠 하한 게이트는 양극 의존인데 스칼라로 고정됐다.** Table 2 가 LiMnO₂ 만 **−0.65**(다른 양극의 2배)임을 보여주고 본문도 인정하는데, **스크리닝은 0.30 하나로** 돌린다. LiMnO₂ 용 코팅 목록은 따로 나와야 했다.
4. **🟠 산물이 *가정*이다.** 코팅 반응(Eq 4·7·8·15)의 산물은 hull 로 뽑은 게 아니라 "실험 관찰에 맞춰" 정한 것이다. **양극 반응(Table 2)에만 GCLP 를 쓴 비대칭**이 특히 아프다 — 같은 도구를 코팅 쪽에도 돌렸다면 옥시불화물·삼원상이 튀어나왔을 것이고, 저자도 §3.5 에서 그 가능성을 인정한다.
5. **🟠 "생성물이 고체인가" 검사가 *사후 수작업*이다.** SiF₄·BF₃·PF₅·NbF₅·TaF₅ 제거는 **스크린 안의 규칙이 아니라 저자의 화학 지식**이다. 그래서 **재현 불가**하고 자동화되지 않는다(그 값을 DB 에서 못 가져왔다는 뜻). 정작 이게 논문의 가장 좋은 통찰인데 **틀 밖에 있다.**
6. **🟠 Sc 의 내부 긴장.** 본문 최고 신규 추천(Sc₂O₃)은 **두 번째 기전(LiF-scavenging)을 못 쓴다**(Li₃ScF₆ = **+0.018 eV**, 불안정). 논문은 §3.4 후보 목록에서 Sc 를 조용히 빼지만 **"우리 최고 추천은 기전 하나를 못 쓴다"고 문장화하지 않는다.**
7. **🟠 H₂O 재생산이 계산에 안 들어간다.** Eq 4 가 **½H₂O 를 내놓고**, 그 물이 Eq 2 로 **2HF 를 만든다**. 즉 "HF 포획"은 부분적으로 자기무효화다. 본문이 §3.5 에서 한 문단 언급하고 끝 — **정량화도, 게이트 반영도 없다.**
8. **🟠 순위가 Ω_V/Ω_G 가중치에 민감**한데 **"똑같이 중요하다고 가정"** 한 줄로 넘어간다(Fig. 6). 부피 곡선이 톱니라(Cr³⁺·Hf⁴⁺ 급등, Sc³⁺·Ca²⁺ 급락) 가중치를 6:4 만 바꿔도 상위 10 순서가 흔들린다.
9. **🟡 figure-read 관찰**: `Fig. 2` 의 DFT–실험 편차가 **화학군별로 한쪽에 몰린다**(무거운 p-block 양이온이 체계적으로 DFT 더 발열). MAE 0.157 을 "무작위 오차"로 읽으면 안 되는데 본문은 그렇게 읽는다.
10. **🟡 내부 열거 불일치(경미)**: Eq 14 의 예외로 본문이 든 것은 **s-block 6종(Rb·Cs·K·Sr·Na·Ba)** 인데, Table S1 로 계산하면 **Pb₂O(Pb⁺, −ΔH 2.52)** 도 조건을 만족한다(`Fig. 4` 의 예상 좌표 (2.14, 1.32)에 마커는 안 보인다 — figure-read). 결론엔 무영향.
11. **🟡 액체상·용매화 전면 부재**: HF 는 전해질 안에서 **용매화**돼 있는데 고립 분자로 다룬다. 다행히 **순위**는 이에 독립이지만(Eq 5 상쇄), **절대값·하한 문턱의 물리적 해석**은 영향을 받는다.
12. **🟡 자체 실험 0**: 모든 검증이 **문헌 실험의 순위 재현**이다. 게다가 인용된 두 실험(Kim 2003 vs Myung 2007)이 **ZrO₂ vs Al₂O₃ 순서에서 서로 충돌**한다 — 저자는 "다른 요인(양극·형상·두께)"으로 넘기는데, 그러면 **틀의 분해능이 그 차이보다 크다**는 뜻이기도 하다.

## 11. 적용 인사이트 (우리 캠페인에 어떻게 쓰나)

1. **🔑 "생성물 물리상태" 열을 우리 계면 표에 추가한다.** `interface_reactivity`(그리고 cascade 계면 축)의 산물 목록에 **기체/저융점 상이 있으면 표시**. 근거는 두 겹 — Aykol 의 SiO₂/B₂O₃/P₂O₅ 실패 사례(**열역학이 맞아도 보호가 안 된 이유**)와 [Zuo] DEMS 의 **SO₂ 실측**. 계산 비용 0(기존 반응식에서 파싱).
2. **🔑 "가역 Li 손실" 열도 같이 뽑는다.** 우리 최악반응식이 이미 Li 화합물 산물을 준다(`0.5155 Li₂S + 0.2577 Li₃PO₄ …`) → **Li 소모 몰수/반응원자당**을 집계하면 Aykol 의 4번째 속성을 **추가 계산 없이** 재현한다. 도판트 간 *"계면이 Li 를 얼마나 삼키나"* 순위가 새로 생긴다.
3. **🔑 정확도 선언 관행을 가져온다.** Aykol 은 *"우리 전압은 ±0.20 V"*, *"MAE 0.125 vs 실험 CSU 0.055"* 를 **본문 표로 선언**한다. 우리는 ESW onset 2.256 V 를 자릿수까지 쓰면서 **자체 정확도 선언이 없다.** 문헌 대조표(축 B)의 "0.1–0.5 V 차를 실차이로 읽지 말 것" 주석을 **숫자화된 선언**으로 승격시킬 근거로 삼을 만하다.
4. **설계도표(Fig. 5) 양식을 cascade 결과 표현에 시험한다.** 축 4개(σ 프록시 · ESW onset · E_VRH · gap)를 거울 배치하고 **성질 사각형**을 그리면, "이 도판트는 저 도판트에 모든 축에서 진다"는 **지배관계**가 한눈에 나온다 — 현재의 종합 점수 순위보다 **가중치 임의성이 없다**(§10-8 의 약점을 우리가 피하는 방법).
5. **Sc 교훈 — "우리 챔피언이 못 쓰는 기전"을 명시적으로 검사한다.** Aykol 의 Sc₂O₃ 는 기전 ①은 최고, 기전 ②는 불가인데 본문이 그걸 안 쓴다. 우리 cascade 챔피언도 **축별로 어디서 지는지** 를 digest/원고에 한 줄씩 박아 두는 편이 낫다.
6. **계보 문장 확보**: "코팅 설계를 열역학 서술자로 형식화한 것이 2014(액체·HF), SSB 로 번역한 것이 2019(고체·양극/SE), 우리는 그 게이트 문법을 **한 host 의 도판트 축**으로 옮긴 것" — 원고 서론의 3단 문장으로 바로 쓸 수 있다.

## 12. 인용 가능 문장 (초안 — 영문/국문)

- "Aykol *et al.* reduced the cathode-coating problem to four thermodynamic descriptors — HF-scavenging enthalpy, volumetric and gravimetric scavenging capacity, and cyclable-Li loss — and screened 81 binary oxide/fluoride pairs, recovering the known effective coatings (Al₂O₃, MgO, TiO₂, ZrO₂) and predicting trivalent d-block oxides (Sc₂O₃, Ti₂O₃, V₂O₃, Cr₂O₃, Mn₂O₃, Y₂O₃)."
- "HF-scavenging protects only when the scavenging product is a solid at operating temperature: SiO₂, B₂O₃ and P₂O₅ scavenge HF thermodynamically but yield gaseous SiF₄, BF₃ and PF₅, and P₂O₅ even regenerates HF." ⭐ *(우리 계면 산물 해석에 직접 인용 가능한 유일한 문장)*
- "Because fluorides lithiate ≈1.0–1.5 V above their parent oxides, a coating's Li-loss gate must be applied to the *evolved* fluoride phase rather than to the as-deposited oxide."
- "DFT reaction enthalpies for these compounds (MAE 0.125 eV HF⁻¹) are comparable to the combined standard uncertainty of the experimental thermochemical data themselves (0.055 eV HF⁻¹); DFT+U changed the MAE by only 0.008 eV HF⁻¹."
- 국문(발표용): "코팅이 듣는 이유를 '**HF 를 양극보다 먼저 먹고, 그 대가로 가역 Li 는 안 먹는다**'는 두 부등식으로 환원한 논문이다. 우리 계엔 HF 가 없지만, **'반응 산물이 안정한 고체여야 보호막이 된다'** 는 조건은 고체 계면에도 그대로 살아 있다."

## 14. 기법 용어 미니사전

| 용어 | 한 줄 뜻 | 이 논문에서 |
|---|---|---|
| **HF-scavenging** | 코팅이 전해질의 HF 를 대신 먹고 불화물로 바뀌는 것 | 주 보호기전 가설. `MₓO₁⸝₂ + HF → MₓF + ½H₂O` |
| **LiF-scavenging** | 이미 석출된 LiF 를 불화물이 흡수해 삼원 Li–M–F 로 치우는 것 | 이 논문이 **새로 제안**한 2차 기전 |
| **전환반응 (conversion)** | 삽입이 아니라 화합물을 **금속 + Li 화합물로 쪼개며** Li 를 받는 반응 | `MₓF + Li → xM + LiF`. 느리고 분극이 크다 |
| **평균 전환전압** | 전환 전 구간을 한 단계로 본 평균 전압 `V = −ΔH/ne` | Li-손실 게이트의 판정량. **개시 전압보다 낮다** |
| **GCLP** | grand canonical linear programming — 주어진 조성에서 **자유에너지 최소 상집합**을 선형계획으로 찾는 것 | Table 2 양극+HF 산물 결정. pymatgen `PhaseDiagram` 의 사촌 |
| **CSU** | combined standard uncertainty — 여러 실험값을 선형결합할 때 **전파된 불확도** `(Σcᵢ²uᵢ²)^½` | DFT MAE 를 **이것과** 비교해 판정 |
| **MAE** | 평균절대오차 `(1/n)Σ&#124;ΔH_exp − ΔH_calc&#124;` | 0.125 eV/HF (전체) |
| **Ω_V / Ω_G** | 부피·질량당 HF 포획 용량 | Ω_V↑ = 더 얇게 발라도 된다 = Li⁺ 장벽이 얇다 |
| **성질 사각형** | 다축 도표에서 한 물질의 점들을 이어 만든 직사각형. **안에 든 물질은 전부 열등** | `Fig. 5` 의 읽는 법 |
| **OQMD** | Wolverton 그룹의 DFT 총에너지 DB (Materials Project 의 경쟁 DB) | 이 논문의 계산 프레임 |
| **HHI** | Herfindahl–Hirschman Index — 원소 **공급 집중도/위험** 지수 | 2014 엔 없다. **2016 에서 추가**(§6d) |
