## 1. 한 줄 요약

**닫힌고리 능동학습으로 만든 경량 MTP** 로 5만 원자급 다결정 Li₆PS₅X(X=Cl,Br,I) MD 를 돌리고, 거기서 뽑은 벌크·입계 확산계수를 **유한요소 균질화**에 넣어 **µm 입도·µs 이상**의 거시 확산계수를 예측했다. 결론 셋: ① **음이온-질서 벌크의 확산장벽은 음이온 반경에 선형**(0.799 eV/Å, R²=0.998) ② **입계는 벌크가 느리면 뚫어 주고(Li₆PS₅I 59×) 빠르면 막는다(무질서 Li₆PS₅Cl 0.44×)** ③ 질서 Li₆PS₅I 의 **비-Arrhenius 거동(T_c ≈ 250 K)은 입계에서 온다.**

## 4. 계산 방법 ★ — 4겹 스택 (DFT → AIMD → MTP → MD → FEM)

### 4-a. DFT (라벨 생성용)
- **code**: VASP (ref 60–62) · **PAW** (ref 63)
- **functional**: **PBE** — ⛔ **vdW 보정 없음** (D3·optB88 등 언급 전무)
- **valence**: Li 1s²2s¹ · P 3s²3p³ · S 3s²3p⁴ · Cl 3s²3p⁵ · Br 4s²4p⁵ · I 5s²5p⁵
- **ecut**: 500 eV · 수렴 **10⁻³ eV / 시뮬레이션 셀** (셀당이지 원자당이 아니다 — 느슨한 편)
- **k-mesh**: AIMD 용 52원자 재래단위포 = Γ-중심 **2×2×2 (416 kp·atom)** · Gaussian smearing **0.03 eV**
  · **AL 로 뽑은 ~200원자 추출구조는 Γ-only**
- **DFT+U**: 없음 (해당 없음)

### 4-b. AIMD (초기 학습셋 생성 — **이것뿐이다**)
- Li₆PS₅X 재래단위포 **52 원자**, **1500 K**(≈ 융점 근처), Nosé–Hoover NVT, **Δt 2 fs**, Nosé 질량 3 u Å²
- 수 ps 짧게. **AIMD 는 벌크 단위포에만 쓴다** — GB 구조에는 AIMD 를 돌리지 않는다(검증용 600 K Σ3/Σ9 AIMD 는 예외, SI Note 2)
- ⇒ **비용 절감의 핵심**: GB 의 DFT 라벨은 전부 "국소구조 추출 + 단일점" 으로 얻는다

### 4-c. MTP (moment tensor potential) — 핵심
- **형식**: E = Σᵢ V(nᵢ) (SI/본문 Eq 1). MLIP-3 (ref 44, Podryabinkin 2023) 계열
- **radial basis 8개** · **cutoff 1.5 ~ 5.0 Å**
- **fitting weight**: 에너지 `1/N_at`, 힘 **0.001 Å²**
- **level**: 6 → 8 → 10 → … → **최종 18** (프로덕션 전부 level 18)
  · 파라미터 수 265(L6) → **807(L18)** → 932(L20)
  · MD 샘플링 비용 9.4×10⁻⁷(L6) → **1.8×10⁻⁵**(L18) core-h/step = **19×**
- **정확도**: 훈련·검증 RMSE 모두 **< 10 meV/atom** (SI Fig S5) · 힘 오차 < 0.2 eV/Å (Σ9 는 +0.03 더)
- **통계**: 같은 AL 로 **독립 5개 MTP** 를 학습해 오차막대 산출 (GB 에너지·D)
- **⭐ 실제 학습 명령 (repo 실측, `active_learning/al/ori_source/bulk_mtps/18.job`)**:
  ```
  mlp3 train init.mtp selectedcfgs.cfg --save_to=mlip.mtp --al_mode=nbh --no_mindist_update=True \
       --energy_weight=1 --force_weight=0.001 --stress_weight=0 \
       --weight_scaling=2 --weight_scaling_forces=1
  ```
  · `--al_mode=nbh` = 원자환경(local) AL ✓ · `--force_weight=0.001` ✓ 본문과 일치
  · 🔴 **`--stress_weight=0` — 응력/비리얼을 학습하지 않는다.** 본문에 없는 사실이고,
    **격자상수·탄성이 DFT 응력으로 구속되지 않는다**는 뜻이다 (§3-e·§14-②의 직접 원인).
  · 자원: refit 1노드 24 코어 × 최대 16 h · MTP-MD 샘플링 24 코어 × 3 h · select 4 코어 × 2 h

### 4-d. 능동학습 (local-AL) ★★ — 축 B 의 본체

영역은 PBC 로 되접힌다(위쪽에 좌표 clamp 코드가 **주석 처리**돼 있다) — **재사용 시 확인할 것.**

### 4-e. 원자 모형 (무질서 처리 포함) ★
- **bicrystal**: CSL 이론(ref 48, aimsgb) · 회전축 **[110]** 고정, 회전각 스캔 → Σ3·Σ9·Σ11·Σ99 등 **38개 단일 GB** (그림 소스 실측; 본문은 개수를 안 밝힌다)
  · 주기 GB 간 거리 **> 50 Å** · 원자쌍 최소거리 > 1.8 Å 되게 법선방향 시프트
- **columnar**: [110] 축, 오배향각 ≈ **61°**
- **polycrystal (surrogate GB model)**: ATOMSK(ref 50) · **2 결정립** · 회전축 [100]/[010]/[001] 에 대해 오배향각 ≈ **44° / 6° / 8°** (즉 무작위 배향)
- **셀 크기**: `Fig. 1c` 기준 **≈ 52 000 원자**, 결정립 ≈ 10 nm, 5 nm 스케일바
- **⚠ 무질서 처리 = SQS 도 enumerate 도 아니다**: *"S atoms inside the Li cage and Cl atoms were **randomly selected** according to the disorder percentage and exchanged"* — **단일 무작위 배열**(직전 연구 ref 22 방식 승계). 배열 앙상블 평균 없음.
  · 단, SI Note 2 에서 **50 % 무질서 벌크만 6개 배열로 독립 MD** 를 돌려 산포를 봤다 (Fig S9a)
- **화학량론**: 모든 셀이 Li₆PS₅X 를 유지 (GB 영역 원자를 지워서 맞춤) ⇒ 형식전하 중성

### 4-f. MD (프로덕션) — ⭐ **코드가 본문보다 훨씬 많이 말해 준다**
- **engine**: LAMMPS (ref 65) + fitted MTP · **Δt 2 fs**
- **평형화**: **NPT, 0 압력, 0.2 ns** ← ⚠ 짧다
- **프로덕션**: **NVE, 5 ns** ← ⚠ 열욕 없음
- **GB 구조 이완**: 어닐-퀜치 — 600 K 평형 → **1 ns 에 걸쳐 ~0 K 냉각** → 0 K 이완 (ref 22)
- **GB 에너지**: Γ = (E_GB − E_bulk)/A_tot
- **온도 격자 (repo 실측, 본문 미보고)**: `cal = [400, 450, 500, 550, 600, 700] K`.
  Arrhenius 피팅은 **벌크 6점(400–700 K)**, **다결정 5점(400–600 K, 700 K 제외)** — 🔴 **두 곡선의 온도범위가 다르다.**
- **덤프 간격**: 다결정·벌크 `interval=1000` × 2 fs = **2 ps/frame** · 단일 GB `interval=500` = **1 ps/frame**

**⭐⭐ D 추정기 (repo 실측, `cal_diff_coe_decom.py` + `fit_diff.py`) — 본문 Eq 8 보다 훨씬 구체적이다**
```python
# 1) MSD 는 첫 프레임 하나를 원점으로 (다중원점 시간평균 아님)
distance = pos(t)[Li] - pos(0)[Li]          # wrap=False
dis = mean(|distance|**2)                   # Å²
# 2) log-log 로 옮기고 기울기를 1 로 **강제**한 뒤 절편만 맞춘다
def func(x, a): return x + a                # slope ≡ 1
logk, _ = curve_fit(func, log10(t)[win:], log10(MSD)[win:])
D = 10**logk / 2 / d                        # d = 3(all) / 2(xy) / 1(z)   [Å²/ns = 1e-7 cm²/s]
```
- ⇒ **단일원점 MSD + α ≡ 1 강제**. 확산 영역인지 데이터에 묻지 않고 **부과**한다.
  (α 를 자유롭게 두는 `fit_alpha.py` 가 따로 있지만 그건 **진단용**이고, 보고값은 α≡1 추정기에서 나온다.)
- ⇒ **Å²/ns = 10⁻⁷ cm²/s** — 논문의 모든 D 가 이 단위인 이유가 여기 있다.
- **피팅 창 (repo 실측)** 🔴 **스크립트마다 다르다**:

| 스크립트 | frame 간격 | 사용 행 | 실제 창 | 본문("3–5 ns") |
|---|---|---|---|---|
| `Polycrystal/…/bulk/fit_diff.py` | 2 ps | `data[1500:]` | **3.0–5.0 ns** | ✓ |
| `Polycrystal/…/poly/fit_diff.py` | 2 ps | `data[2000:]` | **4.0–5.0 ns** | 🔴 **불일치** |
| `Single-type_GBs/…/fit_diff.py` | 1 ps | `data[3000:]` | **3.0–5.0 ns** | ✓ |

  ⇒ **벌크(3–5 ns)와 다결정(4–5 ns)이 서로 다른 창에서 나온 뒤 아래 §의 un-mixing 으로 섞인다.**

**⭐⭐⭐ D_GB 는 측정값이 아니라 *2상 혼합모델의 피팅 파라미터*다 (repo 실측)**
`Polycrystal/diffusion_calculation/fit_arrhenius.py`:
```python
f = 0.67630871385                                  # ← SI Table S2 의 "GB 폭 2.5 nm, 10 nm 셀" 값과 정확히 동일
def difftot(x,a,b,c,d,f):
    return log((1-f)*exp(a-b*x) + f*exp(c-d*x))    # 부피분율 가중 **병렬(산술) 혼합**
par_bulk = fit(arrhenius, bulk_data)               # 벌크 (a,b) 를 먼저 고정
par_gb   = fit(lambda x,c,d: difftot(...,f), poly_data)   # GB (c,d) 만 자유
```
단일 GB 판(`Single-type_GBs/gb_diffusivity/diff_at_t_w.py`)은 아예 닫힌 형태다:
```python
gb_width = 25      # Å   ← 주석: "temporary setting of gb width"
f = gb_width / (cell_length/2)
D_GB = ( D_measured_cell - (1-f) * D_bulk ) / f
```
- ⇒ **D_GB·Ea_GB 는 ① 다결정 총 D ② 별도 벌크 D ③ 가정한 부피분율 f 세 가지로 완전히 결정되는 유도량**이다.
  본문 Methods 의 *"GB diffusion coefficients were extracted from …"* 한 줄이 실제로는 이 식이다.
- ⇒ **막는 GB(D_poly < D_bulk)에서는 큰 수 두 개의 차를 f 로 나누는 꼴이라 수치적으로 나쁜 조건**이다. §14-④ 참조.
- ⇒ 혼합이 **병렬(Wiener 상한)** 이다 — 직렬 성분이 있는 실제 기하에는 상한 근사다.
  그런데 그렇게 뽑은 D_GB 를 다시 **진짜 균질화를 하는 FE 에 입력**한다 (§14-④).
- `uncertainties` 패키지를 import 하지만 **출력 D₀·Ea 에 오차막대는 붙지 않는다.**

### 4-g. 연속체 FEM (축 C 의 본체)
- **지배식**: Fick, q = −D∇c, ∇·q = 0 (정상상태) · **선형 계산균질화**로 D_macro 텐서
- **미세구조**: 3D 주기 **Voronoi 테셀레이션** (ref 55) · 프로덕션 **27 결정립** RVE (거의 등방; 고유값 편차 ≤ 3 %, 대개 < 1 %)
- **GB 표현 2종**:
  - **volume-resolved** (나노입도): 복셀 격자 **512³ ≈ 1.34억 자유도**, FFT 기반 균질화 솔버 **FANS** (ref 20)
  - **thickness-collapsed** (마이크로입도): NEPER 로 GB-정합 2차 메시 + 계면요소 (ref 18) · **0.44 M 자유도**(27립) / 0.23 M(2립)
- **전이 입도**: 두 방식이 가장 잘 맞는 지점 = **100 nm** (GB 폭 2.5 nm 기준; GB 부피분율로는 **6.3 %**)
  · 전이점에서도 잔차 **≈ 5 %** 존재
- **해상도 규칙** (SI Note 3C): 막는 GB(D_GB<D_bulk)면 **GB 폭 ≥ 복셀 10개**, 뚫는 GB 면 5개면 충분
- **GB 는 transversely isotropic**: 면내 D_GB∥ / 법선 D_GB⊥ 를 따로 넣을 수 있으나, 평균 GB 를 쓸 땐 D_GB∥ = D_GB⊥ 로 둠
- **GB 폭 = 2.5 nm** (ref 22 승계, SI Note 4 에서 1.0 / 1.5 nm 와 비교)
- 검증: 등방 GB 설정에서 해석적 **Maxwell–Garnett** 추정(ref 70)과 잘 맞음

## 5. 결과 — 절별 완주 (모든 숫자)

### 5.1 질서 Li₆PS₅Cl 의 GB 형성에너지 — **Σ3 만 특별하고 나머지는 다 비슷하다** (`Fig. 2a`)
- **Σ3(109°) 가 최저 ≈ 5 meV Å⁻²**. 나머지(저각 GB 포함) **12–24**.
- 이유 = 형태학: Σ3 은 Li 케이지와 [PS₄]³⁻ 사면체를 **거의 보존**하고 케이지·할라이드 재배열만 일어난다.
  일반 GB 는 케이지·PS₄ 를 심하게 뒤틀어 복잡한 Li–S 배위·음이온 격자 무질서를 만든다.
- **⇒ 저자 주장**: *"Σ3 같은 이상화된 GB 만 계산하는 선행연구(SI Table S3)로는 실제를 못 본다."*
  Σ3 처럼 온전한 GB 가 생길 확률은 낮다 — GB 는 벌크 전체에 퍼진 2D 결함이므로.
- **황화물 GB 는 산화물보다 싸다** (5–24 vs LLZO 25–56 meV Å⁻²) + 기계적으로 무르다 ⇒ **GB 가 많고 무작위하게 생긴다**.
- **DFT 검증**: Σ3·Σ9 소형셀을 MLP 이완구조 위에서 DFT 로 재계산 → MLP 와 일치(오차막대 = 독립 MTP 5개 표준편차).
  🔴 단 `Fig. 2a` 를 눈으로 읽으면 **Σ9 는 소형셀 24.6 vs 대형셀 15.4 로 1.6× 차이**가 난다 (§14-③).

### 5.2 질서 Li₆PS₅Cl 의 GB 확산 (`Fig. 2b,d`)
- **에너지 순서와 확산 순서가 같다**: Σ3(109.47°) 가 D 도 최저 (**23.1305 / 20.0639 ×10⁻⁷** ∥/⊥, 그림 소스 실측), 나머지는 **31.73–69.02**.
- 벌크 = **17.235 ×10⁻⁷ cm²/s** (600 K) → 다결정 평균 GB **44.425** ⇒ **2.58×** (본문 "약 3배"는 반올림).
- **이방성**: D_GB⊥ ≈ **0.87** D_GB∥ — GB 면 **안쪽**이 빠르다.
- **궤적** (`Fig. 2d`, 300 K, 5 ns): Σ99·Σ11 은 GB 면을 따라 밝은 확산 띠가 뚜렷하고, **Σ3 은 GB 가 궤적에서 거의 안 보인다**(벌크와 구분 불가). GB 가 만든 격자변형이 **저장벽 신규 경로**를 열어 **케이지 간 hopping** 을 촉진한다.
- **과잉엔트로피**(2체 excess entropy, Piaggi–Parrinello ref 51, OVITO 구현)로 GB·삼중점의 구조 무질서를 정량화.
- **나노 공극**이 일부 GB(Σ99)에 생기지만 **1 nm 미만**이고 D_GB 에 거의 영향 없음.
- **2결정립 surrogate 다결정**의 평균 GB 에너지·D 가 단일 GB 38종 분포 **안**에 들어옴 ⇒ 대표성 확보.
  columnar vs polycrystal 도 비슷 ⇒ **삼중점의 기여는 작다.**

### 5.3 음이온 무질서 × GB (`Fig. 3a,b`)
- 300 K 궤적: 무질서 Li₆PS₅Cl 은 **케이지가 사라지고** Li 가 공간적으로 균질 분포.
- **무질서가 벌크 장벽을 168.0 meV 낮춘다** (0 % 0.3843 → 50 % 0.2162). 본문 "~0.17 eV" ✓
  🆕 **digest 관측**: 실제 최소는 50 % 가 아니라 **25 % (0.1985 eV)** — 0 % 대비 **185.8 meV** 하락.
  그리고 **실험 시료의 무질서도는 ≈ 23 %** (Shotwell) ⇒ **실측 무질서도가 예측 최적점과 겹친다.** 논문 미언급.
- **GB 의 부호가 무질서에 따라 뒤집힌다**:
  질서(0 %)에서는 GB 가 장벽을 **−62 meV** 내리고, 무질서(25–75 %)에서는 **+19 ~ +75 meV** 올린다.
- 300 K 에서 무질서 Li₆PS₅Cl 의 GB 는 D 를 **~60 % 깎지만**(0.44×) 특성 hopping 주파수는 여전히 **~10⁸ Hz** 급
  ⇒ 실험에서 GB 저항이 낮게 나오고(ref 26) 임피던스에서 GB 기여가 분리 안 되는 것(ref 27)과 부합.
- 예측 벌크·GB 장벽 **~0.23 eV**, 300 K D **~10⁻⁷ cm²/s** 는 실험 범위(**0.11–0.37 eV**, **3×10⁻⁸–7×10⁻⁷ cm²/s**) 안.
  ⇒ **"실험 산포의 주범은 GB 가 아니다"** — 다른 결함(전위, ref 28)이나 **공간적으로 불균일한 음이온 무질서**일 것.

### 5.4 PDF 로 본 나노화 (`Fig. 3c`)
- 실험 PDF(Schlautmann, ref 74)는 **벌크 단결정 시뮬레이션과 일치** ⇒ 측정 시료는 벌크형 국소배위가 지배.
- 입도 8.6 nm 다결정은 **15 Å 너머 상관이 약해진다** ⇒ 실험에서 관측된 PDF 감쇠의 원자적 설명.

### 5.5 할라이드 치환 (`Fig. 3d–f`)
- **RDF (600 K, `Fig. 3d`)**: Li–I 첫 피크가 Li–Cl 대비 **+0.5 Å 이동 + 감쇠**(figure-read: Cl ≈ 2.45 Å/높이 3.7 → I ≈ 2.9 Å/높이 2.85).
  4 Å 너머는 오히려 **I 쪽이 더 뾰족** ⇒ MD 중 Li₆PS₅I 격자가 더 질서정연.
- **변위 분포 (300 K, 5 ns, `Fig. 3e`)**: 단결정에서 Cl 은 케이지 크기(~5 Å)까지 = **케이지 내 회전운동**,
  I 는 ~3 Å 이하 = **인접 자리 간 국소 hopping** 만. 다결정이 되면 셋 다 꼬리가 길어지고 **Cl 이 가장 크게 늘어난다**(케이지 간 확산 증가).
- **선형 스케일링** (`Fig. 3f` 상단): 질서 벌크 장벽이 음이온 반경에 선형.
  - **digest 계산**: 최소자승 **Ea = 0.799 r(X) − 1.067 eV, R² = 0.998** ⇒ **반경 +0.1 Å 당 +79.9 meV** (본문 "~80 meV" ✓)
  - ⚠ **GB 는 선형이 아니다**: 조각 기울기 Cl→Br **0.152** vs Br→I **1.017 eV/Å** = **6.7× 차이**, R² 0.905.
    (본문이 "선형"이라 부른 것은 **벌크 장벽**과 **GB 형성에너지**(R²=0.951)이지 GB 장벽이 아니다 — 그림의 분홍 점선이 오해를 부른다.)
- **무질서 상태에서는 반경 의존이 사라진다** (`Fig. 3f` 하단): 벌크 0.216/0.224/0.217, GB 0.235/0.239/0.245 — 전부 평평.
- **GB 효과의 할라이드 의존** (Source Data 정확값):
  Cl **−62 meV** · **Br −146 meV**(가장 크게 뚫린다) · I **−105 meV**.
- **기작 주장**: S²⁻ 와 X⁻ 의 **반경 불일치가 Li 경로를 막는다** (K₃OX 관측 ref 37 과 같은 방향).
  ⇒ **격자 분극률(polarizability)이 argyrodite 확산의 지배인자가 아니다** — Kraft 2017(ref 27)의 해석에 정면 반박.
  ⇒ LISICON 계열(양이온 반경↑ → 장벽↓, ref 38)과도 **반대 경향**.

### 5.6 비-Arrhenius 거동 (`Fig. 4a,b` · SI Fig S13–S15)
- 질서 Li₆PS₅I, µm 입도: **T_c ≈ 250 K** 에서 꺾인다.
  - **고온 = 벌크 지배**, 장벽 **≈ 0.69 eV**
  - **저온 = GB 지배**, 장벽 **≈ 0.59 eV**
  - 기작: 저온으로 갈수록 D_GB/D_bulk 비가 커져 GB 경로가 지배권을 잡는다(SI Note 5).
- **실험 일치**: T_c 실측 ≈ 250 K (Brinek ref 43) · 저온 활성화에너지 변화 **예측 −0.10 vs 실험 −0.12 eV**.
- **입도를 줄이면 비-Arrhenius 가 완화된다** (실험 ref 43 과 일치).
- **무질서 상은 비-Arrhenius 가 안 나온다** (SI Fig S14): D_bulk ≈ D_GB 라 다결정이 벌크 Arrhenius 를 그냥 따라간다.
- **할로겐 의존**: I 는 뚜렷, Br₀.₅I₀.₅ 는 약화, Br 는 소멸 — 실험(Hanghofer ref 36)과 일치.
- ⚠ **σ 절대값은 과소예측**된다(§5.8 참조). 저자 자인: "Li₆PS₅I 의 장벽을 과대평가한 탓".
- **논증의 힘**: Li₆PS₅I 의 저온 장벽 감소는 **벌크 국소 에너지 요동으로 설명 안 된다**(ref 39,40 의 통설).
  전이가 **250 K** 인데 실험 구조전이는 **160 K**(ref 36,41) 라 시점이 안 맞기 때문. GB 가 대안 기작을 준다.

### 5.9 유량장 (`Fig. 4d`, d ≈ 25 nm, 300 K)
- **무질서 Li₆PS₅Cl**: GB 가 약간 어두운 띠로 보일 뿐, **유선이 GB 를 그냥 통과**한다. |q|/Δc 컬러바 **10^0.2–10^0.6 ×10⁵ nm/s**.
- **질서 Li₆PS₅I**: GB 가 **밝은 붉은 채널망**을 이루고 유선이 그쪽으로 **몰린다**. 컬러바 **10⁻¹–10^0.5 nm/s**.
- 🔑 두 컬러바의 단위가 **10⁵ nm/s 대 nm/s** — 같은 온도·같은 기하인데 **유량 규모가 ~5–6 자릿수 다르다.**

### 5.10 사전계산 지도 (`Fig. 4e` · SI Fig S21) — **일반화된 판정선**
GB 가 거시 D 를 **1 자릿수 이상** 바꾸면 "GB-dominated", 아니면 "bulk-dominated".

| 입도 d | GB-지배 하한 (막는 쪽) | GB-지배 상한 (뚫는 쪽) |
|---|---|---|
| 10 nm | D_GB/D_bulk < **1/32.8** | > **21.6** |
| **100 nm** | < **1/368** | > **184.5** |
| 1000 nm | < **1/3425** | > **1561** |

- 본문 요약("d > 100 nm 면 GB 가 벌크보다 **2 자릿수 높거나 3 자릿수 낮아야** 의미 있다")은 정확히 이 표의 반올림이다 ✓
- **표시된 세 계**: **LLZO 9.29×10⁻⁴** (Cojocaru-Mirédin ref 6 소환) · **무질서 Li₆PS₅Cl 0.44** · **질서 Li₆PS₅I 59.25**
- 🔑 **산화물 GB 는 ~1000× 막고, 황화물 argyrodite GB 는 ~2× 막는다** — 3 자릿수 차이. 이게 "황화물은 GB 걱정을 덜 해도 된다" 의 정량 근거.
- 🆕 **digest 관측**: D_GB/D_bulk = 59.25 는 지도상 **d ≈ 31 nm** 에서 GB-지배 경계와 만난다 —
  §5.7 의 "실험을 재현하는 유효 입도 31 nm" 와 **같은 값**이다. 즉 Hogrefe 시료는 경계 위에 있다.

### 5.11 Discussion 의 처방 (저자 주장 그대로)
1. **Li₆PS₅Cl 은 GB 를 무서워할 필요가 없다** ⇒ **습식 밀링 + 기계적 가압**(ref 32)으로 입도를 줄여 **공극을 없애고 입자 간 접촉을 늘리는 것**이 초이온 전도도를 안 깎으면서 이득이다.
2. **벌크가 느린 계는 나노화가 활성화 수단**이다 (질서 Li₆PS₅I 가 예). 같은 GB 강화가 Na₃PS₄(ref 34)·β-Li₃PS₄(ref 17)·LiZr₂(PO₄)₃(ref 35)·Li₃InCl₆(ref 13)에서도 보고됨.
3. **벌크가 빠른 계(LLZO 등)는 반대** — GB 저항을 낮추거나 GB 밀도를 줄여야 한다.
4. **음이온 반경이 조성 설계 파라미터**다 (분극률이 아니라).
5. **비-Arrhenius 는 실용적 위험**(실온 근처 성능 불안정) — 입도 제어나 GB 확산도 조절로 완화 가능.

## 9. 세 축별 정밀 대조 ★★ — **우리 좌표에 놓기**

### 9-A. 축 A · **modified Nernst–Einstein** — 우리 H_R = 1 을 바꿔야 하나?

**① 무엇을 어떻게 수정했나** (본문 Eq 10, ref 66 = Uitz/Epp/Bottke/Wilkening, *J. Electroceram.* 38, 142 (2017)):
```
σ = Λ · (z e)² · D / (k_B T)          z = 1 (Li⁺), e = 소전하
Λ = "system-dependent coefficient related to the concentration of the mobile ions and the Haven ratio"
```
표준 NE 는 `σ = n (ze)² D / (H_R k_B T)`. 즉 **수정의 내용은 "n 과 1/H_R 을 하나의 경험계수 Λ 로 합쳤다"** 는 것뿐이다.
**항이 추가되거나 제거되지 않는다** — 형태는 같고 **Λ 를 어떻게 정하느냐**만 다르다.

**② 왜 필요한가 (저자 논거)**: 명시적 논거가 **본문에 없다.** ref 66 을 걸고 Λ 를 "이동이온 농도와 Haven 비에 관련된 계수"라고
한 줄로 정의한 뒤 곧바로 값을 준다. ⇒ 캐리어 수·상관효과 중 **무엇을 고치는지 논문이 분해하지 않는다.**

**③ Λ 값과 그 유래** — 여기가 핵심이다.

| 계 | Λ (Li Å⁻³) | 유래 |
|---|---|---|
| Li₆PS₅Cl | **2.181×10⁻²** | *"following our previous study22"* (Ou 2024 PRM — **우리 미확보**) |
| Li₆PS₅I | **1.590×10⁻¹** | **실험에서 역산**: ref 43(Brinek) 의 σ 와 ref 68(Hogrefe) 의 366 K D 를 맞춰서 |

**Λ_I / Λ_Cl = 7.29.** 즉 **같은 D 를 넣어도 I 계는 Cl 계보다 σ 가 7.3× 높게 나온다.**

**⭐ digest 계산 (원논문 미보고) — Λ 를 물리적 캐리어 밀도와 비교하면**:
공칭 Li 밀도 n = 24/a³ (재래단위포 4 f.u. = 24 Li). **격자상수 3종을 다 놓고 본다** (§3-e 참조):

| a 출처 | a (Å) | n_Li (Li Å⁻³) | Λ_Cl/n | **H_R = n/Λ_Cl** |
|---|---|---|---|---|
| 본문 Methods | 10.28 | 0.022092 | 0.987 | **1.013** |
| **배포 MD 셀 (repo 실측)** | **10.044** | **0.023687** | **0.921** | **1.086** |
| 실험 [Adeli] 중성자 | 9.8598 | 0.025037 | 0.871 | 1.148 |

| a 출처 | a (Å) | n_Li | Λ_I/n | **H_R = n/Λ_I** |
|---|---|---|---|---|
| 본문 Methods | 10.35 | 0.021647 | 7.345 | **0.136** |
| 실험 격자 가정 (~10.14) | 10.14 | 0.023020 | 6.907 | 0.145 |

⇒ **어느 격자상수를 쓰든 결론이 바뀌지 않는다: Cl 은 H_R ≈ 1.0–1.15, I 는 H_R ≈ 0.14.**

> 🔑🔑 **결론 1 — Li₆PS₅Cl 에 대해 그들의 "modified" NE 는 우리 규약과 사실상 같다.**
> Λ_Cl 이 공칭 Li 밀도의 **98.7 %** 다 ⇒ **H_R ≈ 1.01**. 즉 **"수정" 이라는 이름과 달리, Cl 계에서는
> 캐리어 = 전체 Li · Haven = 1 인 표준 NE 다.** 우리 σ = NE(H_R = 1) 은 **이 논문과 어긋나지 않는다.**
>
> 🔑🔑 **결론 2 — Li₆PS₅I 의 Λ 는 Haven 비가 아니라 실험 보정계수다.**
> H_R = 0.136 은 물리적으로 매우 이례적이고(협동운동으로도 0.3 아래는 드물다), 애초에 저자가
> **서로 다른 두 실험(σ from Brinek, D from Hogrefe)의 비**로 정했다고 밝혔다. ⇒ 시료 차이·측정량 차이가
> 전부 Λ 에 흡수된다. **이건 상관효과 보정이 아니라 앵커링이다.**
>
> 🔑🔑 **결론 3 — 그래서 `Fig. 4b` 의 세로 위치는 독립 예측이 아니다.**
> Λ_I 가 실험 (σ, D) 쌍으로 정해졌으므로 366 K 근처에서 σ_pred/σ_exp = D_pred/D_exp 가 **정의상 성립**한다.
> `Fig. 4b` 에서 독립적으로 검증되는 것은 **기울기(Ea)와 꺾임(T_c)** 뿐이다. 저자도 T_c 만 주장하므로
> 논문 자체는 정직하지만, **그림만 보고 "σ 절대값을 맞췄다"고 읽으면 안 된다.**

**④ ⇒ 우리 H_R = 1 을 이 식으로 바꿔야 하나 — 판정: ⛔ 바꾸지 않는다.**

| 항목 | [Ou26] | 우리 | 판정 |
|---|---|---|---|
| σ–D 변환식 | Λ(ze)²D/k_BT | n(ze)²D/(H_R k_BT), **H_R = 1** | 🟰 **Cl 계에서 수치적으로 동일** (Λ_Cl/n = 0.987) |
| Λ(또는 H_R) 결정 근거 | Cl: 선행 논문 승계(미공개 유래) · I: **실험 2편 역산** | 규약으로 **1 고정 + σ 절대값 인용 금지** | ⭕ **우리 쪽이 더 방어적** — 우리는 못 아는 것을 1 로 두고 절대값을 안 쓴다 |
| 조성 간 비교 | ⛔ **불가** — Λ 가 조성마다 다르게(7.3×) 정해진다 | ⭕ 가능 — 같은 H_R 이면 비(ratio)에서 소거 | 🔴 **그들 방식으론 Cl vs I σ 비교가 성립 안 한다** |
| 우리 보고량 `D_rel(design, host)` | 해당 없음 | Λ·H_R 이 **분자·분모에서 소거** | ⭕ **우리 보고량은 이 논쟁에서 자유롭다** |

**⇒ 실무 결론 3줄**
1. **우리 NE(H_R=1) 은 그대로 둔다.** 이 논문이 Cl-argyrodite 에서 사실상 같은 것을 썼다는 **외부 근거**로 쓸 수 있다.
2. **⛔ Λ_I = 0.159 를 우리 계에 이식 금지.** 실험 앵커일 뿐이고 우리 Cl 계와 무관하다.
3. **σ 절대값 인용 금지 규율은 이 논문으로 더 강해진다** — 같은 저자가 같은 논문 안에서 조성에 따라 변환계수를 7.3× 다르게 쓴다.

**⚠ 남은 미확인**: Λ_Cl = 2.181×10⁻² 의 **원래 유도**는 ref 22(Ou 2024 PRM)에 있고 우리는 그 편이 없다.
공칭 밀도와 1.3 % 차이라 "H_R=1 로 두고 300 K 격자로 계산" 이 가장 그럴듯하지만, **확정은 못 한다.**

## 10. 🔬 **코드·그림소스 ↔ 본문 대조 — 배포자료로만 나오는 것 (10건)**

**① 🔴 격자상수가 본문과 배포 구조에서 2.4 % 다르다**
본문 Methods: *"relaxed lattice constants … calculated as **10.28**, 10.31, **10.35 Å**"*.
배포 구조(`FigureS17/diff_ana` notebook 출력): 벌크 셀 = `Cl4000Li24000P4000S20000`,
`cell=[100.4388, 100.4398, 100.3937]` = **52 000 원자 = 재래단위포 10×10×10** ⇒ **a = 10.0439 Å**.
바이크리스털도 부피 기준 10.01–10.09 Å. ⇒ **확산이 실제로 계산된 셀은 10.04 Å 이다.**
→ 실험(9.8598 Å) 대비 **+1.9 %** 로, PBE-without-vdW 로선 **평범하다**. (본문 10.28 을 믿으면 +4.3 % 라는 과장이 된다.)
**⇒ 내 초안의 §14-② 비판을 이 발견으로 자기정정했다.**

**② 🔴🔴 D_GB 는 측정값이 아니라 2상 병렬혼합 모델의 *피팅 파라미터* 다**
`fit_arrhenius.py` / `diff_at_t_w.py`: `D_GB = (D_cell − (1−f)·D_bulk)/f`, `f = 0.67630871385`
(= SI Table S2 의 "2.5 nm, 10 nm 셀" 값). 본문은 *"GB diffusion coefficients were extracted from the
diffusion coefficients derived from the simulation model with GBs"* 라고만 쓴다.
⇒ **Table 1 의 D_GB·D_GB/D_bulk 전부가 f 에 선형으로 매달린 유도량**이다 (§14-④).
`diff_at_t_w.py` 의 GB 폭에는 주석이 붙어 있다: **`gb_width = 25  # temporary setting of gb width`**.

**③ 🔴 MSD 추정기가 "기울기 1 강제 + 단일원점"이다**
`fit_diff.py`: `def func(x,a): return x + a` 를 **log₁₀(MSD) vs log₁₀(t)** 에 맞춘다 = **α ≡ 1 을 부과**.
MSD 는 다중원점 시간평균이 아니라 **프레임 0 하나를 원점으로** 잡는다.
α 를 자유롭게 두는 `fit_alpha.py` 는 **진단용**이고 보고값에 안 들어간다.
본문 Eq 8 (`D = ⟨u²⟩/2dt`) 만 보면 이 두 선택이 안 보인다.

**④ 🔴 MSD 피팅 창이 스크립트마다 다르다** — 벌크·단일GB **3–5 ns**(본문과 일치) vs **다결정 4–5 ns**.

## 11. 적용 인사이트 (우리 연구에 어떻게)

- **① 벌크 상한 주석을 정밀화한다.** "우리 D 는 벌크 상한" → **"치밀 µm-다결정 상한 (입계 손실 < 1 %)"**.
  실험 격차의 책임을 **공극·접촉**으로 명시적으로 옮긴다. 근거 = `Fig. 4c` + SI Fig S20c + S22.
  ⇒ 이건 **원고에 바로 쓸 수 있는 문장**이고, 우리 DEM 축(펠릿 치밀화)과 DFT 축을 **연결하는 다리**가 된다.
- **② σ 절대값 인용 금지 규율의 최강 외부 근거를 얻었다.** 같은 논문이 같은 식을 쓰면서 조성에 따라
  변환계수를 **7.3× 다르게** 잡는다. "NE 변환은 규약이지 측정이 아니다" 를 한 문장으로 방어할 수 있다.
- **③ AL 중단조건 = 보고량 수렴** 이라는 형식을 §J-9 와 보고량 카드 규율에 **외부 선례**로 박는다.
  (우리가 자체 규율로 정한 것을 남이 독립적으로 같은 결론에 도달했다.)
- **④ 변위 분포 히스토그램(`Fig. 3e`)은 우리 기존 궤적에 지금 당장 적용 가능**하다 — 추가 계산 0.
  케이지 내 회전 vs 케이지 간 hopping 을 **분포로** 나눠 보면 comp1↔modelc 차이의 기작을 그림 하나로 말할 수 있다.
- **⑤ Meyer–Neldel 보상선(E_MN = 103 meV)** 도 우리 궤적 후처리로 즉시 계산 가능. 우리 도핑 계열의
  (Ea, D₀) 쌍이 같은 선 위에 있으면 **"같은 기작을 건드리고 있다"** 는 강한 진술이 되고, 벗어나면 그것이 발견이다.
- **⑥ MTP 전이성 표(Table S1)의 우리판**을 만든다 — UMA 를 학습분포 밖으로 밀었을 때의 오차 표.
  §J-11(불확실도 축)의 빈칸과 정확히 같은 방향이고, 이 논문이 **형식**을 준다.
- **⑦ 실험 무질서도 ≈ 23 % 가 예측 최적점 25 % 와 겹친다**는 관측(§5.3)은 논문이 안 쓴 것이고,
  우리 `ordered_vs_disordered.md` 축에 넣을 값이 있다.
- **⑧ ⭐ 입계 축을 "라벨 0개"로 여는 길이 생겼다.** `PolycrystalDiffusion`(LGPL-3.0, §9-C)에
  **우리 D_bulk 하나만 넣고 D_GB/D_bulk 를 10⁻⁴–10⁴ 로 sweep** 하면, 우리 comp1/modelc 가
  `Fig. 4e` 지도의 어디에 앉는지·입도 얼마부터 GB 가 문제인지를 **DFT·MD 추가 0회로** 답할 수 있다.
  선행 조건은 `pixi` + `FANS` 설치뿐이다. ⛔ 남의 D_GB 를 그대로 쓰지 않는다(§9-C 주의).
- **⑨ ⭐⭐ 우리 MSD 규약을 방어할 외부 근거와 반례를 동시에 얻었다.**
  · 방어: 그들은 **α ≡ 1 을 강제**하고 **단일원점**이며 **창이 스크립트마다 다르다**(§10-③④).
    우리의 *"MSD 창 2–50 ps 고정 · 자유절편"* 은 **명시적이고 일관된 규약**이라는 점에서 우위다.
  · 반례: 그들 창은 **3–5 ns 로 우리보다 100× 길다.** "긴 창을 쓴 문헌"으로 인용할 수 있지만,
    ⛔ 그 창은 **α 를 강제한 상태의 창**이라 우리 자유절편 창과 같은 등급으로 놓으면 안 된다.
- **⑩ `--stress_weight=0` 은 우리에게도 질문이다.** UMA-s-1p1 이 argyrodite 응력/부피를 얼마나 잘 내는지
  우리는 **표로 갖고 있지 않다.** 이들처럼 응력을 빼고 학습하면 격자가 흔들린다는 것이 §10-①의 교훈이고,
  우리 쪽 대응 점검은 **기존 궤적의 NPT 부피 시계열을 실험 격자상수와 대조**하는 것으로 무료다.

## 12. 인용 가능 문장 (deck/paper 용)

- "Multiscale MD→FE modelling of polycrystalline Li₆PS₅Cl shows that grain boundaries reduce the macroscopic Li diffusivity by **less than 1 % for micrometre grains** and by only ~6 % at 100 nm, so the order-of-magnitude gap between simulated bulk transport and EIS-measured conductivity must originate from **porosity and interparticle contact rather than grain boundaries** (Ou et al., Nat. Commun. 17, 8726 (2026))."
- "In anion-ordered Li₆PS₅X the Li diffusion barrier scales linearly with the halide radius (**0.80 eV Å⁻¹**, i.e. ~80 meV per 0.1 Å), which argues against lattice polarizability as the dominant descriptor for argyrodite transport."
- "Grain boundaries act **in opposite directions depending on the bulk**: they enhance diffusion 59-fold in slow anion-ordered Li₆PS₅I but suppress it to 0.44× in fast anion-disordered Li₆PS₅Cl."
- "GB formation energies in sulfide argyrodites (**5–24 meV Å⁻²**) are 2–4× lower than in garnet oxides (25–56 meV Å⁻²), consistent with abundant, randomly oriented grain boundaries in synthesized sulfide pellets."
- "A quality-level-based **local active-learning** scheme reduces the number of DFT-labelled configurations needed to fit a GB-capable moment tensor potential by **≈5×** relative to structure-level active learning (441 vs 2372 configurations, 5 independent campaigns; *digest recalculation from the paper's Source Data*)."
- ⚠ **조건부**: "The predicted room-temperature conductivity of dense 50 %-anion-disordered Li₆PS₅Cl (**29.5 mS cm⁻¹**) agrees with QENS (31.0 mS cm⁻¹) but exceeds the best EIS value by ~6×" — **반드시 "modified NE 변환 · Λ 가정 · 치밀 가정" 을 함께 적는다.**
- ⚠ **인용 시 반드시 붙일 단서 (리뷰어가 물을 것)**: "Reported grain-boundary diffusivities are **not measured
  region-resolved quantities**; they are obtained by inverting a volume-weighted parallel two-phase model,
  `D_GB = (D_cell − (1−f)·D_bulk)/f`, with the GB volume fraction fixed by an **assumed 2.5 nm GB width**
  (*f* = 0.676 for their 10 nm cell). Our own re-inversion shows the headline ratio `D_GB/D_bulk = 0.44`
  becomes 0.18 at a 1.5 nm width and is undefined (negative) at 1.0 nm." — **digest §14-④ 근거, 저자 코드 실측.**
- ⭐ **우리 규약 방어용**: "Even a state-of-the-art multiscale study of the same material family extracts
  Li diffusivities with the Einstein exponent **fixed to unity** and a single time origin, and its reported
  activation energies carry **no MD-seed error bars** — which is why we keep a fixed 2–50 ps window with a
  free intercept and a mandatory 3-seed spread." (⛔ 논문 본문에는 없다 — **저자 배포 코드에서만 확인된다**.)

## 13. 기법 미니 용어집 (우리 팀 새 개념 위주)

- **CSL / Σ 지수 (coincidence-site lattice)**: 두 결정립을 회전시켰을 때 **겹치는 격자점의 밀도의 역수**. Σ3 = 격자점 3개당 1개가 겹침 = 매우 정합적인 경계. Σ 가 클수록(Σ99) 무질서한 "일반 GB". 여기선 tilt 축 [110] 고정, 회전각만 스캔.
- **Moment tensor potential (MTP)**: 원자환경을 **모멘트 텐서**의 축약으로 기술하는 다항식형 MLIP. `level` = 다항식 차수 상한(6→20) — 높을수록 파라미터·비용↑. UMA 같은 범용 GNN 과 달리 **계 하나에 하나씩 맞춰 쓰는** 경량 모델.
- **D-optimality / MaxVol / 외삽등급 γ**: 훈련셋에서 "**행렬식이 최대**가 되는 m 개 구조"를 활성집합으로 뽑고, 새 구조를 그 기저로 표현했을 때 계수의 최대 절댓값이 γ. **γ<1 = 내삽, γ>1 = 외삽.** 앙상블 없이 **단일 모델로** 불확실도를 재는 방법 (↔ [Carrete23UQ] 의 committee).
- **local-AL vs global-AL**: 불확실도를 **원자마다** 재느냐(local) **구조 전체**로 재느냐(global). local 이면 30 000 원자 셀에서 문제가 되는 원자 주변만 200원자로 잘라 DFT 를 돌릴 수 있다 — 그게 비용 절감의 원천.
- **과잉엔트로피 (2체 excess entropy)**: g(r) 로부터 계산하는 국소 무질서 지표(Piaggi–Parrinello). 완전 결정 ≈ 낮음(−4 k_B), GB·삼중점 ≈ 높음(−3 k_B). OVITO 내장.
- **계산 균질화 (computational homogenization)**: RVE 에 거시 구배(여기선 Δc)를 걸고 주기경계로 미시장을 풀어 **유효 물성 텐서**를 뽑는 절차. 여기서는 선형(Fick)이므로 3방향만 풀면 D_macro 텐서 완성.
- **FANS (Fourier-Accelerated Nodal Solver)**: 복셀 격자 위에서 FFT 로 균질화 문제를 푸는 솔버. 메시 생성이 필요 없어 512³ 같은 큰 격자에 유리.
- **collapsed interface (두께붕괴 계면)**: 얇은 GB 를 **두께 0 의 2D 면**으로 바꾸고 두께를 구성식 파라미터로만 남기는 기법. µm 입도에서 GB 를 메시로 분해하는 비용을 없앤다.
- **Maxwell–Garnett 추정**: 매질 안에 소량의 이질상이 분산됐을 때의 유효 물성 해석식. FE 결과의 sanity check 로 쓰임.
- **Meyer–Neldel 규칙 (보상 법칙)**: ln D₀ ∝ Ea. 장벽이 높은 계는 prefactor 도 크다. 기울기의 역수 E_MN 이 특성 에너지.
- **Haven ratio H_R**: tracer 확산 D* 와 전하수송 확산 D_σ 의 비 (H_R = D*/D_σ). H_R = 1 이면 무상관 hopping. 협동운동이면 <1.
- **PDF (pair distribution function)**: 총 산란에서 얻는 실공간 상관함수. 장거리 상관이 살아 있으면 큰 결정, 15 Å 너머 감쇠하면 나노결정.

**④ "입계 폭 2.5 nm" 는 결과가 아니라 선택이고, 이제 *얼마나* 걸려 있는지 계산할 수 있다** 🔴🔴
- SI `Table S2`: **10 nm 2결정립 셀에서 GB 폭 2.5 nm 면 GB 부피분율 f = 67.63 %.**
  ⇒ **"입계 확산계수" 라고 부른 양이 사실상 셀의 2/3 를 평균한 값**이다. 날카로운 계면의 물성이 아니다.
  (연속체 쪽도 마찬가지: 배포 CSV 의 분해 나노입도 런은 GB 부피분율 **최대 71.5 %**.)
- **⭐ 배포 코드가 밝힌 정확한 의존성** (§10-②): `D_GB = (D_cell − (1−f)·D_bulk)/f`.
  **digest 계산 (원논문 미보고)** — 50 % 무질서 Li₆PS₅Cl, 300 K, D_bulk = 2.1842, 발표된 D_GB = 0.9594 이면
  역산한 측정 셀 값은 D_cell = (1−0.6763)·2.1842 + 0.6763·0.9594 = **1.3558**. 이 D_cell 을 고정한 채 폭만 바꾸면:

  | GB 폭 | f (Table S2) | **유도 D_GB** | **D_GB/D_bulk** |
  |---|---|---|---|
  | **2.5 nm** (논문 채택) | 0.6763 | **0.959** | **0.44** |
  | 1.5 nm | 0.4608 | **0.387** | **0.18** |
  | 1.0 nm | 0.3261 | **−0.36 (음수!)** | 정의 불가 |

  ⇒ **헤드라인 "무질서 Li₆PS₅Cl 에서 GB 가 D 를 0.44× 로 깎는다" 는 폭 가정의 함수다.**

  말한 것의 **수학적 정체가 이것**이다 — 큰 수 두 개의 차를 작은 f 로 나누는 **악조건 역산**.
- 즉 2.5 nm 는 **"실험과 맞고 스케일 간 일치가 되는 값"** 으로 사후 선택된 것에 가깝다(ref 22 승계).
  코드 주석도 **`# temporary setting of gb width`** 다.
- FE 의 전이입도 100 nm 도 **이 폭에 종속**(저자 명시). GB 부피분율 6.3 % 로 환산해야 폭 독립.
- 🔴 **모델 불일치**: D_GB 를 **병렬(산술) 혼합**으로 역산해 놓고, 그 값을 **진짜 균질화를 하는 FE** 에
  집어넣는다. 병렬 혼합은 Wiener **상한**이라 막는 GB 에서 D_GB 를 계통적으로 과대추정할 수 있다.
⇒ **D_GB 절대값을 우리 표로 옮기지 않는다.** 옮길 수 있는 것은 **D_GB/D_bulk 비**와 **입도 의존 곡선의 형태**뿐이고,
  그 비조차 **"폭 2.5 nm 가정 하에서"** 라는 단서를 달아야 한다.

**⑤ "다결정" 이 결정립 2개다** ⚠
원자 모형의 polycrystal 은 **2 결정립**이다(FE 는 27립). 무작위 배향이라 GB 는 여러 종류가 섞이지만,
**결정립 크기 분포·배향 텍스처·삼중점 통계는 없다.** 저자가 "surrogate GB model" 이라 부르는 것은 정직하지만,
`Table 1` 의 D_GB 가 **"다결정 내 모든 GB 의 평균"** 이라 할 때 그 표본은 2립 셀 하나에서 온다.

**⑥ MD 통계 규약이 약하다 — 코드로 확인하니 더 약하다** ⚠🔴
- 평형화 **NPT 0.2 ns** 만. 그 뒤 **NVE 5 ns** — 열욕 없이 5 ns 는 에너지 드리프트 위험(점검 미보고).
- **⭐ MSD 로그-로그 기울기 1 을 "확인"한 게 아니라 *강제*했다** (§10-③).
  `func(x,a) = x + a` 로 α ≡ 1 을 부과하므로, **하부확산(α<1)이 있어도 D 가 나온다.**
  α 를 자유롭게 두는 `fit_alpha.py` 결과는 논문 어디에도 안 실렸다 — **그게 실렸어야 할 검증이다.**
- **단일원점 MSD** (프레임 0 하나 기준). 다중원점 시간평균이 아니라 통계효율이 낮다.
- **창이 벌크 3–5 ns, 다결정 4–5 ns 로 다르고**(§10-④) 그 둘을 빼서 D_GB 를 만든다(§14-④).
- **MD 시드 반복이 안 보인다.** 오차막대는 전부 "독립 MTP 5개"(**모델** 산포)이고 **시드 산포가 아니다.**
  50 % 무질서 벌크만 6배열 독립 MD 를 했고 그 산포는 **±2.4 meV** 로 매우 작다(§10-⑩).
  ⇒ `Table 1` 의 D 대부분에 **오차막대가 없다.**
- ⇒ 우리 3-seed 규율이 이 논문보다 엄격하다. **"문헌도 그렇게 한다"는 변명으로 쓸 수 없다.**
  ⚠ 단, 그들 배열 산포가 작은 것은 규율 덕이 아니라 **셀이 5.2만 원자라 자기평균**되기 때문이다 —
  **"우리도 큰 셀 쓰면 시드 3개 안 해도 된다" 로 읽으면 안 된다** (우리 셀은 그 1/100 규모다).

**⑦ Λ 의 순환성 (§9-A 반복)** 🔴
`Fig. 4b` 의 σ 세로 위치는 **실험에서 앵커된 Λ_I** 때문에 자유 예측이 아니다. **T_c 와 기울기만 인용한다.**
그리고 저자가 스스로 *"predicted conductivities are underestimated"* 라고 쓴 그 격차는, 우리 재계산으로
**장벽 0.219 eV 과대평가**(예측 0.683 vs 실험 0.464 eV)이고 **312 K 에서 13× 로 벌어진다.**
⇒ **Li₆PS₅I 의 정량 예측은 실패했다.** 성공한 것은 **T_c 와 비-Arrhenius 의 존재**다. 이 구분을 흐리면 안 된다.

**⑧ 공극은 예측이 아니라 후보정이다** ⚠
SI Fig S22 의 공극 효과는 **FE 로 푼 것이 아니라** 외부 이론모델·실험에서 온 배수를 **곱한 것**이다.
그런데 세 모델의 답이 41 % 공극에서 **0.306 vs 0.0295 — 10배 다르다.** ⇒ *"공극을 고려하면 실험에 가까워진다"* 는
**어느 모델을 쓰느냐에 따라 과·소 양쪽으로 다 갈 수 있다.** 정량 인용 금지.

**⑨ 실험 비교가 전부 문헌 소환이고, 그 문헌들끼리 서로 안 맞는다** ⚠
같은 Li₆PS₅Cl 의 실험 장벽이 **0.112 (QENS) ~ 0.451 (EIS Kraft) eV** 로 4배 스팬이고,
`Fig. 3f` 의 두 EIS 데이터셋(Shotwell vs Kraft)은 **할라이드 경향이 서로 반대**다(Cl 0.344 vs 0.451; Br 0.357 vs 0.303).
저자는 *"우리 경향은 Shotwell 과 맞고 Kraft 와는 다르다"* 고 정직하게 쓴다. ⇒ **이 논문의 "실험과 일치" 는
어느 실험을 고르느냐에 의존한다.** 우리가 인용할 땐 **어느 실험 짝인지 반드시 명시.**

**⑩ 전이성 실패를 논문이 축소해 말한다** ⚠
SI 본문: *"Transferability is relatively good for Li₆PS₅Cl, whereas it is **limited** for Li₆PS₅Br and Li₆PS₅I."*
실제로는 **Br 27.71 meV/atom** — 자기들 프로덕션 기준(<10)의 **2.8배**다. "limited" 는 관대한 표현이다.

**⑪ 우리 modelc(Cl-rich) 에 직접 적용 불가** 🔴
그들의 무질서는 **화학량론 고정 자리교환**이고 우리 modelc 는 **조성 변화 + Li 공공**이다.
`Fig. 3b` 의 무질서 축 위에 우리 modelc 를 찍으면 안 된다. 겹치는 것은 **comp1 (Li₆PS₅Cl) 하나뿐**이다.
