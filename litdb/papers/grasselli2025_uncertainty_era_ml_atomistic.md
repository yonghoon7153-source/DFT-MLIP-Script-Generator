## 1. 한 줄 요약

MLIP 시대의 불확실도 정량화(UQ)를 **하나의 수식 — 마할라노비스 거리 `σ²_★ = α² f_★ᵀ G f_★` (식 1) — 으로
통일해서 보여 주는 Perspective**. 선형회귀·GPR·NN(Laplace/마지막층)·앙상블·mixture-of-experts·
능동학습(MIG·D-optimality·데이터 엔트로피)이 **전부 이 한 식의 변형**임을 유도하고, 그 위에
**캘리브레이션 절차 · 강건성(robustness) · 전이성(transferability) · 파운데이션 모델의 UQ** 를 정리한 뒤,
**미해결로 남은 것들**(특히 **수송계수·스펙트럼 같은 시간의존 관측량으로의 불확실도 전파 이론 부재**)을
열거한다.

## 5. 절별 상세 — 이 리뷰가 실제로 말하는 것

### 5-1. §2 서두 — UQ 방법이 갖춰야 할 5조건, 그리고 "불확실도"의 조작적 정의

저자들이 (ref 2 를 따라) 좋은 UQ 의 요건을 5개로 못 박는다:

1. **Accurate** — 진짜 불확실도를 현실적으로 모델링, 편향·계통오차 최소화
2. **Precise** — 충분히 좁은 범위를 줄 것
3. **Robust** — 데이터·모델가정 변화에도, **도메인 밖에서도** 신뢰할 만할 것
4. **Traceable & comprehensive** — **가능한 모든 불확실도 원천을 포착·식별**할 것.
   여기서 원천을 열거한다: **하이퍼파라미터 선택 · 훈련셋 데이터 점 · 비결정론적 모델의 확률적 최적화**
5. **Computationally efficient** — 추론(가능하면 훈련까지)에 무시할 만한 오버헤드

그리고 **조작적 정의**: 이 리뷰에서 "불확실도" = **예측 분포의 분산(2차 모멘트)**.
저자들이 그 한계도 같이 적는다 — *"1·2차 모멘트만 보는 것은 비가우시안(왜도·두꺼운 꼬리·다봉) 분포에는
충분히 서술적이지 않을 수 있다."* 그럼에도 채택한 이유: 해석 가능·가볍고, Laplace 근사 계열과 잘 맞고,
**잔차 `y_i − ỹ_i` 의 2차 모멘트와 직접 비교하는 단순한 캘리브레이션 전략을 지지**하기 때문.

### 5-2. §2.1 — 이 리뷰의 척추: 모든 직접 UQ 공식은 마할라노비스 거리다

새 샘플 ★ 에 대한 불확실도의 일반형 (식 1):

```
σ²_★ = α² · f_★ᵀ G f_★
```

- `f_★` = 모델이 그 샘플에 부여하는 **특징(feature) 벡터** (중심화 가정)
- `G` = **양정치 계량텐서**. 세 가지 공통 성질을 갖는다:
  ① 훈련셋 특징의 **역공분산**으로 볼 수 있다 — `G = [cov(F)]⁻¹`
  ② 따라서 훈련점 분포와, 새 점이 그 분포에 이 계량으로 얼마나 "가까운가"에 **강하게 의존**
  ③ 훈련셋의 **타깃값 `y_i` 에는 거의 무관** (각주 †: 유일한 의존은 역행렬 안정화용 정칙화 항뿐)
- `α` = **캘리브레이션 상수**. ★에 무관한 전역 스칼라이고 **분산에 올바른 단위를 준다**. 검증셋에서 맞춘다.

성질 ③이 핵심이다. **이 계열의 불확실도는 "정답을 몰라도" 계산된다** — 그래서 능동학습에 쓸 수 있고,
동시에 **"타깃 지형이 험한지"는 전혀 모른다**(§3.4 의 한계로 되돌아온다).

| 모델 | 특징 `f` | 계량 `G` | 식 |
|---|---|---|---|
| 선형회귀 | `f ≡ x` | `(XᵀX + λ²I_D)⁻¹` | (3),(4) |
| GPR | `f = φ(x)` 기저함수 | `(FᵀF + λ²I_{N_f})⁻¹` | (6),(7) |
| GPR(커널형) | — | `k(x★,x★) − k(x★,X)ᵀ[K(X,X)+α²I]⁻¹k(x★,X)` | (8) |
| NN (Laplace) | `f_i = (∂ỹ_i/∂w)|_{w_o}` (역전파로 획득) | `H_o⁻¹` (손실의 헤시안, Gauss–Newton 근사) | (10)–(12) |
| **NN (마지막층 = LL)** | **`f_i = (∂ỹ_i/∂w_L)|_{w_o}`** | `(FᵀF + λ²I_{N_L})⁻¹` | **(14)** |

**GPR 두 형태(7)↔(8) 은 Woodbury 항등식으로 오간다.** `F` 가 full rank 가 아닐 때 어느 쪽이 역행렬을
가지느냐가 갈리므로(tall `N_train > N_f` vs broad `N_train < N_f`) **정칙화가 결정적**이다.

**NN 의 실무 문제와 해법**: 완전 헤시안 `H_o` 는 딥NN 파라미터 수의 제곱이라 **저장 자체가 불가능**.
→ **마지막층(LL) 근사** (Bigi et al. ref 15 가 정당화). NTK(Neural Tangent Kernel) 형식론이
이론적 근거를 준다. 저자들이 다는 단서 3개:
1. `ỹ = f ᵀw_L` 처럼 **마지막층 뒤에 추가 비선형 활성화가 없다는 가정**. `ỹ = φ(f ᵀw_L)` 면 복잡해진다(원리적으로는 MC 적분 가능).
2. LL 잠재특징은 `w_L` 에 **명시적으로 의존하지 않고**, 훈련 중 거의 상수. 초기화에서 동일분포·0중심이라 **추가 센터링이 결과를 안 바꿔야 한다**. (← Appendix C 와 미묘하게 대립. §13-4)
3. **`α²` 캘리브레이션은 결정적이고, 정칙화 `λ²` 는 자릿수를 몇 개 흔들어도 `σ²_★` 를 거의 안 바꾼다** — 데이터가 희소하거나 심하게 공선적일 때만 예외.

⚠ **NTK 의 한계도 인용한다** (Wenger et al. ref 21): NTK 의 이점을 쓰려면 *"깊이보다 자릿수만큼 넓은 아키텍처"*
가 필요하다. 저자들은 각주에서 **DeePMD 기본형(3층×240)·Behler–Parrinello(2층×40)** 를 들어
"원자 학습 쪽은 실제로 그렇다"고 방어한다. ⚠ **그런데 현대 등변 메시지패싱 GNN(MACE·SevenNet·UMA)은
그 각주가 커버하지 않는다** — §13-2.

**§2.1.4** Laplace 를 못 쓸 때: 사후분포 `p(w|D) ∝ exp[−U(w)/T]` 를 MCMC 로 명시 표집.
`T` 는 사후 "온도" 하이퍼파라미터 (`T=1` 이 참 베이즈, `T<1` 은 "cold posterior" = 더 뾰족).
NN 규모에선 Hamiltonian MCMC 가 감당이 안 되므로 **stochastic-gradient MCMC** (refs 28, 29) —
**결과가 (deep) 앙상블과 비슷하다**고 보고. 마지막층 변분 베이즈(ref 30)는 **원자 ML 에서 아직 미탐색**.

### 5-3. §2.2–2.3 — 앙상블 · 평균-분산 모델 · shallow ensemble · MoE

**§2.2 앙상블**: *"여러 개의 **동등한(equivalent)** 모델 `y⁽ᵐ⁾(x)`"* 을 만들어 경험적 평균(17)·분산(18)을 쓴다.
멤버를 만드는 표준 두 방법:
1. **데이터 부분표집** — 각 `D⁽ᵐ⁾` 크기 ≈ `(M−1)/M × N_train`
2. **훈련의 확률성** — **랜덤 시드 변경**, Monte-Carlo dropout (ref 31)

> ★ **여기가 우리 매핑의 결정적 지점이다.** "동등한 모델" 이라는 전제, 그리고 시드가 가리키는 것이
> **훈련 시드**라는 점. 우리 것은 둘 다 아니다 → §6-1.

**§2.3 MV(평균-분산) 모델**: 예측과 분산을 **모델이 같이 출력**하도록 학습(NLL 손실, 식 19).
Busk et al. (ref 33) 은 이 `σ̃²(x)` 를 **aleatoric**(무작위 잡음·데이터 불일치·모델이 정확히 못 맞추는 것;
데이터를 더 모아도 안 준다)으로 해석한다.

> ⚠ **저자들이 즉시 반론을 단다** (ref 34 Heid): *"**잡음 없는 관측(noiseless observations)을 가정한
> 데이터셋**이라면, 모델 예측이 관측에서 벗어난 것은 **전부 모델의 편향(bias)으로 봐야 한다**"* —
> 관측을 ground truth 로 두면 완벽한 모델은 그 점들을 정확히 지나야 하니까.
> **★ 우리 DFT 라벨이 정확히 그 "잡음 없는 관측"이다** → §6-1 에서 다시 쓴다.

**MV 앙상블 = deep ensembles** (Lakshminarayanan ref 35, `Fig. 3a`): MV 모델 M개의 위원회.
```
σ²_tot(x) = (1/(M−1)) Σ_m (ỹ⁽ᵐ⁾−ȳ)²   +   (1/M) Σ_m σ̃²,⁽ᵐ⁾(x)
             └── epistemic ──┘              └──── aleatoric ────┘        (식 20)
```
(두 항이 무상관이라는 가정) — Busk(33)·Carrete(36) 의 해석. **`Fig. 3a` 가 이 라벨을 그림에 직접 박아 놨다.**

**§2.3.1 shallow ensemble** (`Fig. 3b`, Kellner–Ceriotti ref 37): 앙상블 5–10개 훈련이 너무 비싸니,
**나머지 가중치는 공유하고 마지막층만 M벌** 두는 구조. LL 근사와 같은 정신. 비용이 거의 안 든다.
⚠ 그림에서 읽히는 것: **shallow ensemble 출력에는 aleatoric 상자가 없다** — 멤버 퍼짐 `σ²_i` 하나뿐.

**§2.3.2 Mixture of Experts (MoE)** — ★★ **UMA 가 여기 인용된다**:
> *"In the context of atomistic modeling these have been explored by **Zeni et al.** for monoelemental
> systems and **Wood et al. for efficient universal models for atoms**."*
ref 40 = **Wood, Dzamba, Fu, Gao, Shuaibi, Barroso-Luque, … Zitnick, "UMA: A Family of Universal Models
for Atoms" (2025)** = **우리가 쓰는 UMA 그 논문**.

MoE 형식:
```
ỹ(x★) = Σ_k p_k(x★) ỹ⁽ᵏ⁾(x★)                                    (21)
p_k(x) = e^{s(d_k(x))} / Σ_k' e^{s(d_k'(x))}   (거리 기반 soft-max, Zeni)  (22)
p_k(x) = p⁽ᵏ⁾(x) / Σ_k' p⁽ᵏ'⁾(x)               (밀도 기반)                (23)
σ²,⁽ᵏ⁾_★ = α²,⁽ᵏ⁾ f_★ᵀ G⁽ᵏ⁾ f_★                                   (24)
⇒ σ²_★ = Σ_k [∂ỹ★/∂ỹ⁽ᵏ⁾★]² σ²,⁽ᵏ⁾_★ = Σ_k p_k² σ²,⁽ᵏ⁾_★            (25)
```
전문가끼리 **독립**이라는 가정 아래 표준 오차전파. ⚠ **식 (25) 가 UMA 에 그대로 안 붙는 이유는 §13-3.**

### 5-4. §2.4 — 캘리브레이션: 절차와 채점 ★

**왜 필요한가**: 식 (1) 의 `α²` 는 임의 스케일이자 **단위를 주는 상수**다. 맞추기 전의 `σ` 는
"상대 순위"만 있고 "eV/Å 단위의 오차막대"가 아니다.

**§2.4.1 최대로그우도 캘리브레이션** (Musil ref 41, Imbalzano ref 11):
```
α² = (1/N_val) Σ_i |y_i − ȳ(x_i)|² / σ²(x_i)                                   (26)
```
**⚠ 식 (26) 은 앙상블 멤버 수 M 에 대해 편향 추정량이다.** M 이 작으면 편향보정형을 써야 한다:
```
α² = −1/M + [(M−3)/(M−1)] · (1/N_val) Σ_i |y_i − ȳ(x_i)|² / σ²(x_i)            (27)
```
> 저자 문장 그대로: *"from which it is also seen that **at least M = 4 members are needed**."*
> (`(M−3)/(M−1)` 가 M=3 에서 0 이 되어 `α² = −1/3 < 0` — 데이터와 무관하게 음의 분산 스케일이 나온다.
> 부호가 바뀌는 지점은 `M² − 4M + 1 = 0` ⇒ `M = 2+√3 ≈ 3.73` — **우리 산술**)

또 하나의 단서: *"캘리브레이션 후에는 epistemic/aleatoric 성분의 명확한 구분을 되짚는 것이
**문제가 될 수 있다**"* — 전역 스칼라를 곱하면 식 (20) 의 두 항이 섞인다.

**§2.4.2 expected vs observed parity plot + ENCE**: 추정분산 대 관측 잔차²을 **log–log** 로 놓고
(보통 추정분산으로 binning) 그린다. 요약 스칼라:
```
ENCE = (1/N_bins) Σ_b |RMV(b) − RMSE(b)| / RMV(b)                              (28)
RMV(b) = sqrt( (1/|b|) Σ_{i∈b} σ²(x_i) )      RMSE(b) = sqrt( (1/|b|) Σ_{i∈b} |y_i−ỹ(x_i)|² )
```
**★ 이 절의 진짜 알맹이(진단 논리)**:
- log–log 공간에서 `α²` 를 바꾸는 것은 **그림 전체의 강체 평행이동(rigid shift)** 이다.
- ⇒ **캘리브레이션이 안 된 UQ 라도 선형 상관은 보여야 한다.**
- ⇒ **선형 상관이 나쁘면** 식 (1) 의 가우시안형 UQ 틀 자체가 부적절하거나(층당 뉴런이 적은 NN 에서 발생),
  **국소 캘리브레이션 `α²(x)` 가 필요하다**는 뜻이다.

**Pernot 층화(stratification)** (refs 43–45): 예측 불확실도 크기(저/중/고)로 데이터셋을 쪼개
**부분집합마다 따로** 캘리브레이션 점수를 낸다. binning 방식을 바꿔 가며 보면 두 가지를 구분할 수 있다:
- **consistency** = 예측 불확실도에 대한 조건부 캘리브레이션
- **adaptivity** = 입력 특징에 대한 조건부 캘리브레이션
→ *"둘은 상당히 별개이고 상보적인 캘리브레이션 목표"*.

**§2.4.3 miscalibration area** (CDF 기반): 잔차의 기대 CDF 와 관측 CDF 사이 면적. 부호로 과신/과소신도 진단.
**⛔ 저자들이 권하지 않는다**: CDF 비교는 **더 높은 모멘트까지 섞어서 본다**. 2차 모멘트가 같아도
왜도·두꺼운 꼬리 때문에 CDF 가 크게 갈릴 수 있어 **불확실도와 분포모양을 혼동**한다.
> *"For this reason, we recommend prioritizing the calibration strategies discussed in Sec. 2.4.1 and 2.4.2."*

**§2.5 Conformal prediction (CP)** — 분포무가정(distribution-free) 대안. 절차:
1. 회귀모델 학습 → `ỹ_i`
2. **별도의** 캘리브레이션 데이터셋 `C` 준비
3. **비순응 점수** `s_i = |y_i − ỹ_i|` 계산 (i ∈ C)
4. 정렬된 점수의 **(1−α) 분위수 `q_{1−α}`** 결정 (α=0.05 면 점수의 95 % 가 `q_0.95` 아래)
5. 새 입력 `x★` 의 예측구간 = **`[ỹ★ − q_{1−α}, ỹ★ + q_{1−α}]`**

⇒ 참값을 최소 `1−α` 신뢰도로 포함. **`q_{1−α}` 는 입력에 무관한 전역 문턱**("전형적 오차")이다.
⚠ **핵심 가정**: 시험셋 오차분포가 훈련·캘리브레이션셋 오차분포를 대표할 것.
**시험 입력이 상당히 OOD 면 가정이 깨지고 구간은 유효성을 잃는다.**
원자 모델링 적용례: Hu et al. (ref 49) · Zaverkin et al. (ref 50).

### 5-5. §2.6 — "UQ 방법들이 다 같은가?" → **표준 벤치마크가 없다**

*"ML 모델 정확도에 대한 표준 벤치마크·평가 프로토콜조차 최근에야 정립됐고 곧 그 한계도 드러났다.
마찬가지로 **UQ 방법 신뢰도에 대한 합의는 아직 없다** — 불확실도 추정을 위한 유일한 벤치마크 집합이
아직 개발되지 않았다."*

리뷰가 정리한 3개 연구 (전부 `[리뷰경유]`):
| 연구 | 계 | 결론 |
|---|---|---|
| **Tran et al.** (본문 첨자 51) | 금속 위 소분자 흡착에너지 | **CNN(특징추출) + GPR(예측) 하이브리드**가 가장 효과적 — 정확도와 신뢰할 만한 UQ 를 동시에 |
| **Tan et al.** (ref 52, *npj Comput. Mater.* 2023) | in-domain **rMD17** → out-of-domain **벌크 실리카 유리** | **어떤 방법도 일관되게 우월하지 않다.** 앙상블 = 일반화·강건성 우수 · MVE = in-domain 우수 · GMM = out-of-domain 우수. **총평: 단일모델 접근은 NNIP 의 UQ 에서 앙상블보다 덜 신뢰할 만하다** |
| **Kahle & Zipoli** (ref 53, *PRE* 2022) | 원자 이합체 · Al 표면 슬랩 · 벌크 액체 물 · 진공 벤젠 | **NN 퍼텐셜 앙상블은 과신(overconfident)일 수 있다** — 불확실도를 과소평가. **계와 아키텍처마다 따로 캘리브레이션이 필요.** 대안으로 베이지안 NN 퍼텐셜(MC 사후표집) 제안 |

추가 실무 지적: UQ 를 기존 ML 아키텍처에 붙이는 구현이 **대개 한 방식 전용**이고,
**하나의 워크플로가 다양한 UQ 방법을 지원하는 경우가 드물다.**

### 5-6. §2.7 — 크기확장성: σ 는 N 으로 어떻게 커지나 (미해결)

MLIP 는 전에너지를 원자 기여의 합으로 학습한다. **그러면 계 크기에 따라 불확실도는 어떻게 커지나?**
두 극한:
- **완전 결정(모든 원자환경 동등)** → 국소 예측이 최대로 상관 → **σ ∝ N**
- **희박 기체(무상관)** → 제곱합으로 커짐 → **σ ∝ √N**
실제 계는 **둘 다 섞여 있다.**

Kellner–Ceriotti 벌크 물 실험(shallow ensemble): 불확실도를 **bias 항**(계 크기별 평균예측−참조의 절대차)과
**residual 항**으로 분해 → **bias ≈ N**, **residual ≈ √N**. 둘 다 유의하게 기여.
⇒ *"확장성을 무시하거나 순진한 스케일링 법칙을 가정하는 접근의 한계를 드러낸다."*

> ⚠ **인용 오류(우리 지적)**: 본문이 *"Kellner and Ceriotti**41**"* 로 달았는데 ref 41 = **Musil et al.**
> JCTC 2019 이고, Kellner & Ceriotti 는 **ref 37** (*MLST* 2024, 5, 035006) 이다. 첨자 오식. §13-6.

### 5-7. §2.8 — ★ 불확실도 전파: 관측량까지 얼마나 가나 (우리 질문 2의 본문)

**세 단계로 정리된다.**

**(a) 해석적 전파 (선형근사)** — `z = f(y)` 이고 선형화가 충분할 때만:
```
σ_z(x★) ≈ |df/dy|_{x★} · σ★                                                    (29)
```

**(b) 명시적 앙상블 표집** — 일반적인 경우. 식 (1) 로는 못 가고 M개 모델을 실제로 굴린다:
```
z⁽ᵐ⁾(x) = f(y⁽ᵐ⁾(x)) ,  z̄ = (1/M)Σ z⁽ᵐ⁾ ,  σ²_z = (1/(M−1)) Σ (z⁽ᵐ⁾ − z̄)²      (30)
```

**(c) ★ 오차의 상관 구조를 살리기** — 저자들이 특히 강조하는 실무 요령:
> 가까운 두 배치의 **상대 에너지 `E(x₁) − E(x₂)`** 같은 **차이량**을 계산할 때 배치별 오차가 독립이라고
> 가정하면 **지나치게 보수적인 UQ** 가 나온다. 실제로 ML 모델은 그런 상황에서 **고도로 상관된 예측**을 낸다
> — 절대 불확실도는 커도 **차이의 불확실도는 훨씬 작을 수 있다**(그리고 물리적으로 의미 있는 것은 대개 차이다).
> ⇒ `ΔE⁽ᵐ⁾ ≡ E⁽ᵐ⁾(x₁) − E⁽ᵐ⁾(x₂)` 를 **모델별로 표집**해 평균·분산을 내면 상관이 **자동으로** 들어간다.

**(d) ★★ ML 불확실도 vs 표집(통계) 불확실도의 분리** — 이 리뷰가 우리 축 분할에 주는 정본 문장:
> *"In ML-driven atomistic simulations, UQ is also needed to **single out the uncertainty ascribable to
> ML models from the statistical one due to a poor sampling (i.e. too short trajectories)**: in fact it
> would be **pointless to run very long MD simulations if the uncertainty due to ML could not be lowered
> below a given threshold**."*

**(e) 열역학적(thermostatic) 관측량으로의 전파 — reweighting** (Imbalzano et al. ref 11):
문제: RDF·평균에너지 같은 양은 ML 에너지가 **볼츠만 가중치 안에** 들어간다 (= 위상공간 표집 자체를 바꾼다).
해법: **위원회 평균 퍼텐셜 `V̄` 로 궤적을 딱 하나 돌리고**, 사후에 재가중한다.
```
⟨a⟩_{V⁽ⁱ⁾} = ∫dr w⁽ⁱ⁾(r) a(r) e^{−βV̄(r)} / ∫dr w⁽ⁱ⁾(r) e^{−βV̄(r)} ,
w⁽ⁱ⁾ ≡ exp[−β(V⁽ⁱ⁾(r) − V̄(r))]                                                 (31)
```
⇒ **M개의 `⟨a⟩_{V⁽ⁱ⁾}` 를 얻고, 그 위원회 표준편차가 열역학 평균 `⟨a⟩` 의 불확실도**다.
표집 효율 문제(가중치 붕괴)를 피하려고 **누적량 전개(cumulant expansion)** 기반 안정화 근사도 있다
(refs 11, 37, 56 — ref 56 = Ceriotti & Manolopoulos *PRL* 2012).

**(f) ★★★ 여기서 멈춘다 — 시간의존 관측량은 미해결**
> *"Looking ahead, fundamental questions remain… **what are the key ingredients towards the definition of
> a rigorous theory for uncertainty propagation for time-dependent thermodynamic observables, such as
> correlation functions?** Such a question is relevant for **spectra and transport coefficients**, obtained
> from ML-driven molecular dynamics simulations, since its answer would make it possible to quantify the
> uncertainty on these dynamical observables in an efficient way, **bypassing time-consuming, brute-force
> approaches that require running several trajectories**."*

⇒ **직답: 전파는 (i) 힘·에너지 → (ii) 에너지 차이 → (iii) 정적/열역학 평균(RDF·⟨E⟩)까지 간다.
확산계수·열전도도 같은 수송계수와 스펙트럼(= 시간상관함수)에는 **이론이 없다.** 현재 유일한 길이
"여러 궤적을 무식하게 돌리기"이고, 저자들이 그걸 **비효율의 대명사**로 부른다.**

### 5-8. §2.9 — ★ 모델 오설정(misspecification): 앙상블이 **못 보는** 오차

여기까지의 UQ 는 전부 *"i.d. 잡음만 빼면 참값이 원리적으로 모델 형태 안에 있다"* 를 암묵 가정했다.
**오설정** = 가정한 모델 형태가 참 데이터생성 과정과 안 맞는 경우.

UQ 에 미치는 영향이 고약하다:
- `N_train → ∞` 이면 사후 `p(w|D)` 는 점추정 주변으로 **뾰족해진다**.
- 모델이 잘 설정돼 있으면 괜찮지만, **오설정이면 파라미터는 "틀린 모델류 안에서만 최적"인 값으로 수렴하고,
  가중치의 사후 불확실도는 줄어드는데 예측 불확실도는 줄어들면 안 된다.**
- 통계·베이즈 추론의 많은 기본 정리가 **well-specified 를 가정**하므로 수정이 필요하다 (ref 67).

원자 모델링에서 오설정이 생기는 경로: **빠뜨린 물리 · 데이터 커버리지 부족 · 잘못된 모델 가정.**
현대 NN 은 용량이 커서 과적합 없이도 아무 함수나 맞출 수 있지만 **오설정은 그와 별개**다.

**★ 결정적 예시 (우리에게 그대로 해당)**:
> 장거리 상호작용을 표현 못 하는 모델(분자 이합체 결합곡선, ref 69) 에서는 **앙상블 멤버 전원이 똑같이 틀린
> 예측에 합의**한다 — 컷오프 밖에서 힘이 0 이 되는 것 같은. **⇒ 인위적으로 낮은 불확실도 추정.**
> *"Such issues **cannot be resolved even with calibration strategies like eqn (26)**"* — 전역 캘리브레이션
> 하나로는 잘 되는 영역(짧은 거리)과 계통적으로 실패하는 영역(먼 거리)을 동시에 맞출 수 없기 때문.
> 또 다른 예: **날카로운 반발 벽을 매끄러운 함수로 모델링**하려는 MLIP.

### 5-9. §3.1–3.2 — in/out-of-distribution: 기하 vs 통계

**§3.1 기하학적(convex hull)**: 훈련 특징의 볼록껍질 `Conv(X)` 안 = in-distribution, 밖 = OOD.
**⛔ 고차원에서 실용성이 무너진다**: 껍질 구성·평가 비용이 차원에 따라 급증하고, **껍질을 근사하는 데
필요한 점 수가 차원에 지수적으로 증가**(차원의 저주). ⇒ 고차원에서 껍질이 희박해져 **거의 모든 점이 OOD 로
분류**된다 (ref 70). **국소 원자환경 표현 기반 원자 ML 에도 그대로 성립** (Zeni ref 71).
추가 함정: 고차원 표현의 **내재차원(intrinsic dimensionality)** 은 낮을 수 있는데, 시각화용
**저차원 투영(D=2,3)** 은 경계를 지나치게 단순화해 **in-distribution 을 OOD 로 잘못 분류하는 인공물**을 만든다.

**§3.2 통계적(밀도 기반)** — 특징공간 표집밀도로 판정. **적응적 k-NN 밀도추정** (Zeni et al. ref 71):
시험점 `x*` 를 훈련셋에 임시로 넣고 `k*` 최근접 이웃을 찾아
```
ρ(x*) = (k* − 1) / (M · V*)                                                     (32)
```
(`M` = 훈련 예제 총수, `V*` = `k*` 이웃에 해당하는 부피). `k*` 는 점마다 **적응적으로** 고르고,
`V*` 는 **내재차원 `d` 의 초구**로 잡는다 — `d` 는 **TwoNN 추정기**(refs 72,73)로 계산.

이 지표가 **회귀 퍼텐셜의 실측 오차와 상관**한다. 그리고 같은 저자들이
**세 가지가 서로 강하게 일치**한다고 보고: ① 밀도 기반 지표 ② **모델 특이(model-specific)** 오차추정
(= 큰 훈련셋의 서로 다른 부분표집으로 학습한 **위원회의 예측 불확실도**) ③ **모델 무관(model-free)** 추정
(= 예측점과 훈련셋 사이 **하우스도르프 거리**). 잠재공간 거리 기반의 다른 대조 결과(ref 74)와도 일관.

관련 연구:
- **Schultz et al.** (ref 75): 특징공간 **커널 밀도 추정**으로 도메인 판정. 전통적으로 무관하다고 여겨진
  화학군이 이 유사도로 뚜렷이 갈린다. **비유사도가 클수록 잔차가 크고 불확실도 추정도 덜 신뢰할 만하다.**
  허용 비유사도 문턱을 **자동으로 정하는 방법**까지 제안.
- **Zhu et al.** (ref 76): **NequIP** 잠재공간 특징 위에 **GMM** 적합 → 시험점의 **음의 로그우도**.
  NLL 이 높을수록 예측 불확실도가 높았다.

⚠ 저자들의 유보: 이 지표들의 **크기는 선택한 표현에 의존**하고, **MAE 와의 정확한 상관은 계와 모델에 달렸다.**

### 5-10. §3.3 — 전이성(transferability) 세 갈래 (`Fig. 5`)

정의: *"훈련셋과 **다른 조건**에서 표집된 구조에 대해 정확도를 유지하는 능력."* 그런데
*"그 '다른 조건'의 정의가 다소 허술하게 남아 있다."* 세 갈래로 정리:

| 갈래 | 뜻 | 리뷰의 경험적 관찰 |
|---|---|---|
| **Phase** | 특정 상(다형체)으로 학습 → 다른 상 예측 (비슷한 온도 가정) | **정확도 vs 일반성 사이 상충(trade-off)이 흔하다.** 다만 많은 실용 목적에는 그 상충이 수용 가능 (refs 39, 81) |
| **Temperature** | 예: 고온 표집으로 학습 → 저온 시험 (또는 반대) | **고온 데이터로 학습한 모델은 저온으로 잘 일반화되는 편** (refs 79, 82) |
| **Compositional** | 미학습 조성. **화학량비 변화**와 **미학습 원소(alchemical learning)** 둘 다 | **조성공간 내부 보간은 대체로 된다. 완전히 새로운 화학량비나 원소로의 외삽은 맞춤 기법 없이는 상당히 어렵다** (refs 84, 85) |

**합격 기준(관행 나열, 표준 아님)**:
- 시험 도메인 오차가 훈련 도메인과 **비슷**하다
- 오차가 꽤 커졌지만 **실용 목적에 수용 가능** (예: **에너지 < 10 meV/atom, 힘 < 100 meV/Å**)
- **장시간 시뮬레이션이 안정** — 유의한 에너지 드리프트 없음, 비물리적 배치를 표집하지 않음

> *"**전이성의 엄밀하고 표준화된 정의의 부재**가 이 주제 연구들의 결론을 통합하려는 우리 시도를
> 어렵게 한다."*

**복잡도 vs 전이성**: 원리적으로 유연한 모델이 과적합에 취약해 전이성이 낮아야 하고, **피드포워드 NN 기반
방법에서는 그 경향이 관찰됐다**(ref 78). **그러나 현대 고차 그래프 합성곱 / 물리기반(대칭보존) 아키텍처는
그 한계를 보이지 않았다**(ref 87) — *"복잡도 증가가 전이성을 반드시 훼손하지는 않는다,
적어도 그 응용들에서 다룬 데이터·파라미터 규모에서는."*

### 5-11. §3.4 — 강건성 정량화: prediction rigidity (PR)

**Chong et al.** (refs 14, 15, 88) 의 PR. 유도: 예측에 섭동을 주고 손실이 어떻게 반응하는지를
라그랑주 형식으로 본다.
```
L̂(w) = L(w) + λ[ ε★ − (f°★)ᵀ(w − w_o) ]                                        (33)
L̂_o(ε★) = L_o + ½ (∂²L̂_o/∂ε★²)|_{ε★=0} ε★²                                     (34)
(∂²L̂_o/∂ε★²)|_{ε★=0} ≡ 1 / [ (f°★)ᵀ (H_o)⁻¹ f°★ ]                               (35)
```
⇒ **PR = 식 (1) 마할라노비스 형태의 역수**. 같은 `H_o` 가 식 (9)·(1) 에도 나온다.

저자들의 세 단서:
- **PR 에는 캘리브레이션 파라미터가 없다** ⇒ 순수하게 **데이터셋·표현 의존** 파라미터이고
  **UQ 지표와는 구별된다**. (불확실도가 아니라 "이 예측이 데이터에 얼마나 단단히 묶여 있나")
- `H_o` 의 데이터셋·훈련 의존성은 Gauss–Newton 근사(식 11)로 계산 가능하고, **주어진 모델에서 상수**다.
- **★ 를 정의하는 자유도가 크다** ⇒ **국소 PR(LPR)** · **성분별 PR(CPR)** 로, **물리 관측량에 대응하지 않는
  중간 예측**(원자별·거리분리 성분)의 강건성까지 정량할 수 있다.

**한계(저자들이 직접 적음)**: 여기까지의 강건성 지표는 **데이터셋 분포에만 의존하고 타깃 분포와는
분리돼 있다** ⇒ **타깃 지형의 복잡도를 무시한다.** 지형이 매끄러우면 적은 점으로 되고, 험하면 더 필요하다.
관련 현상: **activity cliff** (구조적으로 비슷한 쌍이 타깃은 크게 다른 경우, refs 89, 90) 가 성능을 해친다 —
대조학습(contrastive learning) 등으로 표현을 바꿔 그런 구조를 분리하면 학습이 쉬워진다.
데이터점의 영향 해석에는 **수정 Shapley 분석**(refs 91, 92).

### 5-12. §3.5 — 데이터셋 개선·능동학습: "결국 다 같은 기준이다"

두 시나리오: ① 새 타깃 생성이 비싸다(어느 입력에 라벨을 붙일까) ② 방대한 풀에서 부분집합을 고른다.
효시: **"learn on the fly"** (Csányi et al. ref 93) — 예측-교정 알고리즘 + 양자계산.

`Fig. 6` 이 그리는 표준 루프: **불확실도가 문턱을 넘으면 시뮬레이션을 중단**하고, 그 배치를 라벨링해
재학습, 반복. 최근에는 **불확실도가 큰 배치 쪽으로 표집을 바이어스**해 훈련셋 다양성을 확보하고
관심 영역 전체에서 불확실도를 문턱 아래로 유지하는 전략 (refs 50, 100–103).

**§3.5.1 최대 정보이득(MIG)** — 리뷰의 통합 논증:
```
S = −∫dw p(w|D) log p(w|D) = −½ log(det H_o) + const                            (36),(37)
H_o ≈ FᵀF  (Gauss–Newton)                                                        (38)
새 점 추가 → H_o,new ≈ FᵀF + f★f★ᵀ                                               (39)
행렬 판별식 보조정리 ⇒ det(FᵀF + f★f★ᵀ) = [1 + f★ᵀ(FᵀF)⁻¹f★] det(FᵀF)            (41)
⇒ ΔI = ½ log[ 1 + f★ᵀ(FᵀF)⁻¹f★ ]                                                (42)
```
⇒ **정보이득은 `f★ᵀ(FᵀF)⁻¹f★` 가 최대일 때 최대 = 식 (1) 의 불확실도가 가장 큰 곳.**
**"불확실한 곳을 라벨링하라"가 정보이론에서 유도된다.** (Kästner 그룹 ref 24 가 배치 선택으로 확장)
- MIG 는 **타깃과 무관** — 능동선택에 정답을 미리 계산할 필요가 없다.
- `D` 를 고정하면 `max det(F_newᵀF_new)` = **D-optimality** (`F_newᵀF_new` = Fisher 정보행렬).
- **MMIG (평균 주변 정보이득, 식 44)**: 관심영역의 점 집합 `u=1..V` 에 대해 결합 정보이득을 순진하게
  쓰면 **출력 간 상관을 유도하는 쪽으로 치우쳐** 최적이 아니다 — MacKay 는 **주변 정보이득의 평균 최대화**를
  권한다. 유사한 결과가 **Q-optimality** (관심점들의 평균 예측분산 최소화)에서 나온다.

**§3.5.2 D-optimality** (Lysogorskiy ref 107 · Podryabinkin–Shapeev ref 108 · Gubaev ref 113):
앙상블 최대편차 `max_i |ỹ⁽ⁱ⁾ − ȳ|` 가 **D-optimality 기준과 완전히 상관**한다는 것이 출발점.
① `N_train × N_f` 행렬 `F` 에서 `det(F̃ᵀF̃)` 가 최대가 되도록 `N_f` 행을 뽑아 `F̃` 구성 (식 45)
② 새 샘플은 `γ = |f★ᵀF̃⁻¹| = sqrt( f★ᵀ(F̃ᵀF̃)⁻¹ f★ )` 가 최대(또는 문턱 `γ_th ≥ 1` 초과)인 것 (식 46)
⇒ **앞 절의 최대분산 기준과 같은 것**이고, 계량만 `G̃ = (F̃ᵀF̃)⁻¹` 로 바뀐 것.
Binet–Cauchy 로 `det(F̃ᵀF̃) ≤ det(FᵀF) = λ₁²λ₂²…λ_{N_f}²` (식 47).
**문턱**: *"The original paper by **Podryabinkin and Shapeev** suggests that a threshold of **γ ≲ 1**
corresponds to prediction in in-distribution regime, and **γ ≫ 1** would correspond to strong
out-of-distribution regimes."* 비선형 파라미터 의존으로의 일반화는 **Gubaev et al. (ref 113,
*J. Chem. Phys.* 2018, 148, 241727)**. MTP·ACE 커뮤니티가 주로 구현·사용 (refs 107–113).
**D-optimality 는 무작위 선택과 CUR/FPS 선택보다 훨씬 효율적** (ref 107).

**§3.5.3 경험적 데이터셋 엔트로피** — 그리고 리뷰의 비판:
- **Karabin–Perez** (ref 114): `S_KP(A) = (1/N_A) Σ_i log(N_A · min_j |x_{Ai} − x_{Aj}|)` (식 48)
  → `V(A) = E_repulsive(A) − K·S_KP(A)` (식 49) 의 독립 극소를 어닐링으로 찾아 훈련셋을 키운다.
  ⚠ 두 환경 특징이 일치하면 `S_KP → −∞` 로 발산.
- **Schwalbe-Koda** (ref 115): 커널 기반으로 발산을 없앤 데이터셋 엔트로피 `S_SK` (식 50) 와
  **미분 엔트로피** `δS_SK(x★) = log[Σ_i k(x_i, x★)]` (식 51) — **"모델 무관 불확실도 추정기"** 로 사용.
- **★ 리뷰의 통합 비판**: Mercer 정리로 `Σ_i k(x_i,x★) = N_env · f̄ᵀf(x★)` (식 54) 이므로
  `max δS_SK ⟺ min [f̄ᵀ f(x★)]` (식 55). ⇒ **데이터셋의 복잡도가 잠재공간 평균 `f̄` 하나로
  "평균되어 날아간다"** — 식 (1) 기반 방법과 달리 공분산 구조를 안 본다.
  게다가 **잠재특징을 센터링하면 `f̄ = 0` 이 되어 최소화 대상이 모든 `x★` 에서 0** 이 되는 추가 문제.
  또 이 계열은 **국소 환경을 구조로 "묶는(grouping)" 것을 전혀 반영 안 한다** — 마할라노비스 계량텐서
  구성에서는 반영되는 것.
- **KL 발산** (Zeni ref 81): 훈련/시험셋 **원자간 거리 분포**의 KL 발산이 2체 커널 MLIP 의 MAE 와
  **양의 상관**. 3체·결합각 분포로 확장해도 같은 상관. (Ni 나노클러스터 사례)
  ⚠ **Appendix B — 이력현상**: `D_KL(Q‖P) ≠ −D_KL(P‖Q)` 이므로 점을 넣었다 빼는 `Q→P→Q` 순환에서
  **순 정보이득이 0 이 아니다.** KL 을 정보이득으로 쓰는 것 자체의 결함.

**§3.6 베이지안 최적화**: 능동학습과 반복·불확실도 활용은 같지만 **목표가 다르다** —
AL 은 모델 예측 전반 개선, BO 는 **목적함수 직접 최적화**. 획득함수가 탐험(불확실)과 활용(유망)을 균형:
Expected Improvement(122) · Probability of Improvement(121) · **UCB**(123, 예측 + 가중 불확실도).
한계: **차원이 너무 높거나 물성 지형이 험하면(특징공간 작은 변화에 물성이 급변)** 어려워진다 (§3.4 와 같은 맥락).
적용: 분자(124,125)·결정(126–129)·무질서계(130)·복합계면(131,132); 다목적 **파레토 전선** 탐색으로
금속유리 기계물성(133)·다주성분(134)/고엔트로피 합금(135,136)과 촉매성(137–139)·**에너지저장용 전해질 물성**(140).

### 5-13. §4.1 — ★ 파운데이션 모델의 UQ (우리 질문 4의 본문)

절 전체가 짧다(한 문단). 담긴 주장 5개:

1. **정확도가 훈련데이터의 양·다양성에 걸려 있다** — *"if critical subdomains are **underrepresented**,
   predictions in those regions **may falter nevertheless**"* (ref 143 = Niblett et al.,
   *Transferability of datasets between MLIPs*, arXiv 2409.05590).
2. **지금까지의 파운데이션 모델 벤치마크는 열역학적 안정성 오차 중심**이었다 (ref 144 = **Matbench Discovery**).
3. **⛔ *"Community benchmarks and validation practices further **too rarely account for uncertainties or
   their propagation**."*** — 커뮤니티 벤치마크가 불확실도와 그 전파를 거의 안 본다.
4. **관측량 기반 평가의 시도**: MD 에서 뽑은 **열전도도**로 성능을 재려는 시도가 최근 도입됐다
   (ref 145 = Póta, Ahlawat, Csányi, Simoncelli, arXiv 2408.00755).
5. **★★ 단일 파운데이션 모델의 UQ 처방** — 이 리뷰가 주는 유일한 구체적 답:
   > *"Similarly, **UQ has been introduced in foundation models**,¹⁴² adopting the **last-layer
   > approximation described in eqn (14)**, with **almost no additional computational load** with respect
   > to inference of raw prediction."*
   (ref 142 = **Mazitov, Bigi, Kellner, Pegolo, Tisi, Fraux, Pozdnyakov, Loche, Ceriotti**, arXiv 2503.14118)
   ⇒ **앙상블을 못 만드는 단일 대형 모델의 UQ = 마지막층 Laplace(식 14).**
   ```
   σ²_★ = α² f_★ᵀ (FᵀF + λ² I_{N_L})⁻¹ f_★ ,   f_i = (∂ỹ_i/∂w_L)|_{w_o}
   ```
   필요한 것: ① 마지막 은닉층 잠재특징 `f` 를 뽑을 수 있는 접근 ② 그 `F` 를 쌓을 참조 구조집합
   ③ `α²` 를 맞출 **라벨 있는 검증셋**.
6. **미세조정·전이학습**: 사전학습 지식 위에 작은 데이터로 재학습 → 데이터 효율·흔히 강건성도 향상.
   ⚠ *"사전학습 모델의 도메인이 타깃 도메인과 크게 다르면 문제가 생긴다."*
   그리고 **열린 질문**: *"서로 다른 (미세조정) 전략이 **불확실도 추정기의 신뢰성과 강건성**에
   어떤 영향을 주는가."*

**§4.2 multi-level**: **Δ-learning** (ref 151) = 값싼 기저모델(고전/반경험 force field, 저품질 DFT)의
**보정치**를 학습 — 기저모델 품질과 훈련데이터 대표성이 결정적. **Multi-fidelity learning** (ref 152) =
정확도·비용이 다른 데이터셋을 통합. ⚠ *"fidelity 간 불일치와, **여러 fidelity 수준의 모델에서 오는 불확실도를
정확히 전파하는 문제**가 신중한 고려를 요한다."*

### 5-14. §5–§6 — 원자 모델링 너머 / 결론

**§5**: UQ 는 재료 개발 사이클 전 단계에 필요하다 — 합성 프로토콜 재현성(숨은 변수), 분광·현미경 신호 해석,
구조–물성 관계 구축, 공정 반복 최적화. 4개 도메인 지목: 합성 예측 모델(153) · 특성분석 가속(154) ·
대리모델 기반 구조–물성/최적화(155) · **다중스케일 프레임워크 — 원자→연속체 사이 불확실도 전파의 원리적 접근이
필요하고, 하위 스케일에서 잘 캘리브레이션된 모델도 상위 스케일에서 예측 불가능한 오차를 유발할 수 있다**(156).

**§6 결론**: 엄밀한 UQ 틀과 사려 깊은 데이터셋 구축이 ML 원자 모델링의 투명성·강건성을 높인다.
데이터 효율 기법이 성숙할수록 **신중한 검증과 철저한 불확실도 평가가 더 중요**해진다. Tycho Brahe 로 수미상관.

### 5-15. Appendix — 세 개의 부록

- **A. Nyström 근사**: 희소 커널을 `[φ(x)]ᵀ = k(x,X_s)ᵀ U_s Λ_s^{−1/2}` (식 57) 로 두면
  `K(X,X) ≈ FFᵀ` (식 59). **`F` 를 센터링한 뒤** 식 (7) 로 분산을 얻는다.
- **B. 교차엔트로피 이득/손실의 이력현상**: 위 §5-12 참조. `Q→P→Q` 순환의 순 정보변화가 0 이 아니다.
  가중치의 사후분포로 보든 데이터셋 특징의 분포로 보든 **동일하게 존재**한다.
- **C. (유사)특징을 센터링할 것인가 — 답이 없다**:
  선형회귀에서 센터링은 절편에 의미를 준다. 커널법에서는 잠재공간 표현의 분포를 바꿔 **분산 추정에 직접
  영향**을 준다. **편향 없는(bias-less) 모델**에서 특히 문제 — `ỹ★ = f★ᵀw_L` 처럼 특징이 0 이면 출력도
  0 인 모델은 `σ★(f★=0) = 0` 이 **구조적으로** 강제된다. 일반적으로 **잠재공간 원점 근처에서는 분산이 작고
  멀면 크다.** 그런데 그것이 **모델의 특성**이라고 주장할 수도 있고 — *"재센터링이 모델이 결국 데이터를
  잠재공간에 표현(또는 학습)한 방식과 충돌하는 **사후적 인공효과**를 도입할 수도 있다."*
  > 저자들의 결론: *"it is **not evident** that performing centering on pseudofeatures … **should be
  > encouraged**."* — **미해결로 남긴다.** `Fig. 8` 이 그 크기를 보여 준다(3.03 → 3.95).

## 6. ★★ 우리 질문 5개에 대한 직답

### 6-1. ★ 불확실도의 종류를 어떻게 분류하나 — 그리고 **우리 두 축이 어느 칸인가**

**⚠ 먼저: 이 논문은 깔끔한 분류표를 주지 않는다.** aleatoric/epistemic 은 **§2.3 한 곳**에서만,
그것도 **다른 논문(Busk·Carrete)의 해석으로** 등장한다. 리뷰가 실제로 세우는 구분은 아래 4겹이다.

| 겹 | 이 논문의 이름 | 어디 | 무엇을 재나 | 어떻게 얻나 |
|---|---|---|---|---|
| ① | **Epistemic** | §2.3 식 (20) 첫 항 · `Fig. 3a` 파란 라벨 | 모델/파라미터 지식 부족. 데이터를 더 모으면 준다 | **위원회 멤버 간 예측 분산** (식 18) 또는 식 (1) 직접공식 |
| ② | **Aleatoric** | §2.3 식 (20) 둘째 항 · `Fig. 3a` 빨간 라벨 | 무작위 잡음·데이터 불일치·모델이 정확히 못 맞추는 것. 데이터로 안 준다 | MV 모델이 **직접 출력**하는 `σ̃²(x)` 의 위원회 평균 |
| ③ | **Model misspecification (모델 오설정)** | **§2.9** | **모델 형태 자체가 틀린 계통오차.** ①②와 별개 | ⛔ **앙상블·캘리브레이션 어느 것으로도 안 잡힌다.** 전원이 같이 틀린다 |
| ④ | **Statistical / sampling** | **§2.8** | **표집 부족(너무 짧은 궤적)에서 오는 통계오차** | 궤적을 늘리거나 여러 궤적 |

여기에 **UQ 가 아닌 이웃 개념** 두 개가 §3 에 붙는다:
- **Robustness / in-vs-out-of-distribution** (§3.1–3.2) — **정답 없이** "여기가 모델 적용범위 안인가"를 묻는다.
  *"unlike the case of UQ"* 라고 저자들이 명시적으로 갈라 놓는다.
- **Prediction rigidity** (§3.4) — *"캘리브레이션 파라미터가 없으므로 **UQ 지표와 구별된다**"*.

그리고 **§2 서두 요건 (4)** 가 별도로 원천을 열거한다: **하이퍼파라미터 · 훈련셋 데이터 점 ·
비결정론적 최적화의 확률성.** (= 대략 ①의 하위 갈래)

#### ⇒ **우리 두 축의 정확한 매핑**

| 우리 축 | 우리 실체 | 이 논문의 칸 | ⚠ 판정 |
|---|---|---|---|
| **모델 불확실도** | `tools/ionic/mlip_committee.py` 의 **force_contrast** — UMA-s-1p1(OMat24) · MACE-MP-0(MPtrj) · SevenNet-0(MPtrj) **3종의 힘 예측 불일치** | **①epistemic 의 형식(식 18)을 빌렸지만, 이 논문의 §2.2 앙상블이 **아니다**.** 실질적으로는 **③ 오설정 탐침 + §3.2 model-free OOD 프록시** | 🔴 **아래 3가지 이유로 "epistemic σ" 라고 부르면 안 된다** |

**force_contrast 가 §2.2 앙상블이 아닌 이유 3가지 (전부 논문 문장에 근거):**

1. **§2.2 는 멤버가 "equivalent models" 라고 못 박는다.** 멤버 생성법도 (i) 같은 데이터의 부분표집,
   (ii) **훈련의 확률성(랜덤 시드·MC dropout)** 둘뿐이다. 우리 3종은 **아키텍처도 다르고 훈련 코퍼스도
   다르다**(OMat24 vs MPtrj ×2). 식 (18) 의 분산은 그 경우 "같은 문제에 대한 후보해의 퍼짐"이 아니라
   **서로 다른 문제를 푼 세 모델의 차이**다.
2. **M = 3 은 캘리브레이션이 원리적으로 불가능하다** (§6-3 참조, 식 27).
3. **우리 도구의 docstring 이 이미 그 함정을 안다** — *"MACE-MP-0 와 SevenNet-0 은 둘 다 MPtrj 이고
   UMA 만 OMat24 다 ⇒ 불일치가 'UMA 가 이상하다'가 아니라 '저 둘이 무르다'여서 생길 수 있다."*

**⇒ 그럼 force_contrast 는 무엇인가?** 이 논문 어휘로 **"model-free / 위원회 기반 OOD 프록시"** 다

는 물을 수 있고, **"UMA 의 힘에 붙는 오차막대가 몇 meV/Å 인가"** 는 못 묻는다. 지금 우리가 쓰는 방식과 일치하고,
**이름만 바꾸면 된다** — `force_contrast` 를 "epistemic uncertainty" 라고 부르지 않기.

**★ 추가로, 우리 DFT 라벨은 aleatoric 이 0 이다.** §2.3 의 Heid(ref 34) 단서:
*"잡음 없는 관측을 가정한 데이터셋에서는 모델 예측의 모든 편차를 **모델의 편향**으로 봐야 한다."*
DFT 라벨은 결정론적이다 ⇒ **우리 계에는 aleatoric 칸이 비어 있고, 남는 것은 ①epistemic·③오설정뿐이다.**

### 6-2. ★ 관측량까지 전파하는 절이 있나 — **§2.8. 있고, 우리 D 직전에서 멈춘다**

| 관측량 종류 | 전파 가능한가 | 방법 |
|---|---|---|

- **좋은 소식**: 우리가 하는 **3-seed 멀티궤적**이 현재 문헌이 아는 **유일한 방법**이다. 우리 방식이

- **나쁜 소식**: 그 3-seed 가 재는 것은 **④ 표집 불확실도뿐**이다. **①모델 불확실도가 `D_rel` 로 어떻게
  전파되는지는 이 논문 기준으로 아무도 모른다.** 시드를 30개로 늘려도 그 칸은 안 채워진다.
  (§2.8 의 경고와 정확히 같다: *"ML 때문의 불확실도를 문턱 아래로 못 내리면 아주 긴 MD 를 도는 것은 무의미하다."*)

**★ 다만 식 (31) reweighting 은 우리가 지금 할 수 있는 유일한 부분적 우회로다** — 단, 정적 양에 한해서.
`D` 에는 못 쓰지만 **RDF·Li 배위수·⟨E⟩** 같은 구조 지표에는 궤적 하나로 위원회 오차막대를 붙일 수 있다.
그리고 **`D_rel` 이 "비(ratio)" 라는 것은 §2.8(c) 의 차이량 논증과 같은 구조다** — 설계와 host 를
**같은 모델로** 계산하므로 오차가 상관되고, 절대 `D` 보다 **비의 불확실도가 훨씬 작을 것**이 기대된다.
⚠ **기대일 뿐이다.** 이 논문은 에너지 차이에 대해서만 그 논증을 했고, 수송계수 비에 대해서는
아무것도 말하지 않았다. 우리가 인용할 때 **"에너지 차이에서 성립하는 논증을 D 비로 유추한 것"** 이라고
밝혀야 한다.

### 6-3. ★ calibration 을 어떻게 하고 어떻게 채점하나 — 권고 절차

**리뷰가 권하는 것 (§2.4.3 결론): `2.4.1` + `2.4.2` 를 우선하고, miscalibration area 는 뒤로.**

**절차 (우리가 실행 가능한 단계로):**
1. **검증셋 준비** — 라벨(DFT)이 있는 `N_val` 개. 훈련셋과 분리.
2. **σ 추정기 고정** — 앙상블(식 18) 또는 직접공식(식 1/14). 이때 `α²` 는 아직 임의.
3. **전역 스케일 맞추기** — 식 (26). **멤버 수 M 이 작으면 반드시 편향보정 식 (27)** 을 쓴다.
   **⇒ `M ≥ 4` 가 하한. M=3 이면 `α² = −1/M < 0` 로 무의미하다.**
4. **채점 ①: log–log parity plot** — 추정분산 vs 관측 잔차², 추정분산으로 binning.
   - **선형 상관을 먼저 본다.** `α²` 는 log–log 에서 **강체 평행이동**이므로, 캘리브레이션 전이라도
     선형 상관은 나와야 한다.
   - **선형 상관이 나쁘면 → 전역 `α²` 로는 못 고친다.** 가우시안형 UQ(식 1) 자체가 부적절하거나
     **국소 `α²(x)` 가 필요**하다는 신호.
5. **채점 ②: ENCE** (식 28) — bin 별 `|RMV−RMSE|/RMV` 의 평균. 스칼라 요약값.
6. **채점 ③: Pernot 층화** — 예측 불확실도 크기별(저/중/고)로 쪼개 점수를 따로 낸다.
   binning 축을 바꿔 **consistency**(예측 σ 조건부)와 **adaptivity**(입력 특징 조건부)를 분리 진단.
   둘은 별개 목표이므로 **둘 다 봐야 한다.**
7. **(대안 경로) conformal prediction** — 분포무가정 구간이 필요하면 §2.5 5단계.
   ⚠ 시험 입력이 크게 OOD 면 유효성이 깨진다.
8. **⛔ 하지 말 것**: miscalibration area(CDF 면적)를 주 지표로 삼기 — 더 높은 모멘트를 섞어 본다.
9. **⚠ 캘리브레이션 후에는** epistemic/aleatoric 분해를 되짚기 어려워진다(§2.4.1 마지막 문장).

**★ 우리에게 직접 걸리는 것**: 우리 force_contrast 는 **M = 3**. 식 (27) 에서
`(M−3)/(M−1) = 0` 이라 **관측 잔차가 무엇이든 `α² = −1/3`** 이 나온다.
⇒ **우리는 force_contrast 에 "eV/Å 단위의 오차막대"를 붙일 수 없다. 순위·문턱 판정만 가능하다.**
이건 우리 규율("절대 σ 인용 금지")과 이미 같은 결론인데, **이제 식으로 근거가 생겼다.**
멤버를 **최소 4개**로 늘리는 것이 캘리브레이션의 **필요조건**이다(충분조건은 아니다 — §6-1 의 비동등성 문제는 남는다).

### 6-4. ★★ 파운데이션 모델(uMLIP) 의 UQ — 우리에게 제일 급한 칸

**리뷰가 주는 것 (전부 §4.1 + §2.3.2):**

1. **처방은 하나뿐이다 — 마지막층 Laplace(식 14).**
   *"UQ has been introduced in foundation models (ref 142), adopting the last-layer approximation
   described in eqn (14), **with almost no additional computational load**."*
   ⇒ 앙상블 없이, 추론 비용 그대로, 단일 대형 모델에 σ 를 붙이는 유일한 인용된 방법.
   ref 142 = Mazitov et al., arXiv 2503.14118 (Ceriotti 그룹).
   ⚠ **저자 구성으로 보아 PET-MAD 논문으로 보이지만, 이 리뷰 참고문헌에 제목이 없어 확정 못 했다.**
   맞다면 **우리 J-1 벤치가 쓴 Li₃PS₄ 데이터를 배포한 그 모델**이다 — 우연이 아니라 같은 그룹의 라인.

2. **UMA 는 이 리뷰에서 mixture-of-experts 로 분류된다** (§2.3.2, ref 40 = Wood et al. 2025).
   MoE 용 전파식이 주어진다: `σ²_★ = Σ_k p_k² σ²,⁽ᵏ⁾_★` (식 25).
   ⚠⚠ **그러나 이 식은 UMA 에 그대로 못 쓴다 — 아래 §13-3 참조.** 식 (24)–(25) 는
   **전문가 k 마다 독립된 데이터셋·계량텐서 `G⁽ᵏ⁾`·캘리브레이션 `α⁽ᵏ⁾`** 가 있고 `p_k` 가
   "이 입력이 어느 데이터셋 소속인가"를 재는 Zeni 식 구성(식 22–23)을 전제한다.
   **우리가 확인 못 한 것**: UMA 의 전문가 라우팅이 그런 구조인지. 이 리뷰는 확인해 주지 않는다
   (UMA 를 MoE 목록에 한 줄 넣었을 뿐, UMA 의 라우팅 구조를 논하지 않는다).

3. **벤치마크에 대한 경고 2개**:
   - 파운데이션 모델 평가가 **열역학적 안정성 오차**(Matbench Discovery) 중심이었다.
   - *"Community benchmarks and validation practices **too rarely account for uncertainties or their
     propagation**."* ⇒ **"UMA 가 Matbench 에서 좋다"는 우리 D_rel 의 불확실도에 대해 아무것도 말하지 않는다.**
   - 진전으로 인정한 것: **MD 관측량(열전도도)으로 재려는 시도**(ref 145). ← 우리 D_rel 과 같은 정신.

4. **훈련 커버리지 경고**: *"critical subdomains 가 과소대표되면 그 영역 예측은 여전히 흔들릴 수 있다."*
   ⇒ 우리 J-1 이 이미 안 것과 같다 — **PET-MAD Li₃PS₄ 벤치에 Cl 이 없다**.
   이 리뷰 기준으로 그건 "critical subdomain 과소대표"의 교과서 사례다.

5. **미세조정의 UQ 영향은 열린 질문** — 미세조정 전략이 불확실도 추정기의 신뢰성·강건성에 어떤 영향을
   주는지 모른다.

## 9. Post-processing ★

**우리 관례의 post-processing (NEB/Bader/COHP/DOS/ELF/grand-potential) 은 **하나도 없다.**
이 논문의 "후처리"는 전부 **UQ 후처리**다. 우리가 실제로 쓸 수 있는 형태로 정리하면:

| 무엇 | 도구/구현 | 수치화·기록 방식 |
|---|---|---|
| 위원회 분산 | 식 (18) — 이미 `tools/ionic/mlip_committee.py` 에 있다 | ⚠ **M≥4 아니면 캘리브레이션 불가** |
| 마지막층 Laplace | 식 (14) — 모델의 `∂ỹ/∂w_L` 훅 필요 | `F` 를 참조 구조집합으로 쌓고, `α²` 는 라벨 검증셋에서 |
| **α² 캘리브레이션** | 식 (26)/(27) | **`N_val` · `M` · 사용한 식 번호를 반드시 같이 기록** |
| 채점 | **log–log parity plot + ENCE**(식 28) + Pernot 층화 | bin 수 명시. `α²` 는 log–log 에서 강체이동이므로 **선형성부터** 본다 |
| 열역학 평균 전파 | 식 (31) reweighting (+ cumulant 안정화) | 평균 퍼텐셜로 궤적 1개 → 사후 M개 `⟨a⟩` → 표준편차 |
| OOD 판정 | 적응 k-NN 밀도(식 32) + **TwoNN 내재차원** / GMM NLL(NequIP 잠재공간) / 하우스도르프 거리 | 표현 의존성을 같이 기록 |
| 능동선택 | MIG(식 42) ≡ D-optimality(식 45,46) ≡ 최대 σ | **γ 문턱**: `γ≲1` in-dist, `γ≫1` 강한 OOD |

## 10. ★★ 우리 좌표 — 이 논문 어휘로 쓴 우리 상황 한 문단

> 우리는 **단일 파운데이션 모델(UMA-s-1p1, OMat24 학습, 고정 사전학습 체크포인트)** 로 MLIP-MD 를 돌리고,
> 보고량은 **`D_rel = D*(design)/D*(host)` @600 K · MSD 창 2–50 ps · cell-conditioned** 라는 **비(ratio)** 다.
> 이 논문의 분류로 옮기면 — 우리가 지금 정량하는 것은 **④ 표집(statistical) 불확실도 하나뿐**이고
> (600 K 3-seed → `Ea 0.197 ± 0.032 eV`, §2.8 의 *"the statistical one due to a poor sampling"*),
> **① epistemic 은 캘리브레이션된 형태로 전혀 안 재고 있다.** 우리가 가진 유일한 모델측 지표인
> **force_contrast (UMA/MACE-MP-0/SevenNet-0, M=3)** 는 §2.2 의 "동등한 모델들의 앙상블"이 아니라
> **서로 다른 아키텍처·서로 다른 훈련 코퍼스**의 대조이므로, 식 (18) 의 분산은 UMA 의 epistemic σ 가 아니라
> **③ 모델 오설정(model-form) 차이**에 가깝고, 실질 용도는 §3.2 계열의 **위원회 기반 OOD 프록시**다.
> 게다가 **M = 3 은 식 (27) 의 편향보정 캘리브레이션이 원리적으로 성립하지 않는 영역**(하한 M=4)이라
> 단위 있는 오차막대를 붙일 수 없다 — 이것이 우리 "절대 σ 인용 금지" 규율의 **식(式) 수준 근거**다.
> DFT 라벨은 결정론적이므로 **② aleatoric 칸은 우리 계에 애초에 없다**(Heid 단서). 그리고 우리 보고량
> `D_rel` 은 **수송계수**여서, 저자들이 *"rigorous theory 가 없다"* 고 명시한 **시간의존 관측량 전파**의
> 정확히 그 자리에 놓인다 — 우리가 쓰는 멀티시드가 곧 그들이 말한 *"time-consuming brute-force"* 이고,
> **그것이 현재 문헌이 아는 전부**다. 전이성 축(§3.3)으로 보면 우리는 **상(결정↔무질서/융해 경계)·
> 온도(600–1000 K)·조성(도판트 30종 = 화학량비 + 새 원소)** 세 갈래를 **동시에** 밟고 있고, 세 번째가
> 저자들이 *"맞춤 기법 없이는 상당히 어렵다"* 고 한 바로 그 외삽이다. 이것이 우리 봉인 규칙
> (`mlip_applicability` = *"UMA 내부 순위로만 서술"*)이 옳았던 이유를 문헌 어휘로 설명해 준다.

### 10-1. 이 논문 기준 — **지금 할 수 있는 것**

- ✅ **용어 정정 (계산 0회)**: `force_contrast` 를 *"epistemic uncertainty"* 가 아니라
  **"위원회 기반 OOD 프록시 / model-form 대조"** 로 부른다. 우리 시드는 **MD 시드**이고
  §2.2 의 **훈련 시드**가 아님을 문서에 명시.
- ✅ **`M=3` 의 원리적 한계를 규율로 승격**: 식 (27) 인용 한 줄로 "절대 σ 금지"의 근거를 교체
  (지금은 경험적 관례로만 적혀 있다).
- ✅ **전이성 3분류(`Fig. 5`)로 우리 UMA 사용을 자기서술**: 상·온도·조성 세 갈래 중 어디를 밟는지
  캠페인마다 표로 밝힌다. 저자들의 관찰 *"고온→저온 일반화는 잘 된다"* 는 우리 600/800/1000 K 에
  **유리한 방향**이다(우리는 고온에서 표집한다).
- ✅ **`D_rel` 이 비(ratio)라는 것을 §2.8(c) 상관 논증으로 방어**: 설계와 host 를 같은 모델로 계산하므로
  오차가 상관되고 비의 불확실도는 절대 D 보다 작다 — ⚠ **유추임을 밝히고**.
- ✅ **정적 관측량에는 지금 당장 위원회 오차막대를 붙일 수 있다**: 식 (31) reweighting 은 궤적 하나면 된다.
  RDF·Li 배위수·⟨E⟩ 에 적용 가능 (D 에는 불가).
- ✅ **J-1 벤치의 구멍을 이 논문 언어로 명명**: *"critical subdomain underrepresented"* (Cl 부재).

## 13. 비판 / 주의 / 한계 (over-claim 방지)

**13-1. "통합"의 범위가 실제보다 크게 들린다.** 제목·초록은 UQ 일반을 표방하지만, 통합의 실체는
**식 (1) 로 환원되는 계열**(선형·GPR·Laplace·D-optimality·MIG)이다. **conformal prediction(§2.5)·
MCMC(§2.1.4)·미분엔트로피(§3.5.3)** 는 그 틀 밖이거나(CP 는 분포무가정) 오히려 **비판 대상**으로만 다뤄진다.
"모든 UQ 가 마할라노비스"가 아니라 **"직접공식 계열이 마할라노비스"** 다.

**13-2. NTK 방어가 현대 아키텍처를 커버하지 않는다.** §2.1.3 은 Wenger 의 *"깊이보다 자릿수만큼 넓어야"*
경고를 인용한 뒤, **DeePMD(3층×240)·Behler–Parrinello(2층×40)** 각주로 *"원자 학습은 실제로 그렇다"* 고
넘어간다. 그런데 **이 리뷰가 §4.1 에서 다루는 파운데이션 모델들(MACE·UMA 계열)은 깊은 등변 메시지패싱
GNN** 이고 각주의 두 예시와 구조가 다르다. **마지막층 근사의 정당화를 uMLIP 으로 옮기는 다리가 본문에 없다.**
⇒ 우리가 §10-3 #1 을 실행할 때 **"왜 UMA 에서 LL 근사가 타당한가"는 스스로 검증해야 한다.**

**13-3. ★ UMA 를 mixture-of-experts 로 넣은 것은 한 줄 언급이고, 식 (25) 로 이어지지 않는다.**
§2.3.2 는 UMA(ref 40)를 MoE 사례로 들지만, 이어지는 식 (22)–(25) 는 **Zeni 식 구성**을 전제한다:
전문가 k 마다 **자기 데이터셋·중심(centroid)·계량 `G⁽ᵏ⁾`·캘리브레이션 `α⁽ᵏ⁾`** 가 있고,
`p_k` 는 *"이 입력이 어느 데이터셋에 속하나"* 를 재는 거리/밀도 기반 가중치다.
**UMA 의 전문가 라우팅이 그 구조인지 이 논문은 확인해 주지 않는다** (우리도 이 digest 로는 확인 못 했다).
⇒ ⛔ **식 (25) 를 "UMA 의 UQ 공식"으로 인용하지 말 것.** 리뷰가 UMA 를 MoE 목록에 넣었다는 사실과,
MoE 일반 공식이 UMA 에 적용된다는 주장은 **다른 것**이다.

## 15. 기법 용어 미니사전

| 용어 | 뜻 (이 논문 맥락) |
|---|---|
| **Aleatoric uncertainty** | 데이터 자체의 무작위성/잡음에서 오는 불확실도. **데이터를 더 모아도 안 준다.** MV 모델이 직접 출력. ⚠ DFT 라벨처럼 잡음 없는 관측에서는 "모델 편향"으로 봐야 한다(ref 34) |
| **Epistemic uncertainty** | 지식(데이터·파라미터) 부족에서 오는 불확실도. **데이터를 더 모으면 준다.** 위원회 멤버 간 분산 |
| **Model misspecification (오설정)** | 가정한 모델 **형태**가 참 데이터생성 과정과 다른 것. 계통오차. ⛔ 앙상블·캘리브레이션으로 안 잡힌다 |
| **Mahalanobis distance** | 공분산으로 정규화한 거리 `√(fᵀ G f)`. 유클리드와 달리 **훈련 분포가 좁은 방향으로 나가면 훨씬 멀다**(`Fig. 2`) |
| **Calibration constant α²** | 식 (1) 의 전역 스칼라. 분산에 **올바른 단위**를 주고 검증셋에서 맞춘다. log–log parity plot 에서는 **강체 평행이동**으로 작용 |
| **ENCE** | Expected Normalized Calibration Error. bin 별 `|RMV−RMSE|/RMV` 의 평균 (식 28) |
| **Consistency vs Adaptivity** (Pernot) | 예측 σ 에 대한 조건부 캘리브레이션 vs 입력 특징에 대한 조건부 캘리브레이션. **별개이고 상보적** |
| **Conformal prediction** | 분포무가정 예측구간. 캘리브레이션셋의 비순응 점수 `|y−ỹ|` 의 (1−α) 분위수를 **전역 문턱**으로 씀. OOD 에서 무효화 |
| **Laplace approximation** | 가중치 사후분포를 MAP 주변 다변량 가우시안으로 근사. 공분산 = 손실 헤시안의 역 |
| **Gauss–Newton approximation** | 헤시안을 1차 도함수만으로 근사 (식 11). 역전파로 얻는다 |
| **Last-layer (LL) approximation** | 마지막 은닉층 가중치에 대한 기울기만으로 `f` 를 구성 (식 13,14). ★ **파운데이션 모델 UQ 의 표준 처방** |
| **NTK (Neural Tangent Kernel)** | 무한폭 극한에서 NN 을 커널회귀로 보는 형식론. LL 근사의 이론적 근거. ⚠ *"깊이보다 자릿수만큼 넓은"* 아키텍처를 요구 |
| **Shallow ensemble** | 나머지 가중치는 공유하고 **마지막층만 M벌** 두는 값싼 앙상블 (`Fig. 3b`) |
| **Mean-variance (MV) model** | 예측과 그 분산을 **동시에 출력**하도록 NLL 손실로 학습 (식 19) |
| **Deep ensembles** | MV 모델들의 위원회. `σ²_tot` = 멤버 퍼짐(epistemic) + 예측분산 평균(aleatoric) (식 20) |
| **Mixture of Experts (MoE)** | 입력의존 가중치 `p_k(x)` 로 K개 모델을 섞는 구조 (식 21). UMA(ref 40)가 이 목록에 언급됨 |
| **Convex hull (기하적 OOD)** | 훈련점을 모두 담는 최소 볼록집합. ⛔ 고차원에서 붕괴 + **비볼록 분포의 구멍을 in-distribution 으로 오판**(`Fig. 4`) |
| **TwoNN** | 데이터의 **내재차원(intrinsic dimensionality)** 추정기. 밀도 기반 OOD 의 부피 계산에 필요 |
| **Prediction rigidity (PR)** | `1/[(f°)ᵀH_o⁻¹ f°]` — 예측이 데이터에 얼마나 단단히 묶였나. **캘리브레이션 상수가 없어 UQ 지표가 아니다.** 국소(LPR)·성분별(CPR) 확장 |
| **D-optimality / γ (외삽등급)** | `det(F̃ᵀF̃)` 최대화로 대표부분집합을 뽑고, 새 점의 `γ = √(f★ᵀ(F̃ᵀF̃)⁻¹f★)` 로 외삽 정도를 잼. `γ≲1` in-dist · `γ≫1` 강한 OOD |
| **MIG / MMIG** | 최대 정보이득 / 평균 주변 정보이득. **불확실도가 큰 곳을 라벨링하라**가 정보이론에서 유도됨 (식 42,44) |
| **Reweighting (식 31)** | 위원회 **평균 퍼텐셜로 궤적 1개**만 돌리고, `w⁽ⁱ⁾=exp[−β(V⁽ⁱ⁾−V̄)]` 로 사후 재가중해 **열역학 평균의 위원회 오차막대**를 얻는 기법 |
| **Size extensivity of σ** | 불확실도가 계 크기 N 에 따라 커지는 방식. 완전상관 `∝N` ~ 무상관 `∝√N` 사이 |
| **Transferability (3분류)** | **Phase / Temperature / Compositional**(화학량비 · 새 원소=alchemical) (`Fig. 5`) |
| **Activity cliff** | 구조적으로 매우 비슷한데 타깃이 크게 다른 쌍. 학습을 어렵게 만든다 |
