## 3. ★1 — **A자리 / B자리를 어떻게 갈랐나** (여기가 우리가 배울 첫째)

### 3.1 가른 방식: **"자리를 고르는 것"이 아니라 "host 를 고정하는 것"**

이 논문의 자리 분리는 원소 목록을 나눈 것이 아니라 **화학식 자체를 두 개로 못박은 것**이다.

```
A자리 시나리오 :  (La, A2, A3, A4, A5) Co O₃      ← B자리는 Co 하나로 고정, 절대 안 건드림
B자리 시나리오 :  La (Co, B2, B3, B4, B5) O₃      ← A자리는 La 하나로 고정, 절대 안 건드림
```

- **host 원소는 필수(mandatory)** 다. 코드가 이것을 **런타임에 강제**한다:
  `app.py:342` *"Error: La is mandatory for A-site substitution."* / `app.py:356` Co 동일.
- 그래서 **두 계열은 항상 정확히 한 사슬만 다르다.** A자리 화합물과 B자리 화합물을
  비교할 때 *"어느 자리가 바뀌었나"* 가 절대 섞이지 않는다.
- 두 계열의 **교집합은 LaCoO₃ 하나**(둘 다의 극한)이고, 그것이 Fig. S3 벤치마크의 기준점이다.

### 3.2 원소 집합을 무슨 기준으로 골랐나 — **명시 기준은 본문 미확보. 코드에서 역으로 읽히는 것은 이렇다**

SI 에는 원소 선정 기준이 **한 줄도 없다.** 그러나 `app.py:190–195` 의 이온반경 사전이
선정 논리를 사실상 드러낸다.

| 자리 | 원소 | 코드의 이온반경 (Å) | 대응하는 Shannon 값 |
|---|---|---|---|
| A | Ca 1.340 · Sr 1.440 · Ba 1.610 · Ce 1.340 | **CN = 12** (Ca²⁺·Sr²⁺·Ba²⁺·Ce³⁺) |
| A | Nd 1.270 · Sm 1.240 | **CN = 12** (Nd³⁺·Sm³⁺) |
| A | **Pr 1.179 · Gd 1.107** | 🔴 **CN = 9** — Shannon 에 CN=12 값이 **없어서 내려간 것으로 보인다** |
| B | Ti 0.670 · V 0.640 · Cr 0.615 · Mn 0.645 · Fe 0.645 · Ni 0.600 · Cu 0.540 | **CN = 6, 3+** (Mn³⁺·Fe³⁺·Ni³⁺ 는 HS, Cu³⁺ 는 LS) |
| B | **Zn 0.740** | 🔴 **CN = 6, 2+** — Zn³⁺ 가 표에 없어 **2가**를 썼다 |

⇒ **읽히는 선정 기준**: A자리 = *"란타넘족 3가 + 알칼리토 2가 중 12배위 반경이 La³⁺(1.36 Å) 근처인 것"*,
B자리 = *"3d 전이금속 중 6배위 3가 반경이 Co³⁺(0.61 Å) 근처인 것"*.
즉 사실상 **Goldschmidt 허용인자를 깨지 않는 크기 창**이다.
🔴 **그러나 그 규칙이 글로 써 있지 않고, 실제 숫자는 배위수(9 vs 12)와 산화수(2+ vs 3+)가 섞여 있다.**
descriptor 로 쓰는 순간 Pr·Gd 는 계통적으로 작게, Zn 은 계통적으로 크게 들어간다.
Goldschmidt·산화수 논의는 **본문 미확보**.

### 3.3 ★ **한 원소가 양쪽에 다 들어갈 수 있을 때 — 이 논문은 그 상황을 "만들지 않았다"**

> **이게 우리 질문의 정확한 답이다. 그들은 문제를 푼 게 아니라 발생을 막았다.**

- A자리 후보 8종과 B자리 후보 8종은 **교집합이 공집합**이다 (Ca/Sr/Ba/란타넘족 ∩ 3d TM = ∅).
- 그리고 host 두 개(La·Co)는 **서로의 후보 목록에서 배제**돼 있다:
  A자리 pool 은 `['La','Ca',…,'Gd']` 로 **Co 가 없고**, B자리 pool 은 `['Co','Ti',…,'Zn']` 로 **La 가 없다**
  (`app.py:334, 348`).
- 즉 **"이 원소는 A로 들어갔나 B로 들어갔나"** 라는 물음이 원리적으로 생기지 않는다.
  **자리 모호성을 사후 판정으로 푸는 대신, 후보집합의 분할로 사전에 제거했다.**
- 🔴 **대가**: antisite(A자리 양이온이 B자리로 가는 것)를 **모형이 아예 표현하지 못한다.**
  SQS 는 각 부격자 안에서만 무질서를 만든다. 실제 페로브스카이트에서 흔한
  A↔B antisite·양이온 무질서는 이 데이터셋에 **한 개도 없다**. 관련 언급은 본문 미확보.

## 4. ★2 — **자리별 보고량이 달랐나 · 집계·순위 규칙**

### 4.1 보고량은 **양쪽이 완전히 같다** (4개, 동일 정의·동일 단위)

| # | 보고량 | 단위 | 코드 필드 | A/B 동일? |
|---|---|---|---|---|
| 1 | **형성에너지 Ef** | eV/atom | `Ef` | ⭕ 동일 |
| 2 | **격자 왜곡 Δ_lattice** | **%** | `D_lattice` | ⭕ 동일 |
| 3 | **원자 왜곡 Δ_atomic** | **Å** | `D_atomic` | ⭕ 동일 |
| 4 | **확산계수 D** | cm²/s | `D_negative` (= **−D**) | ⭕ 동일 |

- 단위 근거: Fig. R1 의 *"E_f (eV/atom) · Δ_lattice (%) · Δ_atomic (Å) · D (cm²/s)"* + README.
- 모델은 **하나가 4개를 동시에 낸다** (`OUT_FEATURES = 4`, `app.py:105/114`) — 자리마다
  **별개 모델**(`model_A.pkl` / `model_B.pkl`)이지만 **보고량 정의는 공유**한다.
- ⇒ **같은 자를 두 자리에 대고 잰 것이 맞다.** 자리마다 다른 질문을 묻지 않았다.

### 4.2 부호 규약 하나가 전략을 드러낸다 — **`D_negative`**

학습 타깃이 D 가 아니라 **−D** 다 (`app.py:151`, 표시 단계에서 `data_dis['D (cm^2/s)'] = -data_pred['D_negative']`).
⇒ **4개 목표가 전부 "작을수록 좋다" 로 정렬**돼 있다. Ef 는 낮을수록 안정, Δ 는 작을수록
왜곡 적음, −D 는 작을수록 D 가 크다. **다목적 최적화를 단일 방향(minimize)으로 통일한 것**이고,
Pareto front / hypervolume 을 쓰려면 반드시 필요한 정규화다.
🔴 **단, "왜곡이 작은 것이 좋다"와 "D 가 큰 것이 좋다"가 동시에 목표인데 우리 재계산 상관은
Δ_lattice ↔ D 가 A자리 **+0.686**, B자리 **+0.778** `[재구성]` — 즉 **두 목표가 서로 싸운다.**
그래서 Pareto front 가 실제로 의미를 갖는다(단일 최적점이 없다). 이것이 이 설계의 진짜 뼈대다.

### 4.3 순위·집계 규칙 — **그대로 옮겨 적으면**

| 단계 | 규칙 | 출처 |
|---|---|---|
| 방향 정규화 | 4목표 전부 **minimize** (D 는 −D 로) | `app.py:151` |
| 대리모델 출력 | BNN posterior **1,000 샘플**의 **평균 + 표준편차** (`preds['obs'].mean(0)`, `.std(0)`) | `app.py:122,147–150` |
| 역스케일 | `y_scaler.inverse_transform(mean)`, **std 는 `y_std * y_scaler.scale_`** | `app.py:149–150` |
| 후보 선별 | **EI · HVI · ParEGO · Pareto Front** | Fig. R1 (Promising Candidate Selection) |
| 다음 구조 생성 | **icet** + **Monte Carlo / simulated annealing** | Fig. R1 (Guided Structure Generation) |
| 데이터 확장 | **New SQS + Compositional Pool Expansion** | Fig. R1 (Progressive Dataset Expansion) |
| 표시 필터 | 앱은 **D ≤ 0 예측을 버린다** (`data_dis[data_dis['D (cm^2/s)'] > 0]`) | `app.py:456` |

🔴 **획득함수 4개(EI/HVI/ParEGO/Pareto)를 어떻게 조합·전환했는지는 그림 상자에 나열만 돼 있고,
가중·순서·전환 규칙은 본문 미확보다.** 그리고 앱의 `D>0` 필터는 **모델이 음수 확산계수를
예측한다는 것을 인정하는 코드**다 — 물리적으로 불가능한 예측을 사후에 지우고 있다.

### 4.4 σ 로의 환산 — **여기 오류가 하나 있다**

`app.py:217–222`:
```python
def D2C(D, T):
    z = 2                            # charge number of the Oxygen ion
    F = 9.64853399e4
    R = 8.31446261815324
    C = z**2 * D * F**2 / (R*T*100)  # S/cm
```
Nernst–Einstein 은 σ = z²F²**c**D/(RT) 이고 c 는 **mol/cm³ 의 캐리어 농도**다.
이 코드에는 c 가 없고 대신 **`/100`** 이 붙어 있다 ⇒ **c = 0.01 mol/cm³ 로 고정**한 것과 같다.
LaCoO₃ 의 실제 O 몰농도는 대략 **0.09 mol/cm³** 이라 **한 자릿수 가까이 작다**.
게다가 **조성이 바뀌어도 c 가 안 바뀐다** — 즉 앱의 `C (S/cm)` 는 **D 를 1/T 로 눌러 다시 그린
값일 뿐 조성 의존 전도도가 아니다.**
⛔ **이 σ 는 인용 금지.** (본문에 σ 가 나오는지는 미확보.)

### 5.2 Ef 의 기준 상태 — **결정 불가**

`Ef` 의 정의식은 **본문 미확보**다. 공개된 값의 크기로 역추정하면:

| 계열 | Ef 평균 ± sd (eV/atom) `[재구성]` | 범위 |
|---|---|---|
| **A자리** | **−1.6286 ± 0.1285** | −1.8737 … −1.2969 |
| **B자리** | **−2.2030 ± 0.2255** | −2.7775 … −1.6023 |

- ⚠ **크기만으로는 못 좁힌다.** 원소 기준 생성엔탈피라면 ABO₃ 산화물은 통상 훨씬 더 음(陰)이고,
  단부(端部) 페로브스카이트 기준(혼합에너지)이라면 0 근처여야 한다. 관측된 −1.6 / −2.2 는
  **그 어느 쪽으로도 딱 떨어지지 않는다** (이 비교는 우리 판단이지 논문 서술이 아니다).
  ⇒ **원소 기준인지, 이원산화물 기준인지, 단부 페로브스카이트 기준인지 이 자료로는 못 정한다.**
- ⇒ **★3 에 대한 정직한 답: "기준 상태가 무엇인지 알 수 없다."**
  그리고 **그게 바로 문제다** — 우리가 방금 NO-GO 를 받은 바로 그 축이다.

### 5.3 우리 반려 사유와의 직접 대응

   ⇒ 70 + 70 + 280 = **420**.
2. 이 6행은 **SI `Table S1` docx 미리보기의 6행과 글자 그대로 같다.**
3. 원소조당 점 수는 **최소 6** (A자리 **12개 조**, B자리 **11개 조** 가 정확히 6점 = AL 이

host(La/Co) 원자수의 분포를, **후보공간 균등분포**와 비교하면:

|---:|---:|---:|---:|---:|
| **12** (=15 at.%, **최소**) | **55.9 %** | **58.9 %** | 16.7 % | **3.35×** |
| 13 | 6.6 % | 6.1 % | 14.5 % | 0.45× |
| 16 (=20 at.%, 등몰) | 13.1 % | 12.8 % | 9.1 % | 1.44× |

⇒ **경계에서 배우고 내부를 예측한다** — 우리 cascade 가 똑같이 조심해야 할 지점.

### 6.5 🔴 D 채널의 중복 — **공개 학습셋에서 확인된 결함** `[재구성]`

같은 (원소조, 조성, T) 의 **5개 SQS 복제본**을 비교하면:

| 타깃 | 5복제본이 서로 다른 점 수 | 5복제본이 **완전 동일**한 점 수 |
|---|---:|---:|
| **Ef** | **610 / 610** (전부 다름) | 0 |
| **Δ_lattice** | **610 / 610** | 0 |
| **D** | 0 | 🔴 **610 / 610 (전부 동일)** |

- 즉 **D 는 조성당 한 번만 계산되고 5번 복사**됐다. Ef·Δ 는 SQS 마다 다른데 D 만 안 다르다.
- 결과: BNN 의 우도가 D 채널에서 **동일한 (x, y) 를 5번** 본다 ⇒ **유효 표본수 5배 과대,
  구조 잡음 0 으로 인식** ⇒ **D 예측의 불확실도가 계통적으로 과소평가**된다.
- SQS 산포 실측(같은 조성·같은 T): Ef sd 평균 **0.0033 (A) / 0.0091 (B)** eV/atom (최대 0.0188 / 0.0564),
  Δ_lattice sd 최대 **1.36 (A) / 1.61 (B)** %. **작지 않다.** D 만 그 산포가 0 이다.
- ⚠ 이것이 *"학습이 그랬다"* 인지 *"배포 pkl 을 만들 때 5배 복제했다"* 인지는 **본문 미확보**.
  어느 쪽이든 **공개된 학습셋으로는 D 의 구조 산포를 못 잰다**는 사실은 그대로다.

## 10. DFT / 계산 방법 ★

- **주 계산엔진**: **Matlantis** (Preferred Networks 의 **PFP** universal NNP; 클라우드 서비스).
  ⛔ **PFP 버전·모드(예: v6/v7, `crystal_u0` 등) 본문 미확보.**
- **참조 DFT (SI §S2.1, 벤치마크 전용)**: **VASP** · **GGA-PBE** ·
  **k-점 밀도 > 5000 pra** · **총에너지 수렴 1e-6 eV/cell** ·
  **cutoff = pseudopotential 권장값의 1.75배** (이완 계산). ⛔ **DFT+U 언급 없음** (3d TM 산화물인데도).
- **pseudo / PAW**: 명시 없음(VASP 기본 PAW 추정) — **본문 미확보**.
- **셀 / 원자수**: **400원자 SQS supercell** (부격자당 80 자리; ABO₃ = 80/80/240).
- **무질서 처리 ★**: **SQS**, **조성당 5개**, 자리당 **960 prototype** (192 × 5).
  구조 생성 도구 = **icet** (Fig. R1), **Monte Carlo / simulated annealing**.
  ⛔ SQS 목적함수(어느 클러스터까지 맞췄나)·컷오프 **본문 미확보**.
  ⛔ **A↔B antisite 는 모형에 없다** (부격자 내부 무질서만).
- **MD**: 🔶 **직접 서술은 본문 미확보.** 다만 D 가 **1000/1250/1500/1750/2000 K 5수준**으로
  존재하므로 (`[재구성]`) **MD 유래로 보는 것이 합리적**이다. 앙상블·시간·타임스텝·MSD 창 · Haven 비 **전부 미확보**.
  ⛔ **"이 논문의 MD 규약" 을 인용하지 말 것 — 우리는 그것을 본 적이 없다.**
- **DFT+U · 스핀**: ⛔ **언급 0.** LaCoO₃ 는 스핀상태 전이(LS/IS/HS)로 유명하고 B자리 pool 은
  Mn·Fe·Ni·Cu 다. **자성·스핀 상태 선언이 없는 것은 §12 의 핵심 비판이다.**
- **대리모델**: Pyro BNN — in 13 / out 4 / 2 은닉층 / ReLU / `AutoDiagonalNormal` / `Trace_ELBO` /
  Adam / `σ ~ Gamma(0.5,1)` / posterior 1000 샘플 / 입출력 `StandardScaler`.
- **특징 13개**: 치환원소 4개의 **원자번호 4 + 이온반경 4 + at.% 4** + **온도 1**.
  ⇒ **host(La/Co)는 특징에 없다** (`app.py:176,178` 에서 열을 지운다) — 나머지 4개로 유일하게 결정되므로 이론상 손실 없지만,

## 12. 🔴 주의 / 한계 (over-claim 방지 · 비판)

1. **★ 별도 상 판정이 없다** (§5). 이 연구의 결론은 전부 *"그 조성이 단상으로 존재한다면"*
   조건부다. 192 조성 중 실제로 페로브스카이트로 존재하는 것이 몇 개인지 **묻지 않았다.**
   ⇒ 이 논문을 *"고엔트로피 페로브스카이트 조성을 발견했다"* 로 읽으면 안 된다.
   **"조성-물성 대리모델을 만들었다"** 가 정확한 서술이다.
2. **★ 벤치마크가 사용량을 검증하지 않는다** (Fig. S3). 총에너지 parity(동적범위 3 eV/atom)로
   Ef(산포 0.13–0.23 eV/atom)를 정당화했다. **MAE/RMSE 0건**, **무질서 SQS 검증 0건**,
   **D 검증 0건**. 즉 **네 보고량 중 셋(Δ_lattice·Δ_atomic·D)은 아무 검증도 없다.**
3. **★ 자성·스핀 상태 선언이 없다.** B자리 pool 이 Mn·Fe·Co·Ni·Cu 이고 A자리에 Ce·Pr·Nd·Sm·Gd(f전자)가
   들어간다. LaCoO₃ 는 스핀상태 전이의 교과서다. **admissible state 가 여럿인데 집계 규칙이 없으면
   스칼라 보고량은 정의되지 않는다** (우리 `kb/templates/estimand_card.md` §3 판정규칙).
   ⇒ **Ef 는 "어떤 자기 상태의 Ef" 인가?** 답이 자료 어디에도 없다.
4. **★ 그룹 누수 가능성** (Fig. S4a). 5-fold 가 **행 단위**인데 한 점이 25행이다.
   같은 (원소조·조성)이 train/val 에 동시에 들어가면 val MSE 7.43e-2 는 낙관적이다.
   **out-of-composition / out-of-quartet 성능은 보고되지 않았다.**
5. **★ D 채널 5배 중복** (§6.5). 공개 학습셋에서 D 는 SQS 복제본 5개가 **전부 동일**하다.
   D 불확실도가 계통적으로 과소.

### 15.1 첫째 — **질문 유형을 세 가지 중 하나로 강제 선언한다** (근거: §5.3 대응표)

`kb/templates/estimand_card.md` §1 바로 아래에 **필수 필드 하나**를 신설한다:

| 값 | 뜻 | 계산 대상 | 우리 기존 데이터 중 해당 |
|---|---|---|---|
| **`lattice`** | **격자 치환** — 도펀트가 LPSCl 부격자 자리를 차지한다 | **단상 supercell 하나** | (거의 없다 — 이것이 공백) |

(회신 BJ: *"산물표는 보조축으로 남기고"*).

### 15.2 둘째 — `lattice` 를 골랐으면 **자리를 화학식으로 못박는다** (근거: §3.1)

[Liu26AB] 의 방식 그대로. **자리 이름이 아니라 화학식**이다.

```
Li(6−nδ) P S5 Cl              ← 모체
site = P_4b   :  Li₆₋? (P₁₋ₓ Mₓ) S₅ Cl        + 전하보상 규칙
site = S_16e  :  Li₆ P (S₁₋ₓ Xₓ)₄ · S Cl      ← PS₄ 사면체 음이온만
site = S_4a4c :  Li₆ P S₄ (S₁₋ₓ Xₓ) Cl        ← 자유 음이온 자리만
site = Cl_4a4c:  Li₆ P S₅ (Cl₁₋ₓ Yₓ)
site = Li_24g / Li_48h  ← ⚠ 축퇴. 두 자리를 **별개 선언**으로 쪼갠다 (P0 실측: 코드가 둘을 안 나눈다)
```

**계약 3줄** (도구가 시작 전에 검사, 실패하면 **잡을 던지지 않는다**):
1. **host 강제** — 그 자리의 host 원소가 선언과 다르면 **중단**
   ([Liu26AB] `app.py:342` 의 `"X is mandatory"` 를 우리 `substitute_compound.py` 에 이식).
2. **자리 배타성** — 한 도펀트가 두 자리에 들어갈 수 있으면 **두 개의 별개 설계**로 쪼갠다.
   ⚠ [Liu26AB] 는 후보집합을 분할해 이 문제를 **발생시키지 않았다**. 우리는 **분할이 불가능하다**
   (예: O 는 S_16e·S_4a4c 양쪽 후보). ⇒ **우리는 사후 판정이 아니라 `design_id` 분기로 푼다**:
   `Sc@P_4b` 와 `Sc@Li_24g` 는 **다른 설계**이고 같은 표에서 비교하지 않는다.
3. **전하보상 계약** — 치환 전후 총전하가 0 이 아니면 **중단** (현재 `substitute_compound.py:365`
   는 양이온 변화만 합산하고 Li 삽입 실패 뒤에도 불균형 구조를 남긴다 — 회신 BJ P0-Q8).

### 15.3 셋째 — **자리마다 다른 보고량을 쓰지 않는다** (근거: §4.1)

[Liu26AB] 가 한 것: **동일한 4개 보고량**을 두 자리에 그대로 적용, 모델만 나눔.
우리 대응: `D_rel(design, host) ≡ D*(design)/D*(host)` (600 K · 2–50 ps · cell-conditioned)를
**모든 자리에 그대로** 쓴다. **자리마다 다른 양을 재면 자리 간 비교가 죽는다.**
다만 **자리별로 모델을 나눈다** (그들의 `model_A` / `model_B` 처럼) — 자리가 다르면
descriptor 의 의미가 다르기 때문이다.

⚠ **추가로 선언해야 하는 것** (그들이 안 한 것, §12-3):
`D_rel` 을 잴 때 **어느 배열/어느 자기상태의 구조인가**. 우리 카드는 이미
*"설계 대표 = 점수 중앙값을 낸 실제 행 하나"* 로 배열 선택을 닫아 뒀다 — 그 규칙을 **자리 선언과 짝지어** 기록한다.

## 17. 기법 용어 미니사전

- **SQS (Special Quasirandom Structure)** — 유한 셀로 무작위 고용체의 **짧은 거리 상관함수**를
  이상적 랜덤에 가장 가깝게 맞춘 배열. 무질서를 "평균 하나"로 근사하는 표준 도구.
  ⚠ **한 조성에 여러 SQS 가 있고 물성이 달라진다** — 이 논문이 조성당 5개를 만든 이유.
- **icet** — SQS·클러스터전개(cluster expansion)를 MC/simulated annealing 으로 푸는 파이썬 패키지.
- **Matlantis / PFP** — Preferred Networks 의 상용 universal NNP 클라우드 서비스.
  주기율표 대부분을 한 모델로 덮는 범용 MLIP (우리 UMA 와 같은 계열의 도구).
- **OQMD** — Open Quantum Materials Database. DFT 총에너지·형성에너지 참조 DB.
- **BNN (Bayesian Neural Network)** — 가중치를 점이 아니라 **분포**로 두는 신경망.
  예측이 분포로 나와 **불확실도가 공짜로** 나온다.
- **SVI / ELBO** — 사후분포를 직접 못 구하니 다루기 쉬운 분포(여기선 `AutoDiagonalNormal`)로
  근사하고 그 거리를 최소화하는 방법. 최소화하는 양이 **ELBO loss**.
- **`σ ~ Gamma(0.5, 1)`** — 관측 잡음의 크기 자체를 학습하는 사전분포. **aleatoric(데이터 고유
  잡음)** 과 **epistemic(모델 무지)** 을 분리해 준다.
- **Optuna pruning** — 하이퍼파라미터 탐색에서 초반 성적이 나쁜 trial 을 중간에 죽이는 것.
  이 논문 500 trial 중 275(A)/285(B)가 그렇게 죽었다.
- **EI (Expected Improvement)** — 단일목적 획득함수. "현재 최고를 얼마나 넘길 것으로 기대되나".
- **HVI (Hypervolume Improvement)** — 다목적판. "Pareto front 가 덮는 부피를 얼마나 늘리나".
- **ParEGO** — 다목적을 **랜덤 가중 스칼라화**해서 매 반복 다른 방향으로 EGO(=GP+EI)를 도는 방법.
  front 를 고르게 채우는 데 쓴다.
- **Pareto front** — 어떤 목표도 다른 목표를 희생하지 않고는 못 개선하는 해들의 집합.
- **UMAP** — 고차원 점을 2D 로 눌러 그리는 비선형 투영. ⚠ **거리·면적에 물리적 의미 없음**.
- **pra (per reciprocal atom)** — VASP k-점 밀도 지정 단위(역격자 부피 × 원자수 기준).
- **ΔS_conf > 1.5R** — 고엔트로피 물질의 관행적 정의. 5원 등몰이면 ln5 = 1.609R 로 최대.
